## Основы Асинхронности в Python (Asyncio) ⏱️⚡

### Главная концепция: Однопоточная конкурентность

Асинхронность в Python — это **НЕ** параллельное выполнение кода в несколько потоков или на разных ядрах процессора. 
Python выполняет асинхронный код **строго в одном потоке**.

**Суть концепции:** Пока одна задача ждет ответа от внешней системы (например, скачивает файл из интернета или ждет ответ от базы данных), процессор не простаивает. Он временно переключается на выполнение другой задачи. 
**Главная цель:** Эффективно утилизировать время **ожидания** (I/O Bound задачи).

#### Аналогия: Повар на кухне 👨‍🍳
**Синхронный повар:**
  1. Поставил чайник греться, смотрит на него в ожидании пока закипит.
  2. Чайник закипел — повар начал резать бутерброд. (Процессор заблокирован ожиданием).
**Асинхронный повар:**
  1. Поставил чайник греться.
  2. Пока чайник греется, он отошел резать бутерброд.
  3. Как только чайник засвистел, повар вернулся к нему. (Повар один, поток один, но задачи делаются конкурентно).

---

### Главный движок: Event Loop (Цикл событий) 🔄

Вся асинхронность держится на **Event Loop**. Это бесконечный цикл внутри Python, который управляет задачами.
1. Он берет задачу из списка и запускает её.
2. Как только задача говорит: *"Я жду ответ от сервера"*, Event Loop откладывает её в сторону.
3. Он берет следующую задачу.
4. Как только отложенная задача получила ответ, Event Loop возвращает её в работу.

---

### Разница между `async` и `await` 🧱

Это два главных ключевых слова, которые работают только в паре.

#### 1. Ключевое слово `async` (Объявление)
Ставится перед `def` и превращает обычную функцию в **корутину** (coroutine / асинхронную функцию).
**Зачем нужна:** Она сообщает Python: *Внутри этой функции будет происходить асинхронное ожидание. Не выполняй её как обычную функцию*.
**Особенность:** Если просто вызвать такую функцию в коде: `my_async_func()`, она **не выполнится**. Она просто вернет объект корутины (чертеж задачи). Чтобы она запустилась, её нужно передать в Event Loop.

#### 2. Ключевое слово `await` (Точка переключения)
Ставится строго **внутри** асинхронных функций перед вызовом других асинхронных функций.
**Зачем нужна:** Это маркер для Event Loop. Буквально переводится как: *Я здесь засыпаю, жду ответ. Переключись на другие задачи, а когда вернется результат, продолжи выполнение с этой же строчки*.
**Ограничение:** Нельзя использовать `await` внутри обычной синхронной функции. Будет ошибка синтаксиса.

### Базовый шаблон кода на Python 🐍

```python
import asyncio
import time

# 1. Объявляем асинхронную функцию (корутину)
async def fetch_data(task_id, delay):
    print(f"Запрос {task_id} отправлен...")
    
    # Имитируем реальное ожидание сети (нельзя использовать time.sleep, он заблокирует поток!)
    # await отдает управление обратно в Event Loop
    await asyncio.sleep(delay) 
    
    print(f"--> Запрос {task_id} ПОЛУЧЕН!")
    return f"Данные {task_id}"

async def main():
    start_time = time.time()
    
    # asyncio.gather запускает несколько корутин одновременно в Event Loop
    results = await asyncio.gather(
        fetch_data(1, 2),  # Задача 1 ждет 2 секунды
        fetch_data(2, 3),  # Задача 2 ждет 3 секунды
        fetch_data(3, 1)   # Задача 3 ждет 1 секунду
    )
    
    print(f"Все результаты: {results}")
    print(f"Затрачено времени: {time.time() - start_time:.2f} сек")

# Точка входа: запускает Event Loop и передает ему главную функцию
asyncio.run(main())
```

**Вывод в консоли:**
```text
Запрос 1 отправлен...
Запрос 2 отправлен...
Запрос 3 отправлен...
--> Запрос 3 ПОЛУЧЕН!  (через 1 сек)
--> Запрос 1 ПОЛУЧЕН!  (через 2 сек)
--> Запрос 2 ПОЛУЧЕН!  (через 3 сек)
Все результаты: ['Данные 1', 'Данные 2', 'Данные 3']
Затрачено времени: 3.00 сек  (А не 2 + 3 + 1 = 6 секунд, как в синхронном коде!)
```

### Краткая шпаргалка для собеседования (Q&A)

**Асинхронность ускоряет математические вычисления (CPU-bound)?**
  - Нет. Если функция долго считает факториал или крутит циклы, асинхронность не поможет, так как поток всего один и он будет занят вычислениями. Повару некогда отвлекаться.
**Что такое корутина (Coroutine)?**
  - Это функция, объявленная через `async def`, выполнение которой можно приостановить (через `await`) и возобновить позже с того же места.
**Что будет, если в асинхронном коде вызвать синхронный `time.sleep(5)`?**
  - Он заблокирует весь поток целиком на 5 секунд. Event Loop «застынет», и ни одна другая асинхронная задача в этот момент не выполнится. Нужно использовать только `await asyncio.sleep(5)`.
