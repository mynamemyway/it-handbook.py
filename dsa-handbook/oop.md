# Object-Oriented Programming (OOP)

## 1. Разбор кода ListNode на примере LL (Связного списка)

### Пример и определения

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

1. **class** — это ключевое слово, которое сообщает интерпретатору Python: «я создаю новый, пользовательский тип данных» (как int, str или list, но свой собственный).
2. **ListNode** — это имя (название) нового типа данных.
3. **__init__** — это функция (метод). Слово «инициация» здесь означает заполнение начальными данными.
  - Когда ты вызываешь класс, Python сначала выделяет кусок памяти в Куче под объект, а затем передает этот пустой кусок памяти в функцию __init__.
  - Задача __init__ — записать в этот выделенный кусок памяти нужные переменные.
4. **self** — это техническое имя (ссылка) на выделенный кусок памяти, который Python только что создал.
5. **(self, val=0, next=None)** — аргументы функции.
6. **val=0** и **next=None** — значения по умолчанию, если при создании объекта ты ничего не передашь в скобках.
7. **self.val = val** и **self.next = next**:
  - **self.val** — создание переменной внутри выделенного куска памяти.
    - Точка **(.)** — это оператор доступа.
    - Запись означает: «Внутри объекта `self` создай ячейку с именем `val` и запиши туда то, что пришло в аргументе `val`».
  - **self.next** — то же самое с **next**: «Внутри объекта `self` создай ячейку с именем `next` и запиши туда адрес следующего узла».

> *Функция __init__ внутри класса нужна для удобства — чтобы мы могли передавать значения (например, 10, 20) в скобках при создании объекта: ListNode(10). Если её убрать, класс останется классом, но создавать узлы станет не так удобно (придется писать по 3 строки кода на каждый узел).*

### Как создать объект
В самом определении класса объекта еще нет. Класс — это просто описание структуры.
Объект появляется только тогда, когда ты вызываешь класс по имени со скобками, как обычную функцию. В этот момент Python понимает, что нужно создать объект в памяти.

**Синтаксис создания объекта в Python железно зафиксирован:**

`имя_переменной = ИмяКласса(аргументы)`

Когда ты пишешь `node1 = ListNode(10):`

1. Python видит `ListNode(10)` и выделяет память в Куче.
2. Он вызывает __init__ и прокидывает эту память как `self`, а число `10` как `val`.
3. Внутри памяти создаются ячейки `val = 10` и `next = None`.
4. Адрес этого куска памяти записывается в переменную `node1` в Стек.

```python
node1 = ListNode(10) # Создали первый объект в памяти
node2 = ListNode(20) # Создали второй объект в памяти

node1.next = node2 # Связали первый объект с вторым
```

---

### Разбор: как правильно вывести значение объекта?

Переменная `node1.next` хранит в себе ссылку на весь второй объект. Если мы попытаемся распечатать `print(node1.next)`, На экран выведется техническая строка вида <__main__.ListNode object at 0x7f...>, то есть адрес в памяти.

### Как получить само значение через точку?
Внутри `node2` (на который указывает `node1.next`) есть ячейка с именем `val`. Чтобы попасть в неё, мы должны использовать синтаксис точки дважды:

```python
print(node1.next.val)  # Выведет: 20
```

**Как это читает компьютер:**

1. node1 — берем первый узел.
2. .next — переходим по ссылке во второй узел (node2).
3. .val — забираем из второго узла число, которое там хранится.

### Полный код

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

dm = ListNode('fake')

node1 = ListNode(10)
node2 = ListNode(20)
node3 = ListNode(30)

dm.next = node1
node1.next = node2
node2.next = node3

head = node1
```

**Как код выглядит в оперативной памяти компьютера (в Куче):**

```python

       [ dm ]          [ node1 ]         [ node2 ]         [ node3 ]
    +-----------+     +----------+      +----------+      +----------+

    | val:'fake'|     | val: 10  |      | val: 20  |      | val: 30  |
    | next: --------->| next: --------->| next: --------->| next:None|
    +-----------+     +----------+      +----------+      +----------+
                          ^
                          |
                       [ head ]
```

*Также можно передавать ссылку на уже существующий объект прямо в момент его создания в круглых скобках:*

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

node1 = ListNode(10)
node2 = ListNode(20)
node3 = ListNode(30)

node1.next = node2
node2.next = node3

head = node1

dm = ListNode('fake', node1) # head уже есть, передаём ссылку на неё при создании
```
