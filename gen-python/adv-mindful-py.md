## 2.0 Замыкание, Декораторы и Рекурсия

### 2.1 Замыкание функции
В программировании существует такое понятие как «замыкание функции» (closure). Данный термин связан со вложенными функциями, а точнее со внутренней функцией, которую возвращает внешняя функция.

#### «Замыкание» == «Запоминание»
Сам термин «замыкание» может немного сбивать с толку из-за различных ассоциаций. Поэтому можете представлять слово «замыкание» как слово «запоминание», так как именно этот процесс важен.

«замыкание» → ассоциация: «запоминание»

#### Имя функции — это переменная
Имя функции является переменной, посмотрите:

```python
def print_name(name):
    print(name)


p1 = print_name
p2 = print_name

p1("Лена")  # Лена
p2("Миша")  # Миша
```

В `p1` и `p2` мы присвоили имя функции, и теперь `p1`, `p2` и `print_name` — это три переменные, которые являются одной и той же функцией. Другими словами, мы не копируем функцию — мы просто даём ей ещё одно имя, как ярлык на рабочем столе, ведущий к одному и тому же файлу. Это легко проверить:

```python
p1(p1 is print_name)  # True
p2(p2 is print_name)  # True
```

Оператор `is` проверяет не равенство значений, а идентичность — то есть указывают ли обе переменные на один и тот же объект в памяти. Результат `True` подтверждает, что `p1`, `p2` и `print_name` — это не копии, а разные имена одного объекта. Это важно, так как подобное используется в замыкании.

#### Создание и вызов функции
Важно чтобы вы чётко различали два термина: создание и вызов функции:

```python
def print_name(name):  # Создание функции
    print(name)


print_name("Лена")  # Вызов функции
```

#### Вложенные функции и замыкание
Существуют вложенные функции. Это когда в теле функции создают ещё одну функцию:

```python
def one():      # Внешняя функция
    def two():  # Внутренняя функция
        pass
```

Здесь: 

- `one()` — будет называться внешней функцией.
- `two()` — внутренней функцией.

Когда мы запускаем программу, Python создаёт только внешнюю функцию `one()`, поэтому вызвать функцию `two()` в глобальной области не получится:

```python
one()  # Всё хорошо
two()  # Ошибка 
```

`two()` существует только внутри `one()` — снаружи она просто недоступна, как локальная переменная. Но это возможно, если функция `one()` будет возвращать имя функции `two()`:

```python
def one():
    def two():
        print("Функция two")

    return two


inner = one()
inner()  # Функция two
```

Разберём по шагам. Команда `inner = one()` присваивает в `inner` то, что возвращает `one()`. А функция `one()` делает два действия:

1. Создаёт функцию `two()`
2. Возвращает имя `two`

Обратите внимание: **возвращается именно `two` без скобок** — то есть не результат вызова, а само имя функции. Это тот самый трюк, который мы делали в начале статьи: в переменную присваиваем другую переменную. Другими словами, `inner` и `two` — это две переменные, ссылающиеся на одну функцию.

**Функцию `inner()` теперь можно назвать «функцией-замыканием».**
*Также можно вызвать замыкание с помощью двойных скобок: `two()()`*

#### Каждая новая функция хранится в своей ячейке памяти
Важно понимать, что при каждом вызове `one()` будет создаваться новая функция `two`:

```python
def one():
    def two():
        print("Функция two")

    return two


inner1 = one()
inner2 = one()

inner1()  # Функция two
inner2()  # Функция two

print(inner1 is inner2)  # False
```

Здесь `inner1` и `inner2` ведут себя одинаково, но это разные версии функции `two` — они хранятся в разных ячейках памяти:

```python
print(inner1)  # <function one.<locals>.two at 0x000002C5A4D13BA0>
print(inner2)  # <function one.<locals>.two at 0x000002C5A4D1C860>
```

Обратите внимание на адреса в конце — они разные. Это значит, что каждый вызов `one()` порождает независимую копию `two` со своим местом в памяти. 

#### Что доступно внутренней функции
Внутренняя функция может видеть все области видимости, поэтому ей доступны все объекты внешней функции, включая параметры:

```python
def one(a, b):
    c = 30
    def two():
        print("Вижу:", a, b, c)

    return two


inner1 = one(10, 20)
inner2 = one(100, 200)

inner1()  # Вижу: 10 20 30
inner2()  # Вижу: 100 200 30
```

Но возникает вопрос: каким образом аргументы `10`, `20` и другие появились на экране? Ведь мы вызываем только внутреннюю функцию `two`? В этом и кроется особенность замыкания (запоминания) функции.

#### Хранилище __closure__
У каждой функции-замыкания существует специальный атрибут __closure__. В нём хранятся только те переменные внешней функции, на которые ссылается внутренняя функция (так называемые свободные переменные). Посмотрите:

```python
def one(a, b):
    c = 30
    def two():
        print("Вижу:", a, b, c)

    return two


inner1 = one(10, 20)

print(inner1.__closure__)
# (<cell at 0x...: int object at 0x...>,
#  <cell at 0x...: int object at 0x...>,
#  <cell at 0x...: int object at 0x...>)
```

Когда создаётся внутренняя функция (при вызове внешней), в атрибут __closure__ записываются ссылки на переменные внешней функции, которые используются внутри. В нашем случае это `a`, `b` и `c`. Если бы внутренняя функция не использовала какую-то из переменных внешней, та в __closure__ не попала бы — атрибут хранит только то, что реально нужно.

Причём у каждой функции будет свой атрибут __closure__, поэтому `inner1` и `inner2` выводят разные результаты:

```python
inner1()  # Вижу: 10 20 30
inner2()  # Вижу: 100 200 30
```

Именно поэтому `inner1` «помнит» значения 10 и 20, а `inner2` — 100 и 200: у каждой функции своё __closure__ с собственными данными.

#### Значения можно изменять
По умолчанию, переменные из __closure__ нельзя перепривязать (присвоить новое значение) — для этого нужен nonlocal:

```python
def one(a, b):
    def two():
        nonlocal a, b
        a += 1
        b += 1
        print("Изменил значения:", a, b)

    return two


inner1 = one(10, 20)
inner1()  # Изменил значения: 11 21
```

Ключевое слово nonlocal сообщает Python: «переменная a здесь — это та же самая a, что во внешней функции, а не новая локальная». Попытка перепривязки без `nonlocal` приведёт к ошибке:

```python
def one(a, b):
    def two():
        a += 1  # Ошибка: UnboundLocalError
        b += 1
        print("Изменил значения:", a, b)
```

Ошибка `UnboundLocalError` возникает потому, что Python видит присваивание `a += 1` и решает, что a — это локальная переменная функции `two`. Но локальная a ещё не была создана, поэтому обращение к ней до присваивания вызывает ошибку.

Однако, если переменная содержит изменяемый объект (например, список или словарь), его можно модифицировать без `nonlocal`:

```python
def one():
    items = []
    
    def two(x):
        items.append(x)  # Работает без nonlocal
        print(items)
    
    return two


inner = one()
inner(1)  # [1]
inner(2)  # [1, 2]
```

Здесь мы не присваиваем `items` новое значение — мы изменяем сам список через метод append. Python не считает это перепривязкой, поэтому `nonlocal` не нужен. Запомните это различие: `nonlocal` нужен для перепривязки переменной, но не для изменения мутируемого объекта.

#### Примеры использования замыканий
Существуют различные сценарии использования замыкания. Самый распространённый из них — это создание декораторов, но с ним мы познакомимся в следующих статьях. Давайте рассмотрим несколько примеров без декораторов.

##### 1. Создание специализированных функций (фабрики функций)
Когда нужно создать несколько похожих функций с разными параметрами.

```python
def multiplier(n):
    def multiply(x):
        return x * n
    
    return multiply


double = multiplier(2)
triple = multiplier(3)

print(double(10))  # 20
print(triple(10))  # 30
```

Функция `multiplier` — это «фабрика»: она производит новые функции, каждая из которых «помнит» своё значение n. В итоге мы получаем `double` и `triple` — самостоятельные функции, которые можно передавать куда угодно и вызывать независимо друг от друга.

Типичные случаи:

- генерация валидаторов;
- создание конвертеров единиц;
- настройка обработчиков событий.

##### 2. Настройка callback-функций
Особенно часто встречается в GUI, веб-разработке и асинхронном коде.

```python
def make_handler(user_id):
    def handler(event):
        print(f"Пользователь {user_id}: {event}")
    
    return handler


handler_42 = make_handler(42)
handler_42("login")  # Пользователь 42: login
```

Замыкание позволяет привязать контекст к обработчику. Без замыкания пришлось бы передавать `user_id` в каждый вызов `handler` вручную — или хранить его в глобальной переменной. Используется в: GUI, asyncio, веб-серверах, системах событий.

##### 📝 Суть Callback-функций (функций обратного вызова)

Передача исполняемого кода в качестве аргумента для отложенного выполнения.

- Определение: Callback — это функция, которая передается в другую функцию или систему как объект, чтобы быть вызванной позже при наступлении конкретного события.
- Комбинация с замыканиями: Замыкание позволяет «зашить» внутрь колбэка контекст (например, `user_id`) в момент его создания. Когда внешняя система (GUI, веб-сервер) вызовет этот колбэк, ей не нужно знать детали контекста — функция выполнит логику на сохраненных ранее данных.
- Где применяется: Обработка кликов по кнопкам в GUI, обработка входящих сетевых запросов на веб-серверах, асинхронный код (`asyncio`).

#### Как внутренняя функция запоминает то, что во внешней функции?

У каждой функции существует специальный атрибут `__closure__`, который можно вызвать с помощью конструкции:

```python
функция.__closure__
```

В обычных функциях он имеет значение `None`. Но если функция является замыкающей, то в атрибуте `__closure__` замыкающей функции будет храниться информация об объектах, которые она запомнила из внешней функции, в формате кортежа.

```python
def one(x, y):
    def two():
        return f"x = {x}, y = {y}"
    return two

perem = one(10, 20)
print(perem.__closure__)  
# (<cell at 0x00000194E6AC3AC0: int object at 0x00007FF8B8E3CAD8>, 
# <cell at 0x00000194E6AECF70: int object at 0x00007FF8B8E3CC18>)
```

В примере видно, что в замыкающей функции `perem`, хранятся два объекта типа данных `cell`. Нас сейчас не интересует этот тип данных (`cell`), давайте посмотрим как можно узнать, что именно хранит замыкающая функция. Чтобы это сделать, можно использовать следующую конструкцию:

```python
print([cell.cell_contents for cell in функция.__closure__])
```

В нашем случае весь код будет выглядеть вот так:

```python
def one(x, y):
    def two():
        return f"x = {x}, y = {y}"
    return two

perem = one(10, 20)
print([cell.cell_contents for cell in perem.__closure__])  # [10, 20]
```

Теперь мы видим, что функция `perem` хранит информацию о параметрах `x` и `y`. Но важно понимать, что в этом атрибуте хранятся лишь объекты из внешней функции, причём те, которые используются во внутренней функции:

```python
n = 1000
def one(x, y):
    m = 500
    w = 800
    def two():
        z = 200
        nonlocal w
        return x, y, z, m, n
    return two

perem = one(10, 20)
print([cell.cell_contents for cell in perem.__closure__])  # [500, 800, 10, 20]
```

Переменная `n` не относится к внешней функции, поэтому внутренняя функция не хранит информацию об `n` при замыкании в атрибуте `__closure__`. Все объекты из внешней функции, которые возвращает внутренняя, сохранятся в атрибуте `__closure__`. Если использовать `nonlocal`, то переменная из внешней функции также окажется в `__closure__`, в примере это переменная `w`.

По сути с помощью атрибута `__closure__` можно понять, что конкретно сохраняется в процессе замыкания, и что можно использовать для своих целей.

#### Ключевые моменты

##### О замыканиях и вложенных функциях:
- Замыкание (closure) — это внутренняя функция, которая сохраняет доступ к данным внешней функции после её завершения.
- Имя функции в Python является обычной переменной и может быть присвоено другой переменной без копирования функции.
- Вложенная функция доступна только внутри внешней функции, если не вернуть её через `return`.
- При возврате внутренней функции создаётся функция-замыкание, которую можно вызывать вне внешней функции.

##### О механизме работы замыканий:
- Каждый вызов внешней функции создаёт новый объект внутренней функции в отдельной области памяти.
- Внутренняя функция имеет доступ к переменным внешней области видимости, включая параметры и локальные переменные.
- Атрибут __closure__ хранит ссылки только на те внешние переменные, которые реально используются внутренней функцией.
- Благодаря __closure__ каждая функция-замыкание «помнит» значения переменных внешней функции.

##### Об изменении сохранённых данных:
- Для перепривязки переменных внешней функции внутри замыкания необходимо использовать ключевое слово `nonlocal`.
- Без `nonlocal` попытка присвоить новое значение внешней переменной приводит к ошибке `UnboundLocalError`.
- Изменяемые объекты (списки, словари и др.) можно изменять без nonlocal, если не выполняется перепривязка самой переменной.
- Важно различать изменение объекта и переприсваивание переменной — только второе требует `nonlocal`.

##### Практическое применение замыканий:
- Фабрики функций позволяют создавать специализированные функции, которые запоминают свои параметры.
- Callback-функции используют замыкания для хранения контекста (например, идентификатора пользователя или настроек обработчика).
- Замыкания помогают сохранять состояние между вызовами без использования глобальных переменных.
- Одно из самых важных применений замыканий — создание декораторов.

#### Практика

##### Сюжет
Алон создаёт программу для супермаркетов, которая осуществляет контроль над финансами в кассе. Программа знает, сколько денег было в кассе в начале дня, учитывает входящие и исходящие суммы из кассы, и составляет отчёт о наличии денег в кассе по окончании смены. Алон решил испытать свои новые знания о замыкании и использует "фабрику функций", чтобы реализовать поставленные перед ним задачи.

##### Задание
В программу всегда будут поступать четыре числа (см. Sample Input). Например:

```python
1000  # первое число, сумма денег в кассе на данный момент
300   # второе число, операция с кассой (теперь в кассе 1300)
-500  # третье число, операция с кассой (теперь в кассе 800)
2000  # четвёртое число, операция с кассой (теперь в кассе 2800)
```

Примите эти четыре числа и сохраните их в переменные (либо используйте другим способом). Первое число – это всегда количество денег в кассе на данный момент, а остальные числа – это операции с кассой (положительные числа – увеличивают деньги в кассе, отрицательные числа – уменьшают).

Создайте функцию-фабрику `input_kassa(cash)`, внутри которой будут объявлены две вложенные функции следующим образом:

```python
# Структура вложенности:
def input_kassa(cash):
    def operation_with_kassa(number):
        # ваш код    
    def print_kassa():
        # ваш код
    return operation_with_kassa, print_kassa
```

- Функция `input_kassa(cash)` принимает один аргумент и сохраняет его в параметр `cash`. Эта функция будет принимать первое число (то есть сумму денег в кассе на данный момент) и сохранять его в параметр `cash`.
- Функция `operation_with_kassa(number)` принимает один аргумент и сохраняет его в параметр `number`. Функция ничего не возвращает, она лишь изменяет параметр `cash`. Например, функция берёт поступающее число (например, второе), если оно положительное то параметр `cash` увеличивается на это число (`number`), если отрицательное, то `cash` уменьшается на это число (`number`). Функция ничего не возвращает, она лишь изменяет параметр `cash`, поэтому правильно используйте параметр `cash`, чтобы изменить его.
- Функция `print_kassa()` не принимает аргументов и лишь выводит на экран значение параметра `cash`.

Функция `input_kassa()` будет возвращать функции `operation_with_kassa` и `print_kassa`. Используйте это знание, для решения задачи.

После создания функций, используйте знания темы "замыкания функций" и начните проводить операции с поступающими числами. Например:

### 2.2 Декораторы (функции-обёртки)
**Декоратор** — это функция, которая принимает другую функцию или метод в качестве аргумента и возвращает новую функцию, добавляющую некоторую дополнительную функциональность. Декораторы ещё называют "функцией-обёрткой". Для начала давайте посмотрим, как выглядят декораторы.

**Уточнение определения**
*Декоратор — это вызываемый объект (функция или класс), который принимает другой вызываемый объект (функцию, метод или класс) и возвращает его измененную версию или обертку.*

#### Как выглядят декораторы
```python
@add_text
def plus(a, b):
    return a + b
```

В данном примере `@add_text` — это декоратор, который обозначается символом `@` перед именем функции. Декоратор размещается над определением функции, указывая, что к ней (к функции `plus`) будет добавлено дополнительное поведение, описанное в декораторе `add_text`.

`@add_text` — это способ применения декоратора, который предварительно ещё необходимо создать. Давайте создадим декоратор `add_text` и посмотрим, как он изменит поведение функции `plus`.

#### Создание декоратора
Пока не углубляйтесь в детали самого декоратора `add_text`, посмотрите лишь на то, как он изменяет поведение функции `plus`. Устройство декоратора рассмотрим после примера.

```python
# Создание декоратора add_text
def add_text(func): 
    def wrapper(*args, **kwargs):
        print("Привет из декоратора!")
        return func(*args, **kwargs)
    return wrapper

# Применение декоратора add_text
@add_text
def plus(a, b):
    return a + b

# Вызываем функцию plus с дополнительным поведением
print(plus(5, 100))
# Привет из декоратора!
# 105
```

Без декоратора функция `plus` вернула бы только значение `105`. Однако, мы видим, что декоратор добавляет функциональность, выводя сообщение `"Привет из декоратора!"` перед результатом.

#### Как устроен декоратор
Как уже было сказано, декоратор — это функция, которая принимает другую функцию или метод в качестве аргумента и возвращает новую функцию, добавляющую некоторую дополнительную функциональность. Давайте разберём устройство декоратора на примере `add_text`.

```python
def add_text(func): 
    def wrapper(*args, **kwargs):
        print("Привет из декоратора!")
        return func(*args, **kwargs)
    return wrapper
```

Функция `add_text` принимает другую функцию в качестве аргумента и присваивает её параметру `func`. В этот параметр присвоится имя функции, к которой применяется декоратор, в нашем случае произойдёт неявная операция `func = plus`, то есть `func` становится ссылкой на исходную функцию `plus`.

Имя этого параметра (`func`) вы можете выбирать самостоятельно, но рекомендуется использовать `func`.

Далее создаётся внутренняя функция `wrapper` (с англ. "обёртка"), которая принимает любые позиционные и именованные аргументы (`*args`, `**kwargs`). В эти параметры будут передаваться аргументы, которые мы передаём при вызове функции, к которой применён декоратор, в нашем случае — к функции `plus`, то есть в `*args` передаются числа `5`, `100`.

Внутреннюю функцию декоратора обычно называют `wrapper`. Это название делает код более понятным для других программистов. Для универсальности декоратора она принимает параметры `*args` и `**kwargs`, позволяя работать с любыми функциями. Старайтесь использовать параметры `*args` и `**kwargs`.

Внутри функции `wrapper` создаётся самое главное — "дополнительная функциональность". В нашем случае мы выводим текст `"Привет из декоратора!"` с помощью `print()`.

Помимо дополнительного поведения, необходимо вернуть действие самой функции, к которой применён декоратор, то есть происходит команда `return func(*args, **kwargs)`. Так как `func = plus`, то этот код можно представить как `return plus(*args, **kwargs)`, где в `args` передаются числа `5`, `100`.

Внутри функции `wrapper` создаётся дополнительное поведение и, обычно, возвращается результат вызова функции, к которой применяется декоратор. Но всё зависит от цели декоратора, поэтому код внутри `wrapper` может быть разным.

Далее, возвращается имя внутренней функции, то есть `return wrapper`, тем самым создаётся замыкание.

#### Что происходит при вызове функции с декоратором
Когда мы вызываем функцию `plus(5, 10)`, на самом деле выполняется функция `wrapper` и весь код, который содержится в внутри этой функции. В нашем случае выводится на экран текст и возвращается результат вызова `plus(5, 10)`. Таким образом на экране появляется следующий результат:

```python
# Привет из декоратора!
# 105
```

#### Неявные моменты при использовании декоратора
Когда вы применяете декоратор к функции, то происходит неявная команда `функция = декоратор(функция)`. Например:

```python
@add_text
def plus(a, b):
    return a + b

# в неявной форме происходит команда:
plus = add_text(plus) 
```

Имя `plus` становится результатом вызова декоратора. Поскольку декоратор `add_text` возвращает функцию `wrapper`, происходит замыкание, и `plus` теперь ссылается на `wrapper`. Таким образом, при вызове `plus(5, 10)` фактически вызывается `wrapper(5, 10)`, где числа `5` и `10` сохраняются в `args`. Затем `args` используется для вызова исходной функции через `return func(*args, **kwargs)` (где `func = plus`).

Замыкание позволяет внутренней функции `wrapper` сохранять доступ к переменной `func`, даже после завершения выполнения внешней функции `add_text`.

#### Применим декоратор к разным функциям
Давайте применим наш декоратор к трём разным функциям (сложение, вычитание, умножение).

```python
# Создание декоратора add_text
def add_text(func): 
    def wrapper(*args, **kwargs):
        print("Привет из декоратора!")
        return func(*args, **kwargs)
    return wrapper

# Применение декоратора:
@add_text
def plus(a, b):
    return a + b

@add_text
def minus(a, b):
    return a - b

@add_text
def mult(a, b, c):
    return a * b * c

# Вызываем функции с декоратором:
print(plus(5, 100))
# Привет из декоратора!
# 105

print(minus(20, 7))
# Привет из декоратора!
# 13

print(mult(3, 3, 3))
# Привет из декоратора!
# 27
```

В примере видно, что с помощью декоратора мы добавили новое поведение для трёх функций. При вызове функции мы использовали разное количество аргументов, но так как в коде мы использовали `*args`, `**kwargs` то наш код сработал корректно.

#### Что будет, если не использовать *args, **kwargs в wrapper
Если вы хорошо разобрались в теме декораторов, можете осознанно использовать другие параметры в `wrapper`. Но для универсальности кода, обычно используют `*args`, `**kwargs`. Давайте рассмотрим не стандартный вариант:

```python
def add_text(func): 
    def wrapper(arg1, arg2):
        print(f"В функцию {func.__name__} передали аргументы: {arg1, arg2}")
        # метод __name__ позволяет получить имя функции 
        return f'Результат: {func(arg1, arg2)}'
    return wrapper

@add_text
def plus(a, b):
    return a + b

print(plus(5, 100))
# В функцию plus передали аргументы: (5, 100)
# Результат: 105
```

Здесь мы используем параметры `arg1`, `arg2`, так как мы знаем, что в функцию `plus` передаются два аргумента. Но если мы применим декоратор к функции, в которой используются другое количество аргументов, то это вызовет ошибку. Например:

```python
@add_text
def mult(a, b, c):
    return a * b * c

print(mult(3, 3, 3))
# Ошибка, ожидается два аргумента, а вы передаёте три
```

Поэтому, старайтесь осознанно подходить к созданию декораторов. Если вы планируете применять декоратор к функциям с разным количеством аргументов, используйте `*args`, `**kwargs` в функции `wrapper`.

#### Зачем нужны декораторы?
Декораторы в Python используются для добавления или изменения функциональности функций и методов без изменения их кода. Это удобный инструмент для повторного использования кода и решения задач, таких как логирование, проверка данных, кэширование или управление доступом.

##### Логирование
Логирование в Python — это процесс записи информации о работе программы, такой как ошибки, предупреждения, отладочные сообщения или ключевые события. Логирование помогает отслеживать выполнение кода, анализировать поведение приложения и выявлять проблемы.

```python
def log_decorator(func):
    def wrapper(*args, **kwargs):
        print(f"Вызов функции {func.__name__} с аргументами {args} и {kwargs}")
        return func(*args, **kwargs)
    return wrapper

@log_decorator
def add(a, b):
    return a + b

print(add(3, 5))
# Вызов функции add с аргументами (3, 5) и {}
# 8
```

Обычно логирование часто используется с библиотекой `logging` в реальных проектах, а приведённый пример — упрощённая реализация. О библиотеках мы ещё будем говорить в главе "Модули, библиотеки, пакеты".

##### Проверка прав доступа
```python
def auth_decorator(func):
    def wrapper(user, *args, **kwargs):
        if user == "admin":
            return func(user, *args, **kwargs)
        else:
            print("Доступ запрещён")
            return None  # Явное указание на возвращаемое значение
    return wrapper

@auth_decorator
def secret_function(user, data):
    print(f"Секретные данные: {data}")

secret_function("admin", "Пароли")  # Секретные данные: Пароли
secret_function("user", "Пароли")   # Доступ запрещён
```

Этот код использует декоратор `auth_decorator` для проверки пользователя.

Если `user` равен `"admin"`, вызывается исходная функция `secret_function`, которая выводит данные.
Иначе выводится сообщение `"Доступ запрещён"`.
Результат: для `"admin"` данные отображаются, для других пользователей доступ блокируется.

#### Заключение
Если вы разобрались с замыканиями и поняли, как Python присваивает декораторы, создание собственных декораторов станет понятным. Если что-то осталось неясным, вернитесь к теме замыканий, изучите её основательно и снова попробуйте разобраться с декораторами.

Помните: "Всё кажется сложным, пока не поймёшь, как это работает". Декораторы могут показаться сложными, но их понимание становится проще, когда вы освоите их устройство.

#### Важные моменты
Декораторы размещаются перед определением какой-либо функции. Например:

```python
@add_text
def plus(a, b):
    return a + b
```

При применении декоратора к функции фактически выполняется операция: `функция = декоратор(функция)`. Отсюда определение: декоратор — это функция, принимающая другую функцию в качестве аргумента и возвращающая новую функцию, изменяющую или расширяющую её поведение. Это легко проверить на следующем примере:

```python
def add_text(func):
    def wrapper(*args, **kwargs):
        print(f"Привет из функции wrapper!")
        print(f"Результат: {func(*args, **kwargs)}")
    return wrapper

def plus(a, b):
    return a + b

plus = add_text(plus)  # вызвали команду явным образом, вместо объявления декоратора
plus(5, 100)
# Привет из функции wrapper!
# Результат: 105
```

В данном коде мы не объявляли декоратор, но явным образом вызвали команду `plus = add_text(plus)` и результат оказался таким же, как если бы мы объявили декоратор.

Использование `*args` и `**kwargs` при создании декораторов делает их более универсальными, позволяя применять декораторы к функциям с разным количеством аргументов. Однако это не обязательно, если число аргументов заранее известно.

Хотя "функция-обёртка" — это распространённое определение, оно может быть не совсем точным. Декоратор можно рассматривать как шаблон, который модифицирует поведение функции или метода, а не только "оборачивает" их.

#### 📝 Универсальный шаблон декоратора

Данная структура разделяет логику обертки на этапы «до» и «после» выполнения, гарантируя однократный вызов декорируемой функции и корректный возврат её результата.

**Шаблон кода**:
```python
def universal_decorator(func):
    def wrapper(*args, **kwargs):       # Перехват аргументов, валидация или логирование до запуска
        result = func(*args, **kwargs)  # Единственный вызов функции с сохранением возвращаемого значения
        pass                            # Обработка result или логирование побочных эффектов после запуска
        return result                   # Проброс сохраненного результата во внешний код
    return wrapper
```

**Преимущества перед прямой конструкцией `return func(...)`**:
1.  **Защита от дублирования**: Исключает повторный вызов функции, если её результат или последствия работы (например, запись в БД или словарь) требуются для логирования внутри `wrapper`.
2.  **Управление контекстом**: Позволяет модифицировать возвращаемое значение `result` перед тем, как отдать его вызывающему коду.

**Итог**: Использование промежуточной переменной `result` делает декоратор универсальным инструментом для любых задач пред- и постобработки данных.

```python
change_balance(int(input()))  # Баланс пополнен!
change_balance(int(input()))  # Недостаточно средств!
```

### 2.3 Декораторы с параметрами
Существует механика, при которой можно передавать аргументы в декораторы. Такие декораторы обычно состоят из трёх вложенных функций: внешней, средней и внутренней.

```python
def внешняя(arg1, arg2,...):  # принимает аргументы
    def средняя(func):        # принимает функцию, которую нужно задекорировать
        def внутренняя():     # содержит код декоратора
```

Теоретически, можно реализовать декоратор с аргументами и без строго тройной вложенности, но это усложнит код.

#### Если кратко ...
Если сильно не вдаваться в подробности, то здесь всё работает точно также как и в обычных декораторах. Отличие лишь в том, что при определении декоратора мы можем указать аргументы, которые затем можем использовать в коде при декорировании функции.

Параметры декоратора и аргументы самой функции передаются в разное время, поэтому их нельзя объединить в один `*args`. Требуется три уровня вложенности:

1. **Внешняя функция** — принимает НАСТРОЙКИ декоратора (в момент инициализации `@`).
2. **Средняя функция**  — принимает саму ДЕКОРИРУЕМУЮ ФУНКЦИЮ (автоматически от Python).
3. **Внутренняя функция (wrapper)** — принимает АРГУМЕНТЫ ВЫЗОВА функции (в момент работы).

```python
def dec_with_args(arg1, arg2):                             # 1. Ловит настройки (100, 200)
    def decorator(func):                                   # 2. Ловит функцию (print_name)
        def wrapper(*args, **kwargs):                      # 3. Ловит аргументы вызова ('Alon')
            # Замыкание видит переменные всех уровней:
            print("Выводим name:", func(*args))            # func и args доступны
            print(f"Выводим arg1 и arg2: {arg1}, {arg2}")  # arg1 и arg2 доступны
        return wrapper
    return decorator

@dec_with_args(100, 200)
def print_name(name):
    return name

print_name('Alon')
# Выводим name: Alon
# Выводим arg1 и arg2: 100, 200
```

Обратите внимание, что в декораторе мы указали аргументы `@dec_with_args(100, 200)`. Эти аргументы (`100`, `200`) мы можем использовать во внутренней функции `wrapper`, так как они сохраняются при замыкании. Таким образом декораторы с аргументами позволяют делать наш код ещё более гибким.

Механизм замыкания позволяет "захватывать" ссылки на переменные внешних функций, сохраняя их значения для дальнейшего использования в функции `wrapper`.

#### Если подробно ...
Когда мы используем декоратор `@dec_with_args(100, 200)`, неявно происходит команда:

```python
print_name = dec_with_args(100, 200)(print_name)
```

Такая запись может показаться сложной, но её можно упростить. Вызов `dec_with_args(100, 200)` — это вызов функции, возвращающей среднюю функцию `decorator`. Таким образом, код можно представить вот так:

```python
print_name = decorator(print_name)
```

Такой вид выглядит более понятным. Имя функции `print_name` передаётся в параметр `func` функции `decorator(func)`, которая, в свою очередь, возвращает функцию `wrapper`. Таким образом, `print_name` и `wrapper` становятся одной и той же функцией. Следовательно, вызов `print_name('Alon')` эквивалентен вызову `wrapper('Alon')`. Если вы уже знакомы с декораторами, дальнейшая работа аналогична их обычной реализации.

#### 📝 Декоратор с параметрами через functools.partial

Обычный декоратор с параметрами требует **3 уровня вложенности**, чтобы разделить настройки от самой функции. Модуль `functools.partial` позволяет сократить эту структуру до **2 уровней**.

`functools.partial` это инструмент, который берет любую функцию и «замораживает» в ней часть аргументов, возвращая новую функцию с меньшим числом параметров.

Вместо создания промежуточной функции `def decorator(func)`, мы пишем базовый декоратор, принимающий и функцию, и настройки одновременно. Затем с помощью `partial` мы «замораживаем» настройки, превращая её в стандартный декоратор, ожидающий только `func`.

```python
from functools import partial

# ШАГ 1: Базовый декоратор (всего 2 уровня!). Принимает ВСЁ сразу.
def dec_base(func, arg1, arg2):
    def wrapper(*args, **kwargs):
        print("Выводим name:", func(*args))
        print(f"Выводим arg1 и arg2: {arg1}, {arg2}")
    return wrapper

# ШАГ 2: Фабрика, убирающая «матрешку»
def dec_with_args(arg1, arg2):
    # partial берет dec_base и намертво фиксирует в ней arg1 и arg2.
    # На выходе получается функция, которая теперь ждет ТОЛЬКО один аргумент — func.
    # Это полностью заменяет старый средний слой "def decorator(func)".
    return partial(dec_base, arg1=arg1, arg2=arg2)

# ШАГ 3: Стандартное использование
@dec_with_args(100, 200)
def print_name(name):
    return name

print_name('Alon')
# Выводим name: Alon
# Выводим arg1 и arg2: 100, 200
```

#### Заключение
В рамках курса мы не будем использовать декораторы с аргументами, но изучение этой темы будет полезным для вашего профессионального роста. Освоение декораторов позволит углубить понимание языка Python и перейти на более продвинутый уровень.

#### Важные моменты
- Для декораторов с аргументами обычно используется тройной уровень вложенности, что позволяет гибко передавать параметры. Однако, в некоторых случаях можно использовать и другие подходы, хотя они менее распространены.
- Внешняя функция возвращает имя средней функции (`return decorator`), а средняя функция возвращает имя внутренней (`return wrapper`), это необходимо чтобы создания замыкания, это важно запомнить.
- Внешняя функция принимает аргументы декоратора (`100`, `200`), поэтому количество параметров и аргументов должно соответствовать. Средняя функция принимает в качестве аргумента функцию (в параметр `func`), которую нужно декорировать. Внутренняя функция (`wrapper`) содержит логику декоратора и принимает как позиционные, так и именованные аргументы, передаваемые при вызове декорируемой функции (например, `print_name('Alon')`).
- Название "средней функции" (`decorator`) используется в примере для наглядности. В реальных сценариях имя функции можно выбрать произвольно.

### 2.4 Рекурсия
Рекурсия – это способ программирования, при котором функция вызывает саму себя для решения задачи.

```python
def function():
    ...
    return function()
```

Когда функция вызывает саму себя, это чем-то напоминает цикл `while`, поэтому в рекурсии важно создать условие для выхода из неё, чтобы ваш код не привёл к бесконечной рекурсии. Для предотвращения бесконечной рекурсии каждая рекурсивная функция должна иметь:

- **Базовый случай (base case):** Базовый случай определяет условие, при котором рекурсивные вызовы прекращаются. Это может сопровождаться использованием `return` для завершения функции.
- **Рекурсивный случай (recursive case):** Это часть кода, в которой функция вызывает саму себя, постепенно приближаясь к базовому случаю. Обычно, с каждым новым вызовом в коде что-то изменяется и код приближается к тому, чтобы выйти из рекурсии, то есть к базовому случаю.

Базовый и рекурсивный случаи — ключевые элементы рекурсии. На практике базовый случай должен быть корректно определён, чтобы функция могла завершить выполнение, а рекурсивный случай должен приближать выполнение к достижению базового случая.

#### Пример рекурсии
Давайте разберём простой случай:

```python
def print_numbers(number):
    # Базовый случай:
    if number <= 0:
        return None
    # Рекурсивный случай:
    else:
        print(number)
        print_numbers(number - 1)

print_numbers(3)

# 3
# 2
# 1
```

В примере, мы создали функцию, которая выводит на экран все целые положительные числа от указанного нами числа `number` до `1` включительно.

Вызывая функцию `print_numbers(3)`, сначала мы проверяем `number <= 0`, так `number` равен `3`, то выполняется блок `else`, то есть выводится на экран число `3` и функция вызывается снова, но уже с аргументом `number - 1`.
Вызывается функция `print_numbers(2)`, сначала мы проверяем `number <= 0`, так `number` равен `2`, то выполняется блок `else`, то есть выводится на экран число `2` и функция вызывается снова, но уже с аргументом `number - 1`.
Вызывается функция `print_numbers(1)`, сначала мы проверяем `number <= 0`, так `number` равен `1`, то выполняется блок `else`, то есть выводится на экран число `1` и функция вызывается снова, но уже с аргументом `number - 1`.
Вызывается функция `print_numbers(0)`, сначала мы проверяем `number <= 0`, так `number` равен `0`, то условие выполнилось и произошёл выход из рекурсии с помощью `return`. В данном случае мы не возвращаем никакого значения, так как это не требуется, поэтому используем `return None`.

На самом деле здесь можно вообще обойтись без `return`, так как если функция ничего не возвращает, она вернёт `None` автоматически. Поэтому весь наш код можно было записать вот так:

```python
def print_numbers(number):    
    if number > 0:     
        print(number)
        print_numbers(number - 1)

print_numbers(3)

# 3
# 2
# 1
```

И вообще, подобную задачу проще и эффективнее решить с помощью цикла `while`, например:

```python
def print_numbers(number):
    while number > 0:
        print(number)
        number -= 1

print_numbers(3)
```

Однако, в более сложных задачах, рекурсия может быть удобнее.

Рекурсии часто применяются в различных алгоритмах, таких как:

- Обход деревьев и графов.
- Обход в глубину (DFS).
- Алгоритмы быстрой сортировки и сортировки слиянием.

#### Заключение
В рамках курса мы не будем углубляться в тему рекурсии, так как она тесно связана с алгоритмами. Тему алгоритмов лучше проходить на следующей ступени обучения. Главное просто запомните саму идею, что функция может вызывать саму себя для достижения определённой цели.

#### Важные моменты
- Базовый и рекурсивный случаи — ключевые элементы рекурсии. На практике важно обеспечить корректное условие выхода из рекурсии и логику, приближающую выполнение функции к этому выходу.
- Важно помнить, что в Python существует ограничение на глубину рекурсии (по умолчанию около 1000 вызовов) для предотвращения переполнения стека вызовов. При необходимости его можно изменить с помощью `sys.setrecursionlimit`, но это следует делать с осторожностью. Если рекурсия становится слишком глубокой, Python выбрасывает исключение `RecursionError`. Это важно учитывать при проектировании функций, особенно для работы с большими объёмами данных.
- Условие выхода из рекурсии не всегда связано с использованием `return`. Например, функция может просто прекратить дальнейшие вызовы без явного возврата значения.

## 3.0 Генераторы

### 3.1 Функция-генератор

Генераторы — это специализированные итераторы, создаваемые с помощью функций с ключевым словом `yield`. Функция, внутри которой присутствует `yield`, обычно называют "функцией-генератором".

#### Создание генератора
Генератор создаётся за счёт вызова функции-генератора. Посмотрите на пример:

```python
def my_generator():   # создание функции-генератора
    yield 1
    yield 2
    yield 3


gen = my_generator()  # создание объекта-генератора (сокращённо называют "генератором")

print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3

print(*gen, 'Генератор опустошён')  # Генератор опустошён
```

Функция-генератор (ФГ) создаётся как обычная функция, но вместо `return` используется ключевое слово `yield`. В данном случае `my_generator` — это ФГ, которая при выполнении `yield 1` возвращает значение `1`. Аналогично выполняются и следующие выражения `yield 2` и `yield 3`, последовательно возвращая указанные значения.

Вызов `my_generator()` создаёт объект-генератор, часто сокращённо называемый "генератором". В данном случае объект-генератор присваивается переменной `gen`, которая затем используется как генератор.

---

#### 📝 Механика генераторов (Generator expressions, Yield/Return, Next)

Генератор — это ленивый итератор. Он не хранит элементы в памяти, а вычисляет их строго по одному в момент запроса.

*   **Два способа создания генераторов**:
    1.  **Генераторные выражения**: `gen = (f(x) for x in arr)`. Подходят для простых однострочных операций.
    2.  **Функции-генераторы**: Функции, внутри которых вместо `return` используется ключевое слово `yield`. Нужны для сложной логики.

*   **Анатомия работы: yield vs return vs next()**:
    Строка `gen = my_generator()` **не запускает** код функции, а лишь создает объект-генератор. Чтобы запустить код, Python использует встроенную функцию `next()`.
    
    1.  `return` — завершает работу функции навсегда. Очищает локальные переменные функции из памяти.
    2.  `yield` — отдает значение наружу и **замораживает** выполнение функции. Она запоминает текущую строку кода и состояние всех переменных.
    3.  `next(gen)` — встроенная функция Python, которая «будит» генератор. Код внутри него выполняется от текущего места до следующего слова `yield`.

*   **Пример работы механики**:
    ```python
    def my_gen():
        yield 1  # (A) Здесь функция замрет при первом next()
        yield 2  # (B) Здесь функция замрет при втором next()

    gen = my_gen()  # Код функции еще НЕ запустился. Создан объект gen.
    
    print(next(gen))  # Выведет: 1. Код дошел до (A), отдал 1 и уснул.
    print(next(gen))  # Выведет: 2. Функция проснулась на (A), дошла до (B), отдала 2 и уснула.
    ```

*   **Связь с циклом `for`**:
    Обычный цикл `for item in gen:` под капотом автоматически вызывает функцию `next(gen)` на каждой итерации и сам останавливается, когда код в генераторе полностью заканчивается.

**Итог**: `yield` временно приостанавливает функцию, а встроенная функция `next()` продвигает её вперед до следующей остановки.

#### 📝 Итераторы vs Генераторы

Генератор — это подвид итератора.

*   **Связь понятий**:
    Итератор — это широкий стандарт (интерфейс).
    Генератор — это компактный инструмент его реализации.
    *   Любой генератор является итератором, так как поддерживает функцию `next()`.
    *   Не любой итератор является генератором (итератор можно создать через классы).

*   **Функция-генератор как «Фабрика»**:
    Функция с `yield` — это шаблон (инструмент создания) итератора с нужными параметрами. 
    ```python
    def range_generator(start, stop):  # Функция-фабрика с параметрами
        current = start
        while current < stop:
            yield current
            current += 1

    # Вызов функции создает (штампует) готовый объект-итератор
    my_iterator = range_generator(1, 5) 
    ```

*   **В чем разница при создании**:
    1.  **Классический итератор**: Требует создания класса, ручного написания методов `__iter__` и `__next__`, ручного отслеживания состояния переменных и вызова ошибки `StopIteration`.
    2.  **Генератор**: Автоматизирует всю рутину. Python сам превращает функцию с `yield` в объект-итератор, сохраняет состояние её переменных и понимает, когда нужно остановиться.

**Итог**:
Итератор — это то, **чем объект является** (он умеет отдавать элементы по одному через `next`). Генератор — это то, **как этот объект был создан** (через функцию с `yield` или круглые скобки).

---

#### Свойства генератора
Генератор является итератором, поэтому имеет те же особенности:

- Запоминает последнее выполненное состояние.
- Является итерируемым объектом.
- Поддерживает функцию `next()`.
- Имеет ограниченный ресурс, после исчерпания которого дальнейшее использование невозможно.

#### Как использовать генератор, функциz `next()`
Чаще всего генераторы используют с функцией `next()`, либо в цикле `for`.

```python
def my_generator():
    yield 1
    yield 2
    yield 3


gen = my_generator()
print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3
print(next(gen))  # Ошибка StopIteration
```

В примере видно, что генератор запоминает своё предыдущее состояние вызова. С каждым вызовом `next()` активируется и возвращается `yield`. В данном случае, у нас три `yield`, поэтому четвёртый вызов `next()` привёл к ошибке. Чтобы не было ошибки, можно использовать параметр `default` в функции `next()`, о нём мы уже говорили в теме итераторов.

##### Генератор в цикле for

```python
def my_generator():
    yield 1
    yield 2
    yield 3


gen = my_generator()
for i in gen:
    print(i, end=' ')
# 1 2 3
```

Цикл `for` позволяет более безопасно использовать генераторы, контролируя все вызовы `yield`. С каждой итерацией, в `i` присваивается значение, которое возвращает `yield`.

##### Вызов ФГ в цикле for

Если вы планируете использовать генератор в цикле, то можно не создавать переменную `gen`, как в предыдущем примере, а сразу использовать вызов функции в цикле:

```python
def my_generator():
    yield 1
    yield 2
    yield 3


for i in my_generator():  # цикл по генератору
    print(i, end=' ')
# 1 2 3
```

Как мы уже знаем, вызов `my_generator()` возвращает генератор, поэтому цикл проходит по генератору. Такой вариант записи более короткий, но, возможно, не самый читаемый. Чтобы улучшить читаемость кода, можно добавить комментарий.

##### ФГ с параметрами

Мы можем создавать ФГ с параметрами, давайте рассмотрим простой пример:

```python
def my_generator(x, y, z):
    yield x
    yield y
    yield z


for i in my_generator(10, 20, 30):  # цикл по генератору
    print(i, end=' ')
# 10 20 30
```

Здесь мы создаём три параметра `x`, `y`, `z` и ФГ возвращает переданные в эти параметры аргументы с помощью `yield`.

##### Генератор можно преобразовать в другой итерируемый объект

Чтобы преобразовать генератор в другой тип данных, например в список, воспользуемся функцией `list()`.

```python
def my_generator():
    yield 1
    yield 2
    yield 3

gen = my_generator()
gen_list = list(gen)
print(gen_list)  # [1, 2, 3]

# или сразу вот так:
print(list(my_generator()))  # [1, 2, 3]
```

Но важно помнить, что генераторы, как и итераторы, исчерпываются. Рассмотрим пример:

```python
def my_generator():
    yield 1
    yield 2
    yield 3

gen = my_generator()
print(list(gen))  # [1, 2, 3]
print(list(gen))  # []
```

Здесь переменная `gen` – является генератором. При первом вызове `list(gen)` генератор выполняет все инструкции `yield` и исчерпывается. Повторный вызов `list(gen)` возвращает пустой список, поскольку генератор сохраняет состояние и не может быть повторно использован после завершения.

Поэтому, такие команды лучше сохранять в переменные, как в предыдущем примере: `gen_list = list(gen)`. Либо заново определять генератор, например:

```python
def my_generator():
    yield 1
    yield 2
    yield 3

gen = my_generator()
print(list(gen))  # [1, 2, 3]

gen = my_generator()  # Заново определили генератор
print(list(gen))  # [1, 2, 3]
```

##### Генератор и большой объект

Генератор позволяет обрабатывать большие списки по частям, возвращая элементы поочерёдно. Это особенно полезно для работы с большими объемами данных, избегая загрузки всего списка в память.

```python
my_list = list(range(100))

def my_generator(arg):
    mid = int(len(arg) / 2)
    yield arg[:mid]
    yield arg[mid:]

gen = my_generator(my_list)
print(next(gen))  # [0, 1, 2, ..., 49]
print(next(gen))  # [50, 51, 52, ..., 99]
```

Функция-генератор принимает список из 100 элементов, вычисляет индекс середины с помощью переменной `mid` и поочерёдно возвращает первую и вторую половины списка с использованием `yield`. Такой подход позволяет работать с крупными объектами, обрабатывая их частями. Например, вместо списка это может быть текстовый файл, который генератор возвращает построчно, оптимизируя использование памяти.

##### Использование цикла for в теле функции-генератора

Чтобы не писать много раз слово `yield`, внутри генераторов можно использовать циклы, например:

```python
def number_generator():
    for i in range(10):
        yield i


gen = number_generator()

# используем next:
print(next(gen))  # 0
print(next(gen))  # 1

# используем цикл:
for i in gen:
    print(i, end=' ')

# 2 3 4 5 6 7 8 9 
```

В переменную `gen`, присваивается генератор, который будет возвращать числа от `0` до `9`. При её вызове не выполняется сразу весь цикл `for` внутри ФГ. Вместо этого возвращается объект-генератор, который будет управлять выполнением функции.

Используя `next()` цикл `for` внутри функции начнёт выполняться, `i` станет равным `0`, и выполнение остановится на `yield 0`. Значение `0` вернётся как результат вызова `next()`. Повторный вызов `next()` делает то же самое, но возвращает число `1`.

Затем цикл `for` завершает генератор, выводя оставшиеся числа от `2` до `9`.

##### Использование цикла while и бесконечные генераторы

В ФГ можно использовать цикл `while` и создавать неисчерпаемый генератор. Давайте рассмотрим пример:

```python
def greet_generator():
    while True:
        yield 'Привет, я бесконечный генератор'
        string = 'просто для примера'

gen = greet_generator()
print(next(gen))  # Привет, я бесконечный генератор
print(next(gen))  # Привет, я бесконечный генератор
print(next(gen))  # Привет, я бесконечный генератор
```

Внутри `greet_generator()` мы создали конструкцию с бесконечным циклом `while True`, который возвращает строку с приветствием с помощью ключевого слово `yield`. Генератор `gen` данной функции никогда не исчерпается. Такие бесконечные генераторы могут быть полезны в разных ситуациях, поэтому о них важно знать.

Переменная `string` в этом примере нужна для того, чтобы вы лучше поняли процесс работы такого генератора.

Как это работает:

1. Первый вызов `print(next(gen))` проверит условие `while True`, затем выполнит строку с `yield` и на экране появится текст. На этом действие вызова `print(next(gen))` закончено.
2. Второй вызов `print(next(gen))` создаст переменную `string`, затем проверит условие `while True` и снова выполнит строку с `yield`.
3. Третий вызов `print(next(gen))` сделает всё то же самое, что и в пункте 2. И последующие вызовы `print(next(gen))` будут повторять пункт 2.

##### Возврат различных объектов в yield

Ключевое слово `yield` может возвращать различные объекты, в том числе и другие функции, если это необходимо:

```python
def print_hello():
    return 'hello!'

def gen_hello():
    yield print_hello()
    yield print_hello()
    yield print_hello()

for i in gen_hello():
    print(i)
    
# hello!
# hello!
# hello!
```

При каждой итерации, в переменную `i` будет присваиваться вызов функции `print_hello()`, то есть строка `'hello!'`.

#### Где на практике встречаются функции-генераторы с yield
- Обработка больших файлов.
- Постраничная загрузка данных из базы данных.
- Генерация последовательностей чисел.
- Обход графов или деревьев.
- Обработка потоков данных.

#### Заключение
Постарайтесь понять принцип работы функций-генераторов и их объектов — генераторов. Это особый вид итераторов, которые поддерживают все операции, связанные с итерацией. Генераторы запоминают своё состояние между вызовами и на каждой итерации возвращают следующий `yield`.

Они особенно полезны для вычисления значений "на лету", без необходимости сохранять их в памяти, что делает его идеальным для работы с большими объёмами данных. Функции-генераторы обеспечивают гибкость, позволяя управлять возвращаемыми значениями через `yield` на каждом этапе выполнения.

#### Важные моменты
- Функция с ключевым словом `yield` становится функцией-генератором, а её вызов возвращает объект-генератор. Объект-генератор управляет выполнением функции: отслеживает текущий шаг, возобновляет выполнение с точки остановки и завершает функцию при необходимости.
- Генераторы и итераторы — схожие, но не идентичные понятия. Генераторы представляют собой особую разновидность итераторов, создаваемую с использованием функции с `yield`. Итераторы, в свою очередь, могут быть созданы различными способами, и генераторы являются лишь одной из форм их реализации.
- Генератор, будучи особым видом итератора, поддерживает использование функции `next()`. При каждом вызове `next()` выполнение функции продолжается с точки, где оно было остановлено, то есть после последнего `yield`. Как и в случае с итераторами, для повторного вызова `next()` нужно заново создать объект-генератор, так как предыдущий завершается после исчерпания всех значений.
- Если генератор преобразовать, например, в список с помощью `list()`, а затем использовать `next()`, то возникнет ошибка. Дело в том, что после функции `list()`, наш генератор полностью завершил свою работу, и чтобы его использовать повторно, нужно снова определить генератор.

```python
def my_generator():
    yield 1
    yield 2
    yield 3

gen = my_generator()
print(list(gen))            # [1, 2, 3]
print(next(gen, 'Ошибка'))  # Ошибка

gen = my_generator()        # заново определили объект-генератор gen
print(next(gen))            # 1
```

- При желании, вызовы ФГ можно использовать в циклах напрямую, не создавая переменных (как в случае с `gen`).
- Ключевое слово `yield` может возвращать различные объекты, в том числе и другие функции, если это необходимо.
- Генераторы в Python не поддерживают индексацию, так как они создают элементы "на лету" и не хранят их в памяти.

#### `yield from` для углублённого изучения генераторов

В Python можно использовать конструкцию `yield from`, которая была добавлена в язык, начиная с версии 3.3. Эта конструкция упрощает работу с генераторами, позволяя делегировать часть операций другому генератору или итерируемому объекту.

Вот как это работает:

**Основная идея:** `yield from <iterable>` упрощает код, который должен итерироваться по другому генератору или итерируемому объекту и выдавать его элементы. Вместо того чтобы вручную итерироваться и `yield` каждый элемент, `yield from` делает это автоматически.

##### Пример использования:

```python
def generator1():
    yield from range(3)
    yield from "abc"

for value in generator1():
    print(value)
```

Этот код эквивалентен следующему:

```python
def generator2():
    for value in range(3):
        yield value
    for value in "abc":
        yield value

for value in generator2():
    print(value)
```

Оба примера выведут:

```text
0
1
2
a
b
c
```

##### Преимущества:

- **Краткость:** `yield from` позволяет сократить код и сделать его более читаемым.
- **Прозрачность:** Делегирование итерации другому генератору становится более явным.

##### Дополнительные возможности:

- `yield from` также передает любые исключения и значения, возвращаемые дочерним генератором, в родительский генератор.
- Если дочерний генератор использует `return`, то значение, указанное после `return`, будет передано в родительский генератор через `StopIteration` и доступно в родительском генераторе.

##### Пример с возвратом значения:

```python
def subgenerator():
    yield 1
    yield 2
    return "result"

def main_generator():
    result = yield from subgenerator()
    print(f"Subgenerator returned: {result}")

for value in main_generator():
    print(value)
```

Вывод будет:

```text
1
2
Subgenerator returned: result
```

Таким образом, `yield from` является удобным инструментом для работы с генераторами и упрощает их структуру и управление.

### 3.2 Генераторные выражения

Генераторные выражения (generator expressions) — это компактный способ создания генераторов. Они позволяют создавать генераторы на основе любого итерируемого объекта (строки, списка, кортежа и т. д.). Генераторное выражение включает два обязательных компонента (выражение и цикл) и одно необязательное (условие).

#### Функция-генератор и генераторное выражение
Генераторные выражения (ГВ) более компактны, чем функции-генераторы. Посмотрите на пример создания одно и того же генератора.

Функция-генератор:

```python
def squares(n):
    for i in range(n):
        if i > 0:
            yield i ** 2

gen = squares(3)
```

Генераторное выражение:

```python
gen = (i ** 2 for i in range(3) if i > 0)
```

В обоих случаях, переменная `gen` станет генератором. Давайте более подробно разберём синтаксис ГВ.

#### Синтаксис генераторного выражения

```python
переменная = (выражение for item in iterable условие)
```

- **Цикл:** `for item in iterable` — это стандартный цикл `for`. В нашем случае это `for i in range(3)`.
- **Условие (необязательно):** выполняет роль фильтра и проверяет `item` с помощью условия. Если условие истинно, `item` используется в выражении, если ложно, то не используется. Таким образом условие определяет, будет ли элемент включён в генератор. В нашем случае это `if i > 0`.
- **Выражение:** В выражении можно использовать переменную, выполнить какую-либо операцию, вызвать функцию или метод. В нашем случае это операция `i ** 2`. Результат этой операции попадает в генератор.
- **Круглые скобки `()`:** генераторное выражение оформляется в круглых скобках.

Генераторное выражение возвращает генератор. В нашем примере, мы присвоили генератор в переменную `gen`.

#### Примеры работы с генераторным выражением
Давайте рассмотрим несколько примеров ГВ, чтобы понять как они работают и где их можно использовать.

##### Преобразование ГВ в другой тип данных
Генераторные выражения можно преобразовать в различные типы данных, которые поддерживают итерирование. Давайте рассмотрим пример со списком, так как он прост для понимания:

```python
# преобразование в список
gen = (i ** 2 for i in range(3) if i > 0)
print(list(gen))  # [1, 4]
```

**Создание генератора:**

При выполнении строки `gen = (i ** 2 for i in range(3) if i > 0)` создаётся генератор `gen`. Здесь важно понимать, что генератор не производит какие-либо подсчёты, операции и другое в момент создания. Все операции начинают происходить только в момент использования генератора.

**Преобразование в список:**

При вызове `list(gen)` начинается итерация по генератору.

1. Первая итерация: Перебирается первый элемент `range(3)`, переменной `i` присваивается значение `0`.
2. Условие `i > 0` ложно, поэтому выражение `i ** 2` не вычисляется.
3. Вторая итерация: `i = 1`. Условие `i > 0` истинно, поэтому вычисляется выражение `i ** 2`. Генератор возвращает значение `1`.
4. Третья итерация: Условие истинно, поэтому вычисляется `i ** 2`. Генератор возвращает значение `4`.

Функция `list()` собирает полученные значения и создаёт список `[1, 4]`.

Для закрепления, давайте рассмотрим тот же пример, но немного его изменим.

##### ГВ без условия

```python
gen = (i ** 2 for i in range(3))
print(list(gen))  # [0, 1, 4]
```

Если убрать условие, то в каждой итерации будет выполняться выражение `i ** 2` и в список попадут три числа `0`, `1`, `4`. В прошлом примере число `0` не прошло условие, поэтому не попало в список, а в этом примере условия нет, и число попало в список.

##### ГВ с несколькими условиями
Если вы хотите применить несколько условий в генераторном выражении, можно комбинировать их, используя несколько операторов `if`.

```python
gen = (i ** 2 for i in range(8) if i > 0 if i % 2 == 0)
print(list(gen))  # [4, 16, 36]
```

Здесь мы используем два условия с `if`. Первое проверяет `i > 0`, второе проверяет чётность `i`. Выражение `i ** 2` выполняется только при выполнении одновременно обоих условий.

Вообще, не обязательно использовать два `if`. Просто хотел показать, что использование нескольких `if` возможно. Данное условие можно изменить на оператор `and` и результат будет тот же:

```python
gen = (i ** 2 for i in range(8) if i > 0 and i % 2 == 0)
print(list(gen))  # [4, 16, 36]
```

#### Как используют выражение?

##### Переменная в выражении

```python
gen = (i for i in range(3))
print(list(gen))  # [0, 1, 2]
```

В выражении не всегда используют операции, здесь можно разместить, например `i`. Тогда в список попадут значения `i`.

##### Объект в выражении

```python
gen = ('Alon' for i in range(3))
print(list(gen))  # ['Alon', 'Alon', 'Alon']
```

Выражение позволяет добавлять любой объект в список на каждой итерации. Например, при использовании строки `'Alon'` и трёх итерациях цикла, результатом будет список из трёх элементов, каждый из которых содержит строку `'Alon'`.

#### Функция next()
Генераторы являются инструментом, позволяющим эффективно работать с данными, особенно если их объём очень большой и хранить их в памяти одновременно невозможно или нецелесообразно. Если вы хотите работать с элементами генератора по одному, экономя память, используйте функцию `next()`.

```python
gen = (i for i in range(3))
print(next(gen))  # 0
print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # Ошибка. StopIteration
```

Но помните про исчерпаемость генератора. Ошибка `StopIteration` указывает, что итерация завершена и объектов в генераторе больше нет.

#### Исчерпание генераторов
Мы уже знаем, что генераторы исчерпываются, поэтому генераторы являются одноразовыми объектами, так как после полного перебора они становятся пустыми. Для их повторного использования необходимо заново создать генератор.

```python
gen = (i for i in range(3))
print(list(gen))  # [0, 1, 2] # создал список и исчерпал себя как генератор
print(list(gen))  # []

gen = (i for i in range(3))  # повторно определили генератор 
print(list(gen))  # [0, 1, 2]
```

#### Работа с итерируемыми объектами в ГВ
В генераторном выражении мы используем обычный цикл, поэтому, в качестве итерируемого объекта мы можем брать разные объекты, например: список, кортеж, строку и др.

```python
my_list = ['Алон', 'Эйли', 'Донни']
gen = (i for i in my_list if i[0] == 'Э')
print(list(gen))  # ['Эйли']
```

Здесь мы итерируемся по списку `my_list` и используем условие `i[0] == 'Э'`, то есть первую букву строки на равенство с буквой `'Э'`. Таким образом в список попадает только строка `'Эйли'`.

#### Генераторное выражение в качестве аргумента
Так как ГВ возвращает генератор, а генератор – является итерируемым объектом, то ГВ можно передавать в качестве аргумента в некоторых функциях.

##### Функция sum()

```python
result = sum(i ** 2 for i in range(10))
print(result)  # 285
```

Обратите внимание, что ГВ передается в качестве аргумента без круглых скобок. ГВ возвращает генератор, в который входят числа от `0` до `9` возведённые в квадрат, а в переменную `result` поступает сумма всех чисел из генератора.

##### Функция max()

```python
result = max(i for i in range(100) if i % 3 == 0)
print(result)  # 99
```

Здесь, в генератор поступают числа от `0` до `99` кратные `3`, а в переменную `result` присваивается только самое максимальные из них, то есть `99`.

#### Генераторы – это ленивые объекты
Генераторы, как и итераторы, не хранят элементы в памяти, а вычисляют их по мере необходимости. Такой процесс ещё называют "ленивой оценкой" или "lazy evaluation". Генераторы могут применять для работы с большими объёмами данных, чтобы брать из этого объёма всю информацию, но частями. Например, это можно сделать с помощью `next()`. Это позволяет экономить память и улучшает производительность программы.

#### Заключение
Генераторные выражения удобны для создания простой логики, например, создания списков с отфильтрованными элементами. Однако ГВ не рекомендуется использовать для сложной логики, так как это снижает читаемость кода; в таких случаях предпочтительнее функции-генераторы. ГВ удобно напрямую использовать в качестве аргументов в функции, так как они возвращают итерируемый объект.

Генераторы представляют собой особый вид итераторов: они не хранят все элементы в памяти, а вычисляют их по мере необходимости ("ленивая оценка", "lazy evaluation"). Это особенно полезно при работе с большими объёмами данных.

#### Важные моменты
- Генераторные выражения возвращают генераторы.

```python
gen = (num for num in range(5))
print(gen)  # <generator object <genexpr> at 0x00000277128E4DC0>  
```

Здесь `genexpr` – сокращение слова "generator expression", "генераторное выражение".

- Помните об исчерпаемости генераторов.
- Генераторные выражения компактны и возвращают итерируемый объект, поэтому их удобно использовать в качестве аргументов, в определённых функциях.
- При желании можно преобразовать ГВ в словарь или строку. Однако важно учитывать, что элементы в выражении должны быть подходящего типа для преобразования:

```python
# преобразование в словарь
gen = ((i, i ** 2) for i in range(3) if i > 0)
print(dict(gen))  # {1: 1, 2: 4}

# преобразование в строку
gen = (str(i ** 2) for i in range(3) if i > 0)
print(' '.join(gen))  # "1 4"
```

Об этом мы ещё поговорим чуть позже.

### 3.3 Списковые включения / списочные выражения (list comprehensions)

Существуют конструкции, похожие на генераторные выражения, которые позволяют создавать такие типы данных как списки, множества и словари. В этой статье мы поговорим о том, как создавать списки с помощью спискового включения.

#### Списковые включения (list comprehensions)
Списковые включения — это компактный способ создать список. В генераторах списков используются похожий синтаксис, что и в генераторных выражениях, но с квадратными скобками `[]`. Вот пример синтаксиса:

```python
переменная = [выражение for item in iterable условие]
```

Здесь всё очень похоже на генераторные выражения, только при этом создаётся список из элементов. Давайте рассмотрим несколько примеров.

> Термин "генератор списков" является устаревшим, так как "генератор" ассоциируется с объектом, возвращающим значения постепенно. Правильнее использовать термин "списковое включение" (list comprehension).

#### Примеры

##### Список из последовательных чисел

```python
num_list = [i for i in range(5)]
print(num_list)  # [0, 1, 2, 3, 4]
```

Здесь мы используем списковое включение для создания списка из чисел от `0` до `4` включительно. Само списковое включение возвращает список, поэтому, при желании, его можно сразу разместить в `print()` в качестве аргумента:

```python
print([i for i in range(5)])  # [0, 1, 2, 3, 4]
```

Если вы хорошо поняли тему генераторных выражений, то вам должно быть понятно, каким образом получился список из таких элементов. Используя генераторные выражения, мы могли сделать то же самое, только используя функцию `list()`, например:

```python
print(list(i for i in range(5)))  # [0, 1, 2, 3, 4]
```

А если не использовать списковое включение и генераторные выражения, то для создания подобного списка пришлось бы использовать большее количество кода:

```python
num_list = []

for i in range(5):
    num_list.append(i)

print(num_list)  # [0, 1, 2, 3, 4]
```

Думаю, в какой-то степени у вас уже сформировалось понимание, что многое в программировании создаётся для уменьшения количества строк кода и для улучшения читаемости кода. Таким образом, когда-то появился списковое включение, как один из удобных способов создания списков.

##### Использование операций в выражении

В списковых включениях мы также можем использовать операции в выражении, для получения необходимого результата.

```python
num_list = [i * 2 for i in range(5)]
print(num_list)  # [0, 2, 4, 6, 8]
```

Здесь мы используем операцию `i * 2`, и каждое число `i` в цикле умножается на `2`.

##### Использование условия

Для фильтрации данных, мы можем использовать условие в списочном выражении:

```python
num_list = [i * 2 for i in range(5) if i % 2 == 0]
print(num_list)  # [0, 4, 8]
```

Здесь, в каждой итерации происходит проверка на чётность значения переменной `i`. Если значение `i` чётное, то выполняется выражение `i * 2` и результат операции попадает в список. Если `i` не чётное, то выражение не выполняется.

##### Преобразование строк в верхний регистр

С помощью спискового включения можно преобразовывать элементы списка в другой тип данных и это очень удобно.

```python
words = ["hello", "world"]
upper_words = [word.upper() for word in words]
print(upper_words)  # ['HELLO', 'WORLD']
```

В примере выше, на основе списка `words`, мы создали новый список из тех же слов, только в верхнем регистре. В выражении мы использовали метод `.upper()`, который применили к каждому элементу в цикле.

При использовании методов в выражении важно, чтобы они возвращали новый объект, а не значение `None`. В противном случае вы рискуете получить объект, состоящий исключительно из элементов `None`, например, `[None, None, None]`.

##### Преобразование строк в числа

Один из удобных способов преобразовать строки из чисел в целые числа – это использовать списковое включение.

```python
string = '1 2 3 4 5'
num_list = [int(i) for i in string.split()]
print(num_list)  # [1, 2, 3, 4, 5]
```

Метод `string.split()` делит строку на подстроки по пробелу и возвращает список `['1', '2', '3', '4', '5']`, то есть цикл идёт именно по такому списку. Далее, с помощью `int(i)` каждый элемент списка преобразуется в целое число. Таким образом новый список будет состоять из чисел.

Раньше, подобные действия мы делали с помощью функции `map()`, но теперь вы можете выбирать удобный для вас способ:

```python
string = '1 2 3 4 5'

# с помощью map():
num_list = list(map(int, string.split()))
print(num_list)  # [1, 2, 3, 4, 5]

# с помощью спискового включения:
num_list = [int(i) for i in string.split()]
print(num_list)  # [1, 2, 3, 4, 5]
```

Только помните, что `map()` возвращает итератор, поэтому необходимо использовать функцию `list()` для создания списка.

##### Создание вложенного списка (словаря, странный пример)

Если вам необходимо создать вложенный список, состоящий, например, из словаря, укажите словарь в выражении:

```python
companies = ['Panasonic', 'Sony', 'Iphone', 'Nokia', 'LG']
my_list = [{name: 0} for name in companies]
print(my_list)  # [{'Panasonic': 0}, {'Sony': 0}, {'Iphone': 0}, {'Nokia': 0}, {'LG': 0}]
```

В данном выражении указан словарь `{name: 0}`, где `name` — переменная, принимающая строки с названиями фирм. В результате формируется список словарей, как в примере выше. Число `0` может быть использовано как начальное значение для каждого товара.

##### Итерация по словарю

Напомню, что при итерации по словарю в цикле `for` по умолчанию в переменную `i` присваиваются ключи словаря. Поэтому при использовании генератора списков со словарём, элементы нового списка будут состоять из ключей словаря.

```python
my_dict = {'a': 1, 'b': 2, 'c': 3}
list_key = [i for i in my_dict]
print(list_key)  # ['a', 'b', 'c']
```

Также напомню, что у словарей есть методы: `.keys()`, `.values()`, `.items()`. С помощью `.keys()` мы получаем ключи словаря, с помощью `.values()` мы получаем значения словаря, а с помощью `.items()` получаем кортеж из пар (ключ, значение). Всё это можно эффективно использовать в списковых включениях:

```python
my_dict = {'a': 1, 'b': 2, 'c': 3}

list_key = [i for i in my_dict.keys()]
print(list_key)  # ['a', 'b', 'c']

list_value = [i for i in my_dict.values()]
print(list_value)  # [1, 2, 3]

list_items = [i for i in my_dict.items()]
print(list_items)  # [('a', 1), ('b', 2), ('c', 3)]
```

Если вы используете `.items()`, то в генераторе списков, как и в обычном цикле `for`, можно указать несколько переменных:

```python
my_dict = {'a': 1, 'b': 2, 'c': 3}

list_items = [{key: value} for key, value in my_dict.items()]
print(list_items)  # [{'a': 1}, {'b': 2}, {'c': 3}]
```

Здесь мы используем метод `.items()` и переменные `key` и `value` для получения ключей и значений словаря. В выражении `{key: value}` создаются отдельные словари, которые добавляются в итоговый список.

#### Тернарный оператор в выражении
В генераторах списка можно использовать `if` в условии, но нельзя использовать `else`.

```python
my_dict = [i for i in range(3) if i % 2 == 0 else 9]  # Ошибка, else нельзя использовать
```

Но если вам необходимо использовать `else`, можно применить тернарный оператор, но не в условии, а в выражении.

```python
my_list = [i if i % 2 == 0 else 9 for i in range(3)]  # [0, 9, 2]
```

В выражении мы используем тернарный оператор `i if i % 2 == 0 else 9`, который проверяет `i` на чётность и добавляет в список значение `i` если оно чётное, или число `9` если `i` нечётное.

1. В первой итерации `i` равно `0` --> Выполняется тернарный оператор --> так как `0` – это чётное число, поэтому в список добавляется `0`.
2. Во второй итерации `i` равно `1` --> Выполняется тернарный оператор --> так как `1` – это нечётное число, поэтому в список добавляется `9`.
3. В третьей итерации `i` равно `2` --> Выполняется тернарный оператор --> так как `2` – это чётное число, поэтому в список добавляется `2`.

Если вам нужно подобное поведение, используйте тернарный оператор в выражении.

#### Заключение
Эффективность генераторов списков заключается в их лаконичности, читаемости и быстродействии при создании списков, так как они оптимизированы для работы с итерируемыми объектами.

Списковые включения часто используют для фильтрации данных, преобразования типов, создания новых списков на основе существующих, обработки строк, и применения функций к элементам итерируемых объектов.

#### Важные моменты
- Хотя списковые включения (list comprehensions) и генераторные выражения (generator expressions) похожи, важно понимать, что это разные конструкции. Генераторные выражения возвращают объект генератора, тогда как list comprehensions сразу возвращают список.
- Списковые включения быстрее традиционных циклов, так как используют встроенные оптимизации Python для работы с итерируемыми объектами.
- Но важно помнить, что списковые включения создают сразу весь список, занимая память и создавая объект в памяти. Поэтому они менее эффективны для больших данных по сравнению с генераторными выражениями.

### 3.4 Генераторы множеств и словарей

Помимо генераторов списков (List Comprehensions), существуют также генераторы множеств (Set Comprehensions) и генераторы словарей (Dictionary Comprehensions). Их синтаксис аналогичен синтаксису генераторных выражений.

#### Генераторы множеств (Set Comprehensions)
Генераторы множеств позволяют создавать множества с помощью лаконичного синтаксиса, аналогичного синтаксису списковых включений (list comprehensions). Это удобно для создания множества элементов на основе какого-либо итерируемого объекта с возможностью применения условий.

##### Фильтрация уникальных значений

```python
list_num = [22, 44, 1, 0, 0, 2, 22, 11, 121]
set_comp = {x for x in list_num if x % 2 == 0}
print(set_comp)  # {0, 2, 44, 22}
```

В приведённом примере мы преобразовали список `list_num` во множество, одновременно удалив все нечётные числа.

Напомню, что множество является неупорядоченным объектом, в котором элементы не имеют порядка.

##### Удаление дубликатов

```python
items = ['apple', 'banana', 'apple', 'orange', 'banana', 'pear']
unique_items = {i for i in items if len(i) > 5}
print(unique_items)  # {'orange', 'banana'}
```

Здесь, мы создали множество с помощью генератора множеств и отфильтровали значения с помощью условия `len(i) > 5`. Таким образом, мы получили множество из строк, длина которых более 5 букв.

##### Преобразование данных

```python
words = ['hello', 'world', 'python', 'coding']
upper_case_words = {i.upper() for i in words}
print(upper_case_words)  # {'WORLD', 'HELLO', 'CODING', 'PYTHON'}
```

Здесь, мы применяем генератор множеств и метод `.upper()` для преобразования символов строк в верхний регистр, создавая множество строк с заглавными буквами.

##### Используем функцию в выражении

```python
def square(x):
    return x * x


numbers = [1, 2, 3, 4, 5]
squares = {square(x) for x in numbers}
print(squares)  # {1, 4, 9, 16, 25}
```

В выражении можно использовать любые функции, которые возвращают какой-либо объект. В примере выше, мы создаём (определяем) свою функцию, которая возвращает результат операции с числами, то есть возвращает число.

Далее, мы используем эту функцию в выражении и получаем множество из элементов `numbers`, умноженных "сами на себя". Например, `1 * 1 = 1`, `2 * 2 = 4` и т.д.

#### Генераторы словарей
Генераторы словарей позволяют создавать словари из итерируемых объектов. В генераторах словарей также используют фигурные скобки, но в выражении важно указать конструкцию из пар `ключ: значение`.

##### Словарь из чисел

```python
dict_comp = {x: x**2 for x in range(5)}
print(dict_comp)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```

В этом примере используется выражение `x: x**2`. Поскольку оно включает пару значений, разделённых двоеточием, Python интерпретирует его как генератор словаря, а не множества. В результате создаётся словарь, где ключами являются числа, а значениями — их квадраты.

##### Фильтрация данных

```python
prices = {'apple': 120, 'banana': 200, 'cherry': 300}
expensive_fruits = {k: v for k, v in prices.items() if v > 150}
print(expensive_fruits)  # {'banana': 200, 'cherry': 300}
```

При работе со словарями часто используется метод `.items()` для перебора ключей и значений с помощью двух переменных, таких как `k` и `v` (в нашем случае). В примере используется условие для фильтрации словаря `prices` по значениям. В результате формируется новый словарь, содержащий только те пары "ключ-значение", где значение превышает `150`.

##### Подсчет частоты элементов

```python
items = ['apple', 'banana', 'apple', 'cherry', 'banana', 'banana']
frequency = {i: items.count(i) for i in set(items)}
print(frequency)  # {'cherry': 1, 'apple': 2, 'banana': 3}
```

Если вам необходимо подсчитать количество вхождений каждого элемента в списке, рекомендуется использовать генераторы словарей. Для оптимизации процесса можно итерироваться по множеству `set(items)`, что сокращает количество итераций. Затем метод `.count()` позволяет определить количество вхождений каждого конкретного элемента.

##### Создание словаря из двух списков

```python
keys = ['id', 'name', 'age']
values = [1, 'Alice', 30]
person_dict = {k: v for k, v in zip(keys, values)}
print(person_dict)  # {'id': 1, 'name': 'Alice', 'age': 30}
```

Для создания словаря из двух списков, где один используется как ключи, а другой как значения, можно воспользоваться генераторами словарей. Функция `zip()` создает итератор, который на каждой итерации возвращает кортеж, состоящий из элементов обоих списков. Это позволяет эффективно сформировать словарь с ключами из первого списка и соответствующими значениями из второго.

#### Тернарный оператор в выражении
"Условие" в теме генераторных выражений выполняет роль фильтра, то есть либо добавляет объект в генератор, либо нет. Чтобы сделать генераторное выражение более гибким, иногда используют "тернарный оператор" в "выражении". Напомню, что тернарный оператор возвращает один из двух объектов на основании условия, например:

```python
i = 100
print('Положительное' if i > 0 else 'Отрицательное')
```

Здесь мы передали тернарный оператор в качестве аргумента в `print()`, который провел проверку и вернул строку `'Положительное'`. Подобное действие мы можем реализовать в выражении, например:

```python
my_list = [100, -200, -400, 500]
result = {i: ('Положительное' if i > 0 else 'Отрицательное') for i in my_list}
print(result)
# {100: 'Положительное', -200: 'Отрицательное', -400: 'Отрицательное', 500: 'Положительное'}
```

Здесь мы используем генератор словаря. В качестве ключа мы берём каждый элемент из `my_list`, а в качестве значения используем тернарный оператор, который проверяет этот элемент (`i`) и возвращает одну из двух строк. Таким образом мы создали словарь, в котором ключами являются числа, а значениями строки `"Положительное"` или `"Отрицательное"` в зависимости от ключа.

В этом примере тернарный оператор был заключен в круглые скобки для улучшения читаемости кода, но код будет работать и без круглых скобок.

#### Заключение
С помощью синтаксиса генераторных выражений можно эффективно создавать словари и множества, используя соответствующие скобки и конструкции. Важно запомнить правильное использование скобок и элементов в выражении.

#### Важные моменты
Нельзя создать кортеж напрямую с помощью генераторных выражений, но их можно использовать совместно с функцией `tuple()`:

```python
my_list = [1, 2, 3]
my_set = tuple(i for i in my_list if i != 2)
print(my_set)  # (1, 3)
```

Для создания множества или словаря, с помощью синтаксиса генераторного выражения, следует использовать фигурные скобки. Тип данных будет зависеть от того, что вы укажете в выражении:

```python
print({i for i in [1, 2, 3]})        # множество {1, 2, 3} (порядок не гарантируется)
print({i: None for i in [1, 2, 3]})  # словарь {1: None, 2: None, 3: None}
```

Тему библиотек и импорта мы ещё не проходили. Но существует библиотека `collections`, которая позволяет более эффективно подсчитывать элементы и создавать словари. Например:

```python
from collections import Counter


items = ['apple', 'banana', 'apple', 'cherry', 'banana', 'banana']
frequency = dict(Counter(items))
print(frequency)  # {'apple': 2, 'banana': 3, 'cherry': 1}
```

Эта информация предназначена для тех, кто имеет базовое понимание работы с библиотеками. Использование метода `.count()` на каждой итерации не является оптимальным решением.
