# 2.1 Замыкание, Декораторы и Рекурсия

## Замыкание функции
В программировании существует такое понятие как «замыкание функции» (closure). Данный термин связан со вложенными функциями, а точнее со внутренней функцией, которую возвращает внешняя функция.

### «Замыкание» == «Запоминание»
Сам термин «замыкание» может немного сбивать с толку из-за различных ассоциаций. Поэтому можете представлять слово «замыкание» как слово «запоминание», так как именно этот процесс важен.

«замыкание» → ассоциация: «запоминание»

### Имя функции — это переменная
Имя функции является переменной, посмотрите:

```python
def print_name(name):
    print(name)


p1 = print_name
p2 = print_name

p1("Лена")  # Лена
p2("Миша")  # Миша
```

В p1 и p2 мы присвоили имя функции, и теперь p1, p2 и print_name — это три переменные, которые являются одной и той же функцией. Другими словами, мы не копируем функцию — мы просто даём ей ещё одно имя, как ярлык на рабочем столе, ведущий к одному и тому же файлу. Это легко проверить:

```python
p1(p1 is print_name)  # True
p2(p2 is print_name)  # True
```

Оператор is проверяет не равенство значений, а идентичность — то есть указывают ли обе переменные на один и тот же объект в памяти. Результат True подтверждает, что p1, p2 и print_name — это не копии, а разные имена одного объекта. Это важно, так как подобное используется в замыкании.

### Создание и вызов функции
Важно чтобы вы чётко различали два термина: создание и вызов функции:

```python
def print_name(name):  # Создание функции
    print(name)


print_name("Лена")  # Вызов функции
```

### Вложенные функции и замыкание
Существуют вложенные функции. Это когда в теле функции создают ещё одну функцию:

```python
def one():      # Внешняя функция
    def two():  # Внутренняя функция
        pass
```

Здесь: 

- one() — будет называться внешней функцией.
- two() — внутренней функцией.

Когда мы запускаем программу, Python создаёт только внешнюю функцию one(), поэтому вызвать функцию two() в глобальной области не получится:

```python
one()  # Всё хорошо
two()  # Ошибка 
```

two() существует только внутри one() — снаружи она просто недоступна, как локальная переменная. Но это возможно, если функция one() будет возвращать имя функции two():

```python
def one():
    def two():
        print("Функция two")

    return two


inner = one()
inner()  # Функция two
```

Разберём по шагам. Команда inner = one() присваивает в inner то, что возвращает one(). А функция one() делает два действия:

1. Создаёт функцию two()
2. Возвращает имя two

Обратите внимание: возвращается именно two без скобок — то есть не результат вызова, а само имя функции. Это тот самый трюк, который мы делали в начале статьи: в переменную присваиваем другую переменную. Другими словами, inner и two — это две переменные, ссылающиеся на одну функцию.

Функцию inner() теперь можно назвать «функцией-замыканием».

### Каждая новая функция хранится в своей ячейке памяти
Важно понимать, что при каждом вызове one() будет создаваться новая функция two:

```python
def one():
    def two():
        print("Функция two")

    return two


inner1 = one()
inner2 = one()

inner1()  # Функция two
inner2()  # Функция two

print(inner1 is inner2)  # False
```

Здесь inner1 и inner2 ведут себя одинаково, но это разные версии функции two — они хранятся в разных ячейках памяти:

```python
print(inner1)  # <function one.<locals>.two at 0x000002C5A4D13BA0>
print(inner2)  # <function one.<locals>.two at 0x000002C5A4D1C860>
```

Обратите внимание на адреса в конце — они разные. Это значит, что каждый вызов one() порождает независимую копию two со своим местом в памяти. 

### Что доступно внутренней функции
Внутренняя функция может видеть все области видимости, поэтому ей доступны все объекты внешней функции, включая параметры:

```python
def one(a, b):
    c = 30
    def two():
        print("Вижу:", a, b, c)

    return two


inner1 = one(10, 20)
inner2 = one(100, 200)

inner1()  # Вижу: 10 20 30
inner2()  # Вижу: 100 200 30
```

Но возникает вопрос: каким образом аргументы 10, 20 и другие появились на экране? Ведь мы вызываем только внутреннюю функцию two? В этом и кроется особенность замыкания (запоминания) функции.

### Хранилище __closure__
У каждой функции-замыкания существует специальный атрибут __closure__. В нём хранятся только те переменные внешней функции, на которые ссылается внутренняя функция (так называемые свободные переменные). Посмотрите:

```python
def one(a, b):
    c = 30
    def two():
        print("Вижу:", a, b, c)

    return two


inner1 = one(10, 20)

print(inner1.__closure__)
# (<cell at 0x...: int object at 0x...>,
#  <cell at 0x...: int object at 0x...>,
#  <cell at 0x...: int object at 0x...>)
```

Когда создаётся внутренняя функция (при вызове внешней), в атрибут __closure__ записываются ссылки на переменные внешней функции, которые используются внутри. В нашем случае это a, b и c. Если бы внутренняя функция не использовала какую-то из переменных внешней, та в __closure__ не попала бы — атрибут хранит только то, что реально нужно.

Причём у каждой функции будет свой атрибут __closure__, поэтому inner1 и inner2 выводят разные результаты:

```python
inner1()  # Вижу: 10 20 30
inner2()  # Вижу: 100 200 30
```

Именно поэтому inner1 «помнит» значения 10 и 20, а inner2 — 100 и 200: у каждой функции своё __closure__ с собственными данными.

### Значения можно изменять
По умолчанию, переменные из __closure__ нельзя перепривязать (присвоить новое значение) — для этого нужен nonlocal:

```python
def one(a, b):
    def two():
        nonlocal a, b
        a += 1
        b += 1
        print("Изменил значения:", a, b)

    return two


inner1 = one(10, 20)
inner1()  # Изменил значения: 11 21
```

Ключевое слово nonlocal сообщает Python: «переменная a здесь — это та же самая a, что во внешней функции, а не новая локальная». Попытка перепривязки без nonlocal приведёт к ошибке:

```python
def one(a, b):
    def two():
        a += 1  # Ошибка: UnboundLocalError
        b += 1
        print("Изменил значения:", a, b)
```

Ошибка UnboundLocalError возникает потому, что Python видит присваивание a += 1 и решает, что a — это локальная переменная функции two. Но локальная a ещё не была создана, поэтому обращение к ней до присваивания вызывает ошибку.

Однако, если переменная содержит изменяемый объект (например, список или словарь), его можно модифицировать без nonlocal:

```python
def one():
    items = []
    
    def two(x):
        items.append(x)  # Работает без nonlocal
        print(items)
    
    return two


inner = one()
inner(1)  # [1]
inner(2)  # [1, 2]
```

Здесь мы не присваиваем items новое значение — мы изменяем сам список через метод append. Python не считает это перепривязкой, поэтому nonlocal не нужен. Запомните это различие: nonlocal нужен для перепривязки переменной, но не для изменения мутируемого объекта.

### Примеры использования замыканий
Существуют различные сценарии использования замыкания. Самый распространённый из них — это создание декораторов, но с ним мы познакомимся в следующих статьях. Давайте рассмотрим несколько примеров без декораторов.

#### 1. Создание специализированных функций (фабрики функций)
Когда нужно создать несколько похожих функций с разными параметрами.

```python
def multiplier(n):
    def multiply(x):
        return x * n
    
    return multiply


double = multiplier(2)
triple = multiplier(3)

print(double(10))  # 20
print(triple(10))  # 30
```

Функция multiplier — это «фабрика»: она производит новые функции, каждая из которых «помнит» своё значение n. В итоге мы получаем double и triple — самостоятельные функции, которые можно передавать куда угодно и вызывать независимо друг от друга.

Типичные случаи:

- генерация валидаторов;
- создание конвертеров единиц;
- настройка обработчиков событий.

#### 2. Настройка callback-функций
Особенно часто встречается в GUI, веб-разработке и асинхронном коде.

```python
def make_handler(user_id):
    def handler(event):
        print(f"Пользователь {user_id}: {event}")
    
    return handler


handler_42 = make_handler(42)
handler_42("login")  # Пользователь 42: login
```

Замыкание позволяет привязать контекст к обработчику. Без замыкания пришлось бы передавать user_id в каждый вызов handler вручную — или хранить его в глобальной переменной. Используется в: GUI, asyncio, веб-серверах, системах событий.

### Как внутренняя функция запоминает то, что во внешней функции?

У каждой функции существует специальный атрибут `__closure__`, который можно вызвать с помощью конструкции:

```python
функция.__closure__
```

В обычных функциях он имеет значение `None`. Но если функция является замыкающей, то в атрибуте `__closure__` замыкающей функции будет храниться информация об объектах, которые она запомнила из внешней функции, в формате кортежа.

```python
def one(x, y):
    def two():
        return f"x = {x}, y = {y}"
    return two

perem = one(10, 20)
print(perem.__closure__)  
# (<cell at 0x00000194E6AC3AC0: int object at 0x00007FF8B8E3CAD8>, 
# <cell at 0x00000194E6AECF70: int object at 0x00007FF8B8E3CC18>)
```

В примере видно, что в замыкающей функции `perem`, хранятся два объекта типа данных `cell`. Нас сейчас не интересует этот тип данных (`cell`), давайте посмотрим как можно узнать, что именно хранит замыкающая функция. Чтобы это сделать, можно использовать следующую конструкцию:

```python
print([cell.cell_contents for cell in функция.__closure__])
```

В нашем случае весь код будет выглядеть вот так:

```python
def one(x, y):
    def two():
        return f"x = {x}, y = {y}"
    return two

perem = one(10, 20)
print([cell.cell_contents for cell in perem.__closure__])  # [10, 20]
```

Теперь мы видим, что функция `perem` хранит информацию о параметрах `x` и `y`. Но важно понимать, что в этом атрибуте хранятся лишь объекты из внешней функции, причём те, которые используются во внутренней функции:

```python
n = 1000
def one(x, y):
    m = 500
    w = 800
    def two():
        z = 200
        nonlocal w
        return x, y, z, m, n
    return two

perem = one(10, 20)
print([cell.cell_contents for cell in perem.__closure__])  # [500, 800, 10, 20]
```

Переменная `n` не относится к внешней функции, поэтому внутренняя функция не хранит информацию об `n` при замыкании в атрибуте `__closure__`. Все объекты из внешней функции, которые возвращает внутренняя, сохранятся в атрибуте `__closure__`. Если использовать `nonlocal`, то переменная из внешней функции также окажется в `__closure__`, в примере это переменная `w`.

По сути с помощью атрибута `__closure__` можно понять, что конкретно сохраняется в процессе замыкания, и что можно использовать для своих целей.

### Ключевые моменты

#### О замыканиях и вложенных функциях:
- Замыкание (closure) — это внутренняя функция, которая сохраняет доступ к данным внешней функции после её завершения.
- Имя функции в Python является обычной переменной и может быть присвоено другой переменной без копирования функции.
- Вложенная функция доступна только внутри внешней функции, если не вернуть её через return.
- При возврате внутренней функции создаётся функция-замыкание, которую можно вызывать вне внешней функции.

#### О механизме работы замыканий:
- Каждый вызов внешней функции создаёт новый объект внутренней функции в отдельной области памяти.
- Внутренняя функция имеет доступ к переменным внешней области видимости, включая параметры и локальные переменные.
- Атрибут __closure__ хранит ссылки только на те внешние переменные, которые реально используются внутренней функцией.
- Благодаря __closure__ каждая функция-замыкание «помнит» собственные значения переменных внешней функции.

#### Об изменении сохранённых данных:
- Для перепривязки переменных внешней функции внутри замыкания необходимо использовать ключевое слово nonlocal.
- Без nonlocal попытка присвоить новое значение внешней переменной приводит к ошибке UnboundLocalError.
- Изменяемые объекты (списки, словари и др.) можно изменять без nonlocal, если не выполняется перепривязка самой переменной.
- Важно различать изменение объекта и переприсваивание переменной — только второе требует nonlocal.

#### Практическое применение замыканий:
- Фабрики функций позволяют создавать специализированные функции, которые запоминают свои параметры.
- Callback-функции используют замыкания для хранения контекста (например, идентификатора пользователя или настроек обработчика).
- Замыкания помогают сохранять состояние между вызовами без использования глобальных переменных.
- Одно из самых важных применений замыканий — создание декораторов.

```python

Примите эти четыре числа и сохраните их в переменные (либо используйте другим способом). Первое число – это всегда количество денег в кассе на данный момент, а остальные числа – это операции с кассой (положительные числа – увеличивают деньги в кассе, отрицательные числа – уменьшают).

```python

def input_kassa(cash):

Например, функция берёт поступающее число (например, второе), если оно положительное то параметр `cash` увеличивается на это число (`number`), если отрицательное, то `cash` уменьшается на это число (`number`). Функция ничего не возвращает, она лишь изменяет параметр `cash`, поэтому правильно используйте параметр `cash`, чтобы изменить его.
- Функция `print_kassa()` не принимает аргументов и лишь выводит на экран значение параметра `cash`.

Функция `input_kassa()` будет возвращать функции `operation_with_kassa` и `print_kassa`. Используйте это знание, для решения задачи.

После создания функций, используйте знания темы "замыкания функций" и начните проводить операции с поступающими числами. Например:
