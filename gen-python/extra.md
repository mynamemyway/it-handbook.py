# Правила аннотации функций в Python

-   **Аннотация аргументов:** Тип указывается через двоеточие сразу после имени переменной: `аргумент: тип`.
-   **Значения по умолчанию:** Если у аргумента есть дефолтное значение, оно пишется через знак равенства строго ПОСЛЕ типа: `аргумент: тип = значение`.
-   **Возвращаемое значение:** Тип, который возвращает функция, указывается через стрелочку `->` после закрывающей круглой скобки, но ДО двоеточия: `def имя_функции(...) -> тип_выхода:`.

> **Примечание:** Если аргументы функции могут принимать абсолютно любые типы данных, их аннотацию можно полностью опустить, указав только тип возвращаемого значения через `-> тип_выхода:`.

### Пример кода:

```python
# Функция со всеми видами аннотаций и значением по умолчанию
def process_data(text: str, repeats: int = 1) -> str:
    return text * repeats


# Функция без аннотации аргументов (принимает любой тип), но с типом выхода
def get_length(any_data) -> int:
    return len(any_data)
```

### Функция `enumerate()` и ленивые вычисления

* **Суть**: Превращает итерируемый объект в ленивый итератор (генератор), который создаёт пары `(индекс, элемент)` на лету в момент запроса.
* **Зачем**: Позволяет получать индекс элемента в цикле `for` без ручного создания счетчиков (`i += 1`).
* **Память**: Сложность по памяти **O(1)**. Не копирует данные и не создает структуры в памяти до явного требования. На каждой итерации цикла существует ровно одна пара значений, которая сразу после использования стирается.
* **Распаковка**: Прямой `print(enumerate(x))` выведет адрес объекта в памяти. Для визуализации структуры нужно использовать `list(enumerate(x))`.

---

### Примеры использования

#### 1. Прямая распаковка в список (для отладки)
Если просто напечатать объект `enumerate`, мы увидим его технический адрес в памяти (объект-генератор):

```python
nums = ['99', '5', '85']
gen = enumerate(nums)

print(gen)
# Вывод: <enumerate object at 0x...>
```

Чтобы вытащить из него все данные, его нужно обернуть в `list()`, тогда получим список кортежей:
    
```py
print(list(gen)) 
# Вывод: [(0, '99'), (1, '5'), (2, '85')]
```

#### 2. Классический перебор в цикле `for`
В цикле пары значений автоматически распаковываются в две отдельные переменные `index` и `item`:

```python
passengers = ["Костя", "Ваня", "Катя"]

# enumerate() автоматически отдаёт и индекс, и значение
for index, name in enumerate(passengers):
    print(f"Пассажир № {index + 1} — это {name}")

# Вывод:
# Пассажир № 1 — это Костя
# Пассажир № 2 — это Ваня
# Пассажир № 3 — это Катя
```

### Бесконечность (Infinity) ♾️

#### Концепция

В Python нет отдельного ключевого слова для бесконечности, поэтому для её создания используется встроенный тип данных `float()`, в который передаётся строка `'inf'` (от английского *infinity*).

Бесконечность используется как **«маркер невозможности»** или стартовая заглушка при поиске минимума/максимума в алгоритмах.

#### Синтаксис и свойства

```python
# 1. Создание положительной и отрицательной бесконечности
INF = float('inf')   # Положительная бесконечность
MINF = float('-inf') # Отрицательная бесконечность

# 2. Как это выглядит при выводе на экран
print(INF)   # Выведет: inf
print(MINF)  # Выведет: -inf

# 3. Математические свойства (Любое число всегда меньше INF)
print(1000000 < INF)        # Выведет: True
print(-1000000 > MINF)      # Выведет: True
print(INF + 500 == INF)     # Выведет: True (Бесконечность нельзя увеличить)
```

#### Правило💡

*   Если алгоритм ищет **минимум** (`min`) — заполняй стартовые ячейки `float('inf')`. Любое первое найденное реальное число гарантированно перезапишет её.
*   Если алгоритм ищет **максимум** (`max`) — заполняй стартовые ячейки `float('-inf')` или просто нулями `0` (если числа строго положительные).
