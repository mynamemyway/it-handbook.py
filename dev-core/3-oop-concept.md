# Object-Oriented Programming (OOP)

## 1. Осознанный Python — Быстрый Старт в ООП

### 1.1 Создание класса и объекта

#### Что такое классы и объекты
-   **Класс** — шаблон или «чертёж», по которому создаются объекты. Описывает свойства и поведение.
    -   *Аналогия:* Чертёж автомобиля на заводе.
-   **Объект** — конкретный экземпляр класса, обладающий заложенными в классе свойствами и поведением.
    -   *Аналогия:* Конкретный автомобиль, собранный по чертежу.

![Автомобильный завод](/assets/images/oop/1.png)

#### Синтаксис создания класса
Для создания используется ключевое слово `class`, имя и двоеточие.

```python
class ИмяКласса:
    pass
```

![](/assets/images/oop/Video_2026-04-26_133628.gif)

-   `pass` — заглушка, если тело класса пока не определено.
-   Отступы внутри класса — строго 4 пробела.

#### Синтаксис создания объекта
Объект создается вызовом класса. Для использования его присваивают переменной.

```python
# Создание одного объекта
user = User()

# Создание нескольких объектов
user1 = User()
user2 = User()
user3 = User()
```

> Все объекты одного класса обладают одинаковым набором свойств и поведения, заложенным в шаблоне.

#### Стиль именования (PEP 8)

| Сущность | Стиль | Примеры (Хорошо) | Примеры (Плохо) |
| :--- | :--- | :--- | :--- |
| **Класс** | CapWords (PascalCase) | `UserManager`, `NetworkClient` | `User_Manager`, `network_client` |
| **Объект** | snake_case | `user_manager`, `network_client` | `UserManager`, `Network_Client` |

-   Имена классов и объектов пишутся в **единственном числе**.
-   В учебных целях допустимо использовать первую букву класса (`u = User()`), но в продакшене нужны описательные имена.

#### Оформление кода
-   Определение класса отделяется от остального кода **двумя пустыми строками**.
-   Несколько классов также разделяются **двумя пустыми строками**.

```python
class Person:
    pass


class User:
    pass


class BankAccount:
    pass
```

#### Ключевые выводы
1.  Класс — это шаблон, объект — экземпляр. Один класс порождает множество объектов.
2.  Класс объявляется через `class Name:`, объект создается вызовом `Name()`.
3.  Соблюдай нейминг: CapWords для классов, snake_case для объектов.
4.  Следуй PEP 8: 4 пробела отступа, 2 пустые строки вокруг определений классов.
