# Object-Oriented Programming (OOP)

## 0. Осознанный Python — Быстрый Старт в ООП

### 0.1 Создание класса и объекта

В этой статье разберём, что такое классы и объекты, и как они создаются.

#### Что такое классы и объекты

Класс — это шаблон или «чертёж», по которому создаются объекты. Объект — это конкретный экземпляр класса, обладающий свойствами и поведением, заложенными в классе. Чтобы было проще, представьте автомобильный завод:

- **Класс** — это чертёж автомобиля со всеми его характеристиками и инструкциями по сборке.
- **Объекты** — это конкретные автомобили, созданные по этому чертежу.

![Автомобильный завод](/assets/images/oop/1.png)

#### Как создать класс?

Для создания класса используется ключевое слово `class`, затем вы придумываете имя и ставите двоеточие.

```python
class ИмяКласса:
    pass
```

![](/assets/images/oop/Video_2026-04-26_133628.gif)

Обычно вместо `pass` размещают код, который описывает свойства и поведение объектов. Если вы пока не знаете, чем заполнить класс, можно использовать заглушку `pass`. Отступы стандартные — 4 пробела.

#### Как создать объект?

Чтобы создать объект необходимо вызвать класс:

```python
Класс()
```

Чтобы создать объект и присвоить его переменной:

```python
ссылка_на_объект = Класс()
```

В примере ниже `user` — это ссылка на объект класса `User`.

![](/assets/images/oop/Video_2026-06-07_024146.gif)

По сути, вызов класса создаёт объект (экземпляр) этого класса:

```python
class User:
    pass

User()  # Создали объект
```

Но чтобы пользоваться этим объектом, мы присваиваем его переменной:

```python
user = User()  # user – это переменная, которая хранит ссылку на объект User()
```

Можно создать сколько угодно объектов:

```python
user1 = User()  # user1 – ссылка на ПЕРВЫЙ созданный объект класса User
user2 = User()  # user2 – ссылка на ВТОРОЙ созданный объект класса User
user3 = User()  # user3 – ссылка на ТРЕТИЙ созданный объект класса User
...
```

И все объекты будут обладать свойствами и поведением, заложенным в классе.

#### Создание объектов без переменной

Если вы вызываете класс без присваивания переменной (`User()`):

   1. Python честно создает объект в памяти.
   2. Но так как вы не привязали к нему переменную, у вас нет способа обратиться к нему.
   3. Интерпретатор Python видит, что объект никому не нужен (0 ссылок), и Garbage Collector удаляет его из памяти.

Исключение:
*Иногда объекты создают без явной переменной, если их сразу передают «внутрь» чего-то другого (например, добавляют в список)*

#### Стиль именования
Классы именуются в стиле PascalCase (CapWords), а объекты — как обычные переменные (snake_case).

- **Стиль CapWords** — имя класса пишется слитно, и каждое слово начинается с заглавной буквы.
  Примеры имён классов: `UserManager`, `NetworkClient`, `CacheController`

- **Стиль snake_case** — все символы в нижнем регистре, для разделения слов используется нижнее подчёркивание.
  Примеры имён объектов: `user_manager`, `network_client`, `cache_controller`

Обычно имена классов и объектов создаются в единственном числе. Имена объектов нередко похожи на имена классов — это распространённая практика. Иногда в учебных целях используют первую букву класса в качестве имени объекта — это допустимо, но в реальных проектах лучше использовать описательные имена.

Например:

```python
class User:
    pass

user = User()  # user - хорошее имя
```

#### Отступы и разделители

PEP 8 рекомендует отделять определение класса от остального кода двумя пустыми строками.

![](/assets/images/oop/Video_2026-04-26_142224.gif)

Если нужно создать несколько классов, разделяйте их так же:

```python
class Person:
    pass


class User:
    pass


class BankAccount:
    pass
```

#### Ключевые выводы

**О классах и объектах:**
- Класс — это шаблон (чертёж), который описывает свойства и поведение будущих объектов.
- Объект — конкретный экземпляр класса, созданный на основе этого шаблона.
- Один класс может использоваться для создания любого количества объектов.

**Создание классов и объектов:**
- Класс создаётся с помощью ключевого слова `class` и двоеточия после имени класса.
- `pass` используется как временная заглушка, если тело класса ещё не определено.
- Объект создаётся вызовом класса: `ClassName()`.
- Для работы с объектом его обычно сохраняют в переменную: `object = ClassName()`

**Правила именования:**
- Классы именуются в стиле PascalCase (CapWords): `UserManager`, `NetworkClient`.
- Переменные (для объектов) именуются в стиле snake_case: `user_manager`, `network_client`.
- Имена классов и объектов обычно используются в единственном числе.
- Для реального кода предпочтительны понятные и описательные имена переменных.

**Оформление кода:**
- Отступы в теле класса выполняются четырьмя пробелами.
- Согласно PEP 8, определения классов отделяются от остального кода двумя пустыми строками.
- При объявлении нескольких классов их также следует разделять двумя пустыми строками.

### 0.2 Хитрости в создании объектов

Важно помнить, что объект создаётся путём вызова класса: `Класс()`. Например:

```python
class User:
    pass

User()  # Создали объект
```

Конечно, объект создастся, но его нельзя использовать в таком виде, поэтому мы присваиваем его переменной:

```python
class User:
    pass

u = User()  # Создали объект u
```

Теперь мы можем обращаться к объекту в любое время с помощью переменной `u`. Переменную `u` можно назвать объектом, но важно помнить, что это лишь переменная, **ссылающаяся на объект**, который хранится в памяти.

#### Объекты в коллекциях

Иногда несколько объектов создают внутри коллекции, например, в списке:

```python
class User:
    pass

objects = [User(), User(), User(), User(), User()]  # Создали 5 объектов
```

Здесь создано 5 объектов внутри списка. Каждый объект индивидуален, так как хранится в разных ячейках памяти. Чтобы пользоваться этими объектами, мы можем обратиться к ним по индексу или с помощью цикла `for`.

#### Что можно сделать уже сейчас?

В задачках могут попросить создать 3–5 и более объектов, поэтому вы можете сократить запись и использовать распаковку. Давайте рассмотрим несколько вариантов одной задачи: создать 3 объекта.

**Вариант 1. Обычный способ:**

```python
class User:
    pass

u1 = User()
u2 = User()
u3 = User()
```

**Вариант 2. Распаковка кортежа:**

```python
class User:
    pass

u1, u2, u3 = User(), User(), User()
```

Такой вид записи более лаконичный. Но если нам нужно создать 10 объектов, то такая запись будет громоздкой, поэтому можно использовать списковые включения (генераторы списков):

**Вариант 3. Списковые включения**

```python
class User:
    pass

u1, u2, u3, u4, u5, u6, u7, u8, u9, u10 = [User() for _ in range(10)]
```

Вот почему важно знать, что создание объекта — это вызов класса. Таким образом вы можете использовать базовые и продвинутые знания Python и создавать объекты тем способом, который подходит для конкретной ситуации.

**Вариант 4. Список из объектов**

Конечно, если у вас сотни объектов, то здесь уже нет смысла в распаковке, лучше хранить такие данные сразу в коллекции:

```python
class User:
    pass

objects = [User() for _ in range(100)]
```

**Вариант 5. Генераторные выражения:**

Если у вас тысячи объектов, то можно использовать генераторные выражения и создавать объекты по мере необходимости, не загружая всё в память сразу:

```python
class User:
    pass

objects = (User() for _ in range(1000))
```

#### Заключение

В этой главе мы поговорили о важности понимания, что создание объекта — это вызов класса: `Класс()`. В зависимости от задачи вы можете использовать базовые или продвинутые знания Python, чтобы создавать нужное количество объектов эффективным способом.

#### Ключевые моменты

**О создании объектов:**
- Объект создаётся вызовом класса: `Класс()`.
- Переменная хранит не сам объект, а **ссылку на объект** в памяти.

**Об объектах в коллекциях:**
- Список объектов позволяет хранить и обрабатывать несколько экземпляров одного класса.
- Каждый экземпляр класса является отдельным объектом и занимает свою область памяти.
- Доступ к объектам в коллекции осуществляется по индексу или через цикл.

**О способах создания нескольких объектов:**
- Распаковка кортежа позволяет компактно создать несколько объектов одной строкой.
- Списочное включение удобно для массового создания большого количества объектов.
- Понимание, что создание объекта — это вызов класса, позволяет использовать любые конструкции Python для генерации объектов.

**О выборе подходящего подхода:**
- Распаковка подходит для небольшого числа объектов.
- Список удобен для хранения десятков и сотен объектов.
- Генераторное выражение экономит память, создавая объекты только по мере необходимости.
- Способ создания объектов следует выбирать исходя из количества объектов и требований к памяти.

### 0.3 Атрибуты

Атрибуты – это данные (свойства). Существуют атрибуты класса и атрибуты объекта.

- **Атрибуты класса** – это общие данные для всех объектов, они хранятся внутри класса.
- **Атрибуты объекта** – это "личные" данные конкретного объекта, они хранятся внутри объекта.

Это можно представить как вещи. Есть вещи, которые общие для всех друзей, а есть личные вещи для конкретного человека.

![](/assets/images/oop/3.1.png)

#### Атрибуты класса

Атрибуты класса реализованы как переменные в теле класса:

```python
# Класс сотрудников
class Employee:
    uniform = "Деловой костюм"  # Атрибут класса
```

Здесь `uniform` – это атрибут класса. Теперь каждый объект может обратиться к этому атрибуту и получить информацию.

![](/assets/images/oop/Video_2026-06-07_222639_1.gif)

#### Обращение к атрибуту

Для обращения к атрибуту используется конструкция: `объект.атрибут`

```python
class Employee:
    uniform = "Деловой костюм"


# Создадим два объекта
e1 = Employee()
e2 = Employee()

# Обратимся к атрибуту
print(e1.uniform)  # Деловой костюм
print(e2.uniform)  # Деловой костюм
```

С помощью точки мы обращаемся к атрибуту. Так как атрибут класса общий для всех объектов, каждый объект может обратиться к нему.

#### Обращение через класс

К атрибутам класса можно обращаться как через объект, так и через класс:

```python
class Employee:
    uniform = "Деловой костюм"


e = Employee()
print(e.uniform)         # Деловой костюм
print(Employee.uniform)  # Деловой костюм
```

#### Алгоритм поиска атрибута

Здесь есть важный нюанс, на который стоит обратить внимание.

Когда вы обращаетесь к атрибуту через объект (экземпляр), Python сначала ищет его в самом объекте. Если не находит — идёт в класс, а затем поднимается по цепочке наследования.

Когда вы обращаетесь к атрибуту от имени класса, поиск начинается сразу в классе и также продолжается по наследованию. Если атрибут не найден нигде — возникнет ошибка.

```python
# Краткая последовательность поиска атрибута:
# объект.атрибут → ищем в объекте → ищем в классе → далее по наследованию → если нет, вызов ошибки
# Класс.атрибут → ищем в классе → далее по наследованию → если нет, вызов ошибки
```

#### Создание и изменение атрибута класса

Для создания и изменения атрибута класса используется одинаковая конструкция: `Класс.атрибут = значение`.

**Изменение атрибута класса**

Давайте изменим значение атрибута `uniform`. Для этого обратимся к атрибуту от имени класса и укажем новое значение:

```python
class Employee:
    uniform = "Деловой костюм"


Employee.uniform = "Пижама"     
print(Employee.uniform)  # Пижама
```

Теперь значение `uniform` изменено на "Пижама". С помощью точки мы обращаемся к атрибуту, а затем указываем значение.

**Создание нового атрибута класса**

Создание нового атрибута класса возможно двумя способами:

1. Указать атрибут в теле класса при его объявлении.

```python
class Employee:
    uniform = "Деловой костюм"
    store_opening_time = "9:00"


print(Employee.store_opening_time)  # 9:00
```

Указали `store_opening_time` сразу внутри класса.

2. Либо во время работы программы, использоваться конструкцию: `Класс.атрибут = значение`.

```python
class Employee:
    uniform = "Деловой костюм"    


Employee.store_opening_time = "9:00"  # Создали атрибут класса
print(Employee.store_opening_time)    # 9:00
```

Логика конструкции `Класс.атрибут = значение` такая: если атрибута нет — он создастся, если есть — изменится.

#### Атрибуты объекта

Каждый объект может иметь свои "личные" данные — атрибуты объекта. Для их создания используется конструкция: `объект.атрибут = значение`.

```python
class Employee:
    uniform = "Деловой костюм"    


e = Employee()
e.name = "Вася"  # Создали атрибут объекта
print(e.name)    # Вася
```

Обращаясь от имени объекта, мы создаём атрибут внутри объекта.

#### Хранилище __dict__

Существует специальный атрибут `__dict__` в котором хранятся атрибуты. У класса и объектов свои собственные хранилища. Это можно проверить, обратившись к `__dict__`.

```python
class Employee:
    uniform = "Деловой костюм"    


e1 = Employee()
e2 = Employee()

e1.name = "Вася"
e2.name = "Дима"

print(e1.__dict__)        # {'name': 'Вася'}
print(e2.__dict__)        # {'name': 'Дима'}
print(Employee.__dict__)  # {..., 'uniform ': 'Деловой костюм'}
```

У объектов `e1` и `e2` свой атрибут `name`, а в классе хранится различная информация и атрибут `uniform`. Атрибуты хранятся как в словарях в виде пар ключ-значение.

#### Изменение атрибута объекта

Для изменения используется та же конструкция: `объект.атрибут = значение`.

```python
class Employee:
    uniform = "Деловой костюм"    


e = Employee()
e.name = "Вася"      # Создали атрибут объекта
e.name = "Васяндра"  # Изменили атрибут объекта
print(e.name)        # Васяндра
```

Создание и изменение атрибута имеют одинаковую конструкцию — это удобно.

#### Заключение

Важно чтобы вы понимали, что существуют атрибуты класса и атрибуты объекта. Атрибуты класса – общие, обычно они создаются в момент создания класса. Например, одежда всех сотрудников, время открытия магазина и т.д. Нет смысла эти данные указывать в каждом объекте, лучше один раз указать в классе.

Атрибуты объекта – это личные данные каждого объекта. Например, имена сотрудников, их возраст, их должность и т.д. Такие данные лучше указывать внутри каждого объекта.

Создание и изменение атрибутов имеет одинаковую конструкцию. Но здесь важно обращаться от правильного имени (от класса или объекта).

#### Ключевые моменты

**Об атрибутах класса:**
- Атрибуты класса — это общие данные, доступные всем объектам класса.
- Атрибут класса объявляется в теле класса и хранится в единственном экземпляре для всех объектов.
- К атрибуту класса можно обращаться как через объект (`obj.attr`), так и через класс (`Class.attr`).
- Конструкция `Класс.атрибут = значение` используется и для создания нового атрибута класса, и для изменения существующего.
- Атрибуты хранятся в специальном хранилище `__dict__`, у каждого своё хранилище.

**Об атрибутах объекта:**
- Атрибуты объекта — это индивидуальные данные конкретного экземпляра класса.
- Атрибут объекта создаётся через конструкцию `объект.атрибут = значение`.
- К атрибуту объекта можно обращаться только через тот объект, в котором он создан.
- Конструкция `объект.атрибут = значение` одинаково используется для создания и изменения атрибута объекта.

**Правила поиска атрибутов:**
- При обращении через класс поиск выполняется только среди атрибутов класса.
- При обращении через объект поиск сначала выполняется в объекте, затем в классе.
- Если атрибут не найден ни в объекте, ни в классе, возникает ошибка.

**Когда использовать разные типы атрибутов:**
- Атрибуты класса подходят для данных, общих для всех объектов (например, форма сотрудников или время открытия магазина).
- Атрибуты объекта подходят для персональных характеристик объектов (например, имя, возраст, должность сотрудника).
- Важно правильно выбирать, от чьего имени обращаться к атрибуту — от класса или от объекта.
```
