# Object-Oriented Programming (OOP)

## 0. Осознанный Python — Быстрый Старт в ООП

### 0.1 Создание класса и объекта

В этой статье разберём, что такое классы и объекты, и как они создаются.

#### Что такое классы и объекты

Класс — это шаблон или «чертёж», по которому создаются объекты. Объект — это конкретный экземпляр класса, обладающий свойствами и поведением, заложенными в классе. Чтобы было проще, представьте автомобильный завод:

- **Класс** — это чертёж автомобиля со всеми его характеристиками и инструкциями по сборке.
- **Объекты** — это конкретные автомобили, созданные по этому чертежу.

![Автомобильный завод](/assets/images/oop/1.png)

#### Как создать класс?

Для создания класса используется ключевое слово `class`, затем вы придумываете имя и ставите двоеточие.

```python
class ИмяКласса:
    pass
```

![](/assets/images/oop/Video_2026-04-26_133628.gif)

Обычно вместо `pass` размещают код, который описывает свойства и поведение объектов. Если вы пока не знаете, чем заполнить класс, можно использовать заглушку `pass`. Отступы стандартные — 4 пробела.

#### Как создать объект?

Чтобы создать объект необходимо вызвать класс:

```python
Класс()
```

Чтобы создать объект и присвоить его переменной:

```python
ссылка_на_объект = Класс()
```

В примере ниже `user` — это ссылка на объект класса `User`.

![](/assets/images/oop/Video_2026-06-07_024146.gif)

По сути, вызов класса создаёт объект (экземпляр) этого класса:

```python
class User:
    pass

User()  # Создали объект
```

Но чтобы пользоваться этим объектом, мы присваиваем его переменной:

```python
user = User()  # user – это переменная, которая хранит ссылку на объект User()
```

Можно создать сколько угодно объектов:

```python
user1 = User()  # user1 – ссылка на ПЕРВЫЙ созданный объект класса User
user2 = User()  # user2 – ссылка на ВТОРОЙ созданный объект класса User
user3 = User()  # user3 – ссылка на ТРЕТИЙ созданный объект класса User
...
```

И все объекты будут обладать свойствами и поведением, заложенным в классе.

#### Создание объектов без переменной

Если вы вызываете класс без присваивания переменной (`User()`):

   1. Python честно создает объект в памяти.
   2. Но так как вы не привязали к нему переменную, у вас нет способа обратиться к нему.
   3. Интерпретатор Python видит, что объект никому не нужен (0 ссылок), и Garbage Collector удаляет его из памяти.

**Исключение**
*Иногда объекты создают без явной переменной, если их сразу передают «внутрь» чего-то другого (например, добавляют в список)*

#### 📝 Ссылочная модель памяти (Переменные и Объекты)

В Python любое имя (переменная) — это не объект / ячейка для него, а лишь ссылка на область в ОП.

*   **Анатомия одной строки `user = User()`**:
    Интерпретатор выполняет этот код строго **справа налево**:
    1.  `User()` — в памяти создается изолированный объект-экземпляр. У него свой уникальный адрес (ID).
    2.  `user = ...` — создается имя (переменная), в которую записывается **адрес (ссылка)** на этот объект.

*   **Создание нескольких объектов**:
    ```python
    user1 = User()  # user1 — ссылка на первый созданный объект в памяти
    user2 = User()  # user2 — ссылка на второй (другой) объект в памяти
    ```
    Каждая переменная получает адрес своего собственного, независимого экземпляра класса.

*   **Копирование ссылки**:
    ```python
    user1 = User()
    user2 = user1  # Скопировали ССЫЛКУ, а не сам объект
    ```
    В памяти находится всего **один объект**, но теперь на него указывают **две разные переменные** (`id(user1) == id(user2)`).

**Итог**: Объекты живут в памяти сами по себе, а переменные — это указатели, которые связывают код с объектами.

#### 1. Что такое ссылка?
Ссылка в Python — это 64-битное целое число, которое является адресом памяти (номером «ячейки»), где физически расположен сам объект.
Когда вы вызываете функцию id(user), Python показывает вам этот адрес (например, 140523094833216).

#### 2. Где всё это хранится в памяти?

* Куча (Heap): Это огромный склад, где хаотично разбросаны объекты (строки, списки, экземпляры классов.
* Стек (Stack): Это быстрая и упорядоченная структура данных. Здесь хранятся имена переменных и их значения — адреса-ссылки.

#### Как это выглядит на схеме памяти
Когда мы пишем код user = User(), в памяти компьютера происходит следующее:

```sheme
  СТЕК (Stack)                      КУЧА (Heap)
┌────────────────┐               ┌────────────────────────┐
│ Имя  │ Значение│               │ Адрес      │ Объект    │
├──────┼─────────┤               ├────────────┼───────────┤
│ user │ #001 ───┼──────────────►│ #001       │ [ User ]  │
└──────┴─────────┘               └────────────┴───────────┘
```

   1. В Куче создается объект User по адресу #001.
   2. В Стеке создается переменная с именем user.
   3. В значение переменной user записывается адрес #001.

#### Что происходит при user2 = user?

```sheme
  СТЕК (Stack)                      КУЧА (Heap)
┌────────────────┐               ┌────────────────────────┐
│ Имя   │Значение│               │ Адрес      │ Объект    │
├───────┼────────┤               ├────────────┼───────────┤
│ user  │ #001 ──┼──────────────►│ #001       │ [ User ]  │
│ user2 │ #001 ──┼───────────────┘            │           │
└───────┴────────┘               └────────────────────────┘
```

В Стеке создается еще одна строка с именем user2, и в нее копируется точно такое же число — адрес #001. Объект в Куче по-прежнему один.

**Итог**: Ссылка — это число (адрес в памяти).
Переменная и её ссылка хранятся в Стеке, а сам объект, на который она указывает — в Куче.

#### Стиль именования
Классы именуются в стиле PascalCase (CapWords), а объекты — как обычные переменные (snake_case).

- **Стиль CapWords** — имя класса пишется слитно, и каждое слово начинается с заглавной буквы.
  Примеры имён классов: `UserManager`, `NetworkClient`, `CacheController`

- **Стиль snake_case** — все символы в нижнем регистре, для разделения слов используется нижнее подчёркивание.
  Примеры имён объектов: `user_manager`, `network_client`, `cache_controller`

Обычно имена классов и объектов создаются в единственном числе. Имена объектов нередко похожи на имена классов — это распространённая практика. Иногда в учебных целях используют первую букву класса в качестве имени объекта — это допустимо, но в реальных проектах лучше использовать описательные имена.

Например:

```python
class User:
    pass

user = User()  # user - хорошее имя
```

#### Отступы и разделители

PEP 8 рекомендует отделять определение класса от остального кода двумя пустыми строками.

![](/assets/images/oop/Video_2026-04-26_142224.gif)

Если нужно создать несколько классов, разделяйте их так же:

```python
class Person:
    pass


class User:
    pass


class BankAccount:
    pass
```

#### Ключевые выводы

**О классах и объектах:**
- Класс — это шаблон (чертёж), который описывает свойства и поведение будущих объектов.
- Объект — конкретный экземпляр класса, созданный на основе этого шаблона.
- Один класс может использоваться для создания любого количества объектов.

**Создание классов и объектов:**
- Класс создаётся с помощью ключевого слова `class` и двоеточия после имени класса.
- `pass` используется как временная заглушка, если тело класса ещё не определено.
- Объект создаётся вызовом класса: `ClassName()`.
- Для работы с объектом его обычно сохраняют в переменную: `object = ClassName()`

**Правила именования:**
- Классы именуются в стиле PascalCase (CapWords): `UserManager`, `NetworkClient`.
- Переменные (для объектов) именуются в стиле snake_case: `user_manager`, `network_client`.
- Имена классов и объектов обычно используются в единственном числе.
- Для реального кода предпочтительны понятные и описательные имена переменных.

**Оформление кода:**
- Отступы в теле класса выполняются четырьмя пробелами.
- Согласно PEP 8, определения классов отделяются от остального кода двумя пустыми строками.
- При объявлении нескольких классов их также следует разделять двумя пустыми строками.

### 0.2 Хитрости в создании объектов

Важно помнить, что объект создаётся путём вызова класса: `Класс()`. Например:

```python
class User:
    pass

User()  # Создали объект
```

Конечно, объект создастся, но его нельзя использовать в таком виде, поэтому мы присваиваем его переменной:

```python
class User:
    pass

u = User()  # Создали объект u
```

Теперь мы можем обращаться к объекту в любое время с помощью переменной `u`. Переменную `u` можно назвать объектом, но важно помнить, что это лишь переменная, **ссылающаяся на объект**, который хранится в памяти.

#### Объекты в коллекциях

Иногда несколько объектов создают внутри коллекции, например, в списке:

```python
class User:
    pass

objects = [User(), User(), User(), User(), User()]  # Создали 5 объектов
```

Здесь создано 5 объектов внутри списка. Каждый объект индивидуален, так как хранится в разных ячейках памяти. Чтобы пользоваться этими объектами, мы можем обратиться к ним по индексу или с помощью цикла `for`.

#### Что можно сделать уже сейчас?

В задачках могут попросить создать 3–5 и более объектов, поэтому вы можете сократить запись и использовать распаковку. Давайте рассмотрим несколько вариантов одной задачи: создать 3 объекта.

**Вариант 1. Обычный способ:**

```python
class User:
    pass

u1 = User()
u2 = User()
u3 = User()
```

**Вариант 2. Распаковка кортежа:**

```python
class User:
    pass

u1, u2, u3 = User(), User(), User()
```

Такой вид записи более лаконичный. Но если нам нужно создать 10 объектов, то такая запись будет громоздкой, поэтому можно использовать списковые включения (генераторы списков):

**Вариант 3. Списковые включения**

```python
class User:
    pass

u1, u2, u3, u4, u5, u6, u7, u8, u9, u10 = [User() for _ in range(10)]
```

Вот почему важно знать, что создание объекта — это вызов класса. Таким образом вы можете использовать базовые и продвинутые знания Python и создавать объекты тем способом, который подходит для конкретной ситуации.

**Вариант 4. Список из объектов**

Конечно, если у вас сотни объектов, то здесь уже нет смысла в распаковке, лучше хранить такие данные сразу в коллекции:

```python
class User:
    pass

objects = [User() for _ in range(100)]
```

**Вариант 5. Генераторные выражения:**

Если у вас тысячи объектов, то можно использовать генераторные выражения и создавать объекты по мере необходимости, не загружая всё в память сразу:

```python
class User:
    pass

objects = (User() for _ in range(1000))
```

#### Заключение

В этой главе мы поговорили о важности понимания, что создание объекта — это вызов класса: `Класс()`. В зависимости от задачи вы можете использовать базовые или продвинутые знания Python, чтобы создавать нужное количество объектов эффективным способом.

#### Ключевые моменты

**О создании объектов:**
- Объект создаётся вызовом класса: `Класс()`.
- Переменная хранит не сам объект, а **ссылку на объект** в памяти.

**Об объектах в коллекциях:**
- Список объектов позволяет хранить и обрабатывать несколько экземпляров одного класса.
- Каждый экземпляр класса является отдельным объектом и занимает свою область памяти.
- Доступ к объектам в коллекции осуществляется по индексу или через цикл.

**О способах создания нескольких объектов:**
- Распаковка кортежа позволяет компактно создать несколько объектов одной строкой.
- Списочное включение удобно для массового создания большого количества объектов.
- Понимание, что создание объекта — это вызов класса, позволяет использовать любые конструкции Python для генерации объектов.

**О выборе подходящего подхода:**
- Распаковка подходит для небольшого числа объектов.
- Список удобен для хранения десятков и сотен объектов.
- Генераторное выражение экономит память, создавая объекты только по мере необходимости.
- Способ создания объектов следует выбирать исходя из количества объектов и требований к памяти.

### 0.3 Атрибуты

Атрибуты – это данные (свойства). Существуют атрибуты класса и атрибуты объекта.

- **Атрибуты класса** – это общие данные для всех объектов, они хранятся внутри класса.
- **Атрибуты объекта** – это "личные" данные конкретного объекта, они хранятся внутри объекта.

Это можно представить как вещи. Есть вещи, которые общие для всех друзей, а есть личные вещи для конкретного человека.

![](/assets/images/oop/3.1.png)

#### Атрибуты класса

Атрибуты класса реализованы как переменные в теле класса:

```python
# Класс сотрудников
class Employee:
    uniform = "Деловой костюм"  # Атрибут класса
```

Здесь `uniform` – это атрибут класса. Теперь каждый объект может обратиться к этому атрибуту и получить информацию.

![](/assets/images/oop/Video_2026-06-07_222639_1.gif)

#### Обращение к атрибуту

Для обращения к атрибуту используется конструкция: `объект.атрибут`

```python
class Employee:
    uniform = "Деловой костюм"


# Создадим два объекта
e1 = Employee()
e2 = Employee()

# Обратимся к атрибуту
print(e1.uniform)  # Деловой костюм
print(e2.uniform)  # Деловой костюм
```

С помощью точки мы обращаемся к атрибуту. Так как атрибут класса общий для всех объектов, каждый объект может обратиться к нему.

#### Обращение через класс

К атрибутам класса можно обращаться как через объект, так и через класс:

```python
class Employee:
    uniform = "Деловой костюм"


e = Employee()
print(e.uniform)         # Деловой костюм
print(Employee.uniform)  # Деловой костюм
```

#### Алгоритм поиска атрибута

Здесь есть важный нюанс, на который стоит обратить внимание.

Когда вы обращаетесь к атрибуту через объект (экземпляр), Python сначала ищет его в самом объекте. Если не находит — идёт в класс, а затем поднимается по цепочке наследования.

Когда вы обращаетесь к атрибуту от имени класса, поиск начинается сразу в классе и также продолжается по наследованию. Если атрибут не найден нигде — возникнет ошибка.

```python
# Краткая последовательность поиска атрибута:
# объект.атрибут → ищем в объекте → ищем в классе → далее по наследованию → если нет, вызов ошибки
# Класс.атрибут → ищем в классе → далее по наследованию → если нет, вызов ошибки
```

#### Создание и изменение атрибута класса

Для создания и изменения атрибута класса используется одинаковая конструкция: `Класс.атрибут = значение`.

**Изменение атрибута класса**

Давайте изменим значение атрибута `uniform`. Для этого обратимся к атрибуту от имени класса и укажем новое значение:

```python
class Employee:
    uniform = "Деловой костюм"


Employee.uniform = "Пижама"     
print(Employee.uniform)  # Пижама
```

Теперь значение `uniform` изменено на "Пижама". С помощью точки мы обращаемся к атрибуту, а затем указываем значение.

**Создание нового атрибута класса**

Создание нового атрибута класса возможно двумя способами:

1. Указать атрибут в теле класса при его объявлении.

```python
class Employee:
    uniform = "Деловой костюм"
    store_opening_time = "9:00"


print(Employee.store_opening_time)  # 9:00
```

Указали `store_opening_time` сразу внутри класса.

2. Либо во время работы программы, использоваться конструкцию: `Класс.атрибут = значение`.

```python
class Employee:
    uniform = "Деловой костюм"    


Employee.store_opening_time = "9:00"  # Создали атрибут класса
print(Employee.store_opening_time)    # 9:00
```

Логика конструкции `Класс.атрибут = значение` такая: если атрибута нет — он создастся, если есть — изменится.

#### Атрибуты объекта

Каждый объект может иметь свои "личные" данные — атрибуты объекта. Для их создания используется конструкция: `объект.атрибут = значение`.

```python
class Employee:
    uniform = "Деловой костюм"    


e = Employee()
e.name = "Вася"  # Создали атрибут объекта
print(e.name)    # Вася
```

Обращаясь от имени объекта, мы создаём атрибут внутри объекта.

#### Хранилище __dict__

Существует специальный атрибут `__dict__` в котором хранятся атрибуты. У класса и объектов свои собственные хранилища. Это можно проверить, обратившись к `__dict__`.

```python
class Employee:
    uniform = "Деловой костюм"    


e1 = Employee()
e2 = Employee()

e1.name = "Вася"
e2.name = "Дима"

print(e1.__dict__)        # {'name': 'Вася'}
print(e2.__dict__)        # {'name': 'Дима'}
print(Employee.__dict__)  # {..., 'uniform ': 'Деловой костюм'}
```

У объектов `e1` и `e2` свой атрибут `name`, а в классе хранится различная информация и атрибут `uniform`. Атрибуты хранятся как в словарях в виде пар ключ-значение.

#### Изменение атрибута объекта

Для изменения используется та же конструкция: `объект.атрибут = значение`.

```python
class Employee:
    uniform = "Деловой костюм"    


e = Employee()
e.name = "Вася"      # Создали атрибут объекта
e.name = "Васяндра"  # Изменили атрибут объекта
print(e.name)        # Васяндра
```

Создание и изменение атрибута имеют одинаковую конструкцию — это удобно.

#### Заключение

Важно чтобы вы понимали, что существуют атрибуты класса и атрибуты объекта. Атрибуты класса – общие, обычно они создаются в момент создания класса. Например, одежда всех сотрудников, время открытия магазина и т.д. Нет смысла эти данные указывать в каждом объекте, лучше один раз указать в классе.

Атрибуты объекта – это личные данные каждого объекта. Например, имена сотрудников, их возраст, их должность и т.д. Такие данные лучше указывать внутри каждого объекта.

Создание и изменение атрибутов имеет одинаковую конструкцию. Но здесь важно обращаться от правильного имени (от класса или объекта).

#### Ключевые моменты

**Об атрибутах класса:**
- Атрибуты класса — это общие данные, доступные всем объектам класса.
- Атрибут класса объявляется в теле класса и хранится в единственном экземпляре для всех объектов.
- К атрибуту класса можно обращаться как через объект (`obj.attr`), так и через класс (`Class.attr`).
- Конструкция `Класс.атрибут = значение` используется и для создания нового атрибута класса, и для изменения существующего.
- Атрибуты хранятся в специальном хранилище `__dict__`, у каждого своё хранилище.

**Об атрибутах объекта:**
- Атрибуты объекта — это индивидуальные данные конкретного экземпляра класса.
- Атрибут объекта создаётся через конструкцию `объект.атрибут = значение`.
- К атрибуту объекта можно обращаться только через тот объект, в котором он создан.
- Конструкция `объект.атрибут = значение` одинаково используется для создания и изменения атрибута объекта.

**Правила поиска атрибутов:**
- При обращении через класс поиск выполняется только среди атрибутов класса.
- При обращении через объект поиск сначала выполняется в объекте, затем в классе.
- Если атрибут не найден ни в объекте, ни в классе, возникает ошибка.

**Когда использовать разные типы атрибутов:**
- Атрибуты класса подходят для данных, общих для всех объектов (например, форма сотрудников или время открытия магазина).
- Атрибуты объекта подходят для персональных характеристик объектов (например, имя, возраст, должность сотрудника).
- Важно правильно выбирать, от чьего имени обращаться к атрибуту — от класса или от объекта.

### 0.4 Метод __init__

Слово `init` – это сокращение от слова «initialization» («инициализация»). В этой статье мы поговорим об инициализации объектов с помощью `__init__`.

#### Что такое __init__?

`__init__` – это специальный метод, который вызывается автоматически сразу после создания объекта для его начальной настройки. С помощью него удобно задавать атрибуты объектам прямо в момент их появления.

#### Создание __init__ в классе

Методы – это функции класса, поэтому они создаются с помощью ключевого слова `def`.

```python
class User:
    def __init__(self):
        pass
```

В `__init__` есть обязательный параметр `self`, который всегда указывается первым. Помимо `self` в `__init__` часто указывают и другие параметры. Первый параметр в методе объекта имеет особое поведение — в него автоматически передаётся ссылка на объект, об этом мы ещё поговорим.

#### 📝 Типы данных - это классы, Методы – это функции класса

В Python абсолютно все встроенные структуры данных (списки, строки, словари) под капотом спроектированы по тем же правилам ООП.

*   **Класс-тип данных**: `list`, `str`, `dict` и т.д. — это классы, прописанные в исходном коде Python.
*   **Методы под капотом**: Функции вроде `.append()`, `.split()` или `.keys()` — это методы, объявленные внутри этих классов с обязательным первым параметром `self`.
*   **Механика вызова**: Когда мы вызываем метод у конкретного списка:
    ```python
    my_list = [1, 2, 3]  # Создали объект-экземпляр класса list
    my_list.append(4)    # Вызываем метод .append()
    ```
    Интерпретатор под капотом превращает это в вызов функции класса, передавая туда ссылку на наш объект в качестве `self`:
    ```python
    list.append(my_list, 4)
    ```

**Итог**: Правила работы с методами и объектами одинаковы как для системного класса `list`, так и для любого кастомного класса (например, `User`).

#### Как используют __init__?

Чаще всего `__init__` используют для инициализации, то есть для начальной настройки объектов в момент их создания. Раньше мы создавали атрибуты после создания объектов, но с помощью `__init__` можно делать это сразу в момент создания объекта.

Например:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age


user = User("Михаил", 30)
```

![](/assets/images/oop/Video_2026-06-08_175757_4.gif)

Давайте подробно разберём, как это работает.

**Создание объекта и автоматический вызов __init__**

Выполняется `user = User("Михаил", 30)`. Создаётся объект `user` и автоматически вызывается `__init__`. Его вызов можно представить так:

```python
User.__init__(user, "Михаил", 30)
```

В этот момент `user` уже является объектом. В параметры передаются аргументы: `self=user`, `name="Михаил"`, `age=30`.

**Создание атрибутов внутри __init__**

Напомню, что конструкция `объект.атрибут = значение` создаёт атрибуты. Внутри `__init__` происходит следующее:

```python
self.name = name
self.age = age
```

Так как `self` – это объект `user`, то код можно представить как:

```python
user.name = name
user.age = age
```

Другими словами, в `__init__` создаются атрибуты `name` и `age` конкретно для объекта `user`.

**Почему мы передаём 2 аргумента, а не 3?**

В момент вызова `User` мы передаём аргументы во все параметры кроме `self`, так как в `self` автоматически передаётся объект. Поэтому только два аргумента.

![](/assets/images/oop/4.1.png)

#### Другой пример для закрепления

```python
class Person:
    def __init__(self, h, w, c):
        self.hobby = h
        self.work = w
        self.car = c


p = Person("Gaming", "IT", "Toyota")
print(p.hobby)  # Gaming
print(p.work)   # IT
print(p.car)    # Toyota
```

Обычно параметры в `__init__` называют так же, как называют сами атрибуты. Но иногда одинаковые имена атрибутов и параметров путают начинающих, поэтому здесь параметры намеренно названы по-другому, чтобы было легче понять пример.

Здесь:
- в `__init__` объявляем параметры (`self`, `h`, `w`, `c`).
- В теле `__init__` создаются три атрибута: `hobby`, `work`, `car` со значениями `h`, `w`, `c`.
- В момент создания объекта `p` передаём 3 аргумента: `"Gaming"`, `"IT"`, `"Toyota"`, которые присвоятся в параметры `__init__` позиционным способом.

Таким образом создаются объект и 3 атрибута.

#### 📝 Хранение атрибутов: без `__init__` vs с `__init__`

В Python важно разделять, где физически хранятся данные — в классе или в его экземпляре.

*   **Без `__init__` (Атрибуты класса)**:
    ```python
    class Employee:
        uniform = "Костюм"  # Хранится в КЛАССЕ
    ```
    *   **Механика**: Свойство создается в единственном экземпляре внутри самого класса.
    *   **Память**: Объекты (`e1`, `e2`) не хранят это свойство в себе. При вызове `e1.uniform` Python берет значение из общего класса.

*   **С `__init__` (Атрибуты объекта/экземпляра)**:
    ```python
    class Employee:
        def __init__(self, name):
            self.name = name  # Хранится в ОБЪЕКТЕ
    ```
    *   **Механика**: Конструктор через `self` записывает данные внутрь объекта в момент его инициации.
    *   **Память**: Каждый объект хранит свои изолированные данные внутри.

**Итог**:
- Атрибуты класса — общие для всех и лежат в классе.
- Атрибуты из `__init__` — индивидуальные для каждого объекта и лежат в самом объекте.

#### Виды параметров __init__

`__init__`, как и любая функция, может иметь любые параметры:

- Позиционные
- Именованные
- Позиционные переменного типа (`*args`)
- Именованные переменного типа (`**kwargs`)

Это значит, что способ передачи данных при создании объекта можно гибко настраивать под конкретную задачу.

**Пример с именованными параметрами (значения по умолчанию):**

```python
class Person:
    def __init__(self, name="Unknown", age=0):
        self.name = name
        self.age = age


p1 = Person()
p2 = Person("Вася", 21)

print(p1.name)
print(p2.name)
```

Здесь мы использовали параметры со значениями по умолчанию. При создании объекта мы можем указывать аргументы, а можем и не указывать, так как уже есть значения по умолчанию. Это удобно, когда часть данных необязательна: объект создастся даже без аргументов, а не выдаст ошибку.

**Пример с *args:**

```python
class Person:
    def __init__(self, *args):
        self.data = args


p = Person("Вася", 21)
print(p.data)  # ('Вася', 21)
```

`*args` позволяет передать любое количество позиционных аргументов — они автоматически собираются в кортеж и сохраняются в `self.data`. Это полезно, когда заранее неизвестно, сколько значений получит объект.

**Пример с **kwargs:**

```python
class Person:
    def __init__(self, **kwargs):
        self.data = kwargs


p = Person(name="Вася", age=21)
print(p.data)  # {'name': 'Вася', 'age': 21}
```

`**kwargs` работает похожим образом, но для именованных аргументов: все переданные пары ключ=значение собираются в словарь. В отличие от `*args`, здесь у каждого значения есть имя, что упрощает дальнейшую работу с данными внутри класса.

#### 📝 Извлечение данных из `**kwargs` в конструкторе

При передаче именованных аргументов через `**kwargs` внутри класса они упаковываются в обычный словарь. Ключи этого словаря всегда являются строками.

*   **Прямое извлечение (обязательные ключи)**:
    Выполняется по строковому ключу в кавычках. Если ключ не передан, вызовется ошибка `KeyError`.
    ```python
    self.name = kwargs['name']
    ```
*   **Безопасное извлечение с дефолтным значением**:
    Метод `.get()` позволяет задать значение по умолчанию, если аргумент не был передан при создании объекта.
    ```python
    self.str = kwargs.get('str', 'Атрибут не передан при инициации')
    ```

**Пример реализации**:
```python
class SomeClass:
    def __init__(self, **kwargs):
        self.name = kwargs['name']
        self.age = kwargs['age']
        self.str = kwargs.get('str', 'Атрибут не передан при инициации')

s = SomeClass(name=1, age=2)
print(s.__dict__) 
# Выведет: {'name': 1, 'age': 2, 'str': 'Атрибут не передан при инициации'}
```

#### Частые вопросы про __init__

**Нужно ли всегда использовать __init__?**
Нет. Если объекту не нужны начальные атрибуты или настройка, класс может существовать без `__init__`.

**Может ли __init__ что-то возвращать?**
Нет. Метод `__init__` не должен возвращать значение. Если попытаться вернуть не `None`, возникнет ошибка:

```python
class Person:
    def __init__(self):
        return 10  # TypeError: __init__() should return None (not 'int')
```

Единственное допустимое возвращаемое значение — `None` (явное или неявное).

**Где размещают __init__?**
При создании `__init__` является хорошей практикой размещать его выше остальных методов в классе (то есть в самом верху тела класса). Если есть атрибуты класса, `__init__` и другие методы, то обычно указывают атрибуты класса, затем `__init__` и другие методы.

```python
class Person:
    attr = None

    def __init__(self, name, age):
        self.name = name
        self.age = age
```

**Как ещё называют __init__?**
`__init__` часто называют конструктором, но есть нюанс. На самом деле `__init__` не создаёт объект, он лишь инициализирует (настраивает) уже созданный объект. Но если вы услышите слово «конструктор», то часто имеют в виду именно `__init__`.

Ещё методы с двумя подчёркиваниями в начале и в конце называют dunder-методами (от англ. double underscore — двойное подчёркивание). В российском сегменте их часто называют «волшебными» или «магическими» методами. Поэтому `__init__` — магический метод.

`self` — это **имя первого параметра** в методах объекта.
Фактически, можно использовать любое имя и код будет работать корректно:

```python
class Person:
    def __init__(котик, name, age):
        котик.name = name
        котик.age = age


user = Person("Вася", 21)
print(user.name)  # Вася
print(user.age)   # 21
```

Здесь мы используем имя `котик` вместо `self`, и всё работает. Но программистами принято называть первый параметр `self`.

#### Ключевые моменты

**О назначении и работе __init__:**
- `__init__` — специальный метод, который автоматически вызывается сразу после создания объекта.
- Инициализация объекта позволяет задавать атрибуты и выполнять начальную настройку в момент создания экземпляра класса.
- `self` всегда является первым параметром метода и автоматически получает ссылку на текущий объект.

**О создании атрибутов и передаче аргументов:**
- Атрибуты объекта обычно создаются внутри `__init__` через присваивание вида `self.атрибут = значение`.
- Аргументы конструктора передаются во все параметры, кроме `self`, так как он заполняется автоматически.

**О параметрах __init__:**
- Параметры `__init__` могут быть позиционными, именованными, а также использовать `*args` и `**kwargs`.

**О важных особенностях __init__:**
- Метод `__init__` не обязан присутствовать в каждом классе.
- Возвращаемое значение метода `__init__` всегда только `None`; возврат других значений вызывает ошибку.
- `__init__` принято размещать в начале класса после атрибутов класса.
- Конструктор — распространённое название `__init__`.
- Dunder-метод («волшебный / магический метод») — ещё одно название методов с двойными подчёркиваниями, к которым относится `__init__`.

### 0.5 Чуть больше о __init__

В этой статье мы поговорим на три темы:

- Вычисления в `__init__`.
- Как правильно понимать задачки на Stepik.
- Частые ошибки начинающих.

#### Вычисления в __init__

На практике `__init__` редко ограничивается простым присваиванием параметров атрибутам. Часто в нём выполняются небольшие вычисления, подготовка данных или создание дополнительных атрибутов. При этом важно помнить правило: `__init__` обычно выполняет инициализацию объекта, а не сложную бизнес-логику.

Например:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height
        self.area = width * height
```

Атрибуты `width` (ширина) и `height` (высота) берут значения из параметров напрямую, а `area` (площадь) вычисляется на основе параметров. Примеры могут быть различными, поэтому для новичков полезно придерживаться такого правила:

**Что хорошо в __init__:**
- Создавать атрибуты с помощью параметров;
- Выполнять простые вычисления;
- Создавать дополнительные атрибуты;
- Приводить данные к нужному виду.

**Что нежелательно:**
- Выполнять очень долгие вычисления;
- Загружать большие объёмы данных;
- Делать сложную бизнес-логику;
- Писать код, который может долго блокировать создание объекта.

#### Как правильно понимать задачки на Stepik

**Пример 1**

> Определите `__init__` в классе, который создаёт два атрибута: `name` и `age` с соответствующими значениями параметров.

Определить (define) — значит создать метод в классе. От нас требуется создать `__init__`, в котором будут создаваться атрибуты `name` и `age`. Имена параметров часто соответствуют именам будущих атрибутов, поэтому и говорится присвоить соответствующие имена параметров. Решение выглядит так:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

Создаётся атрибут `name` со значением параметра `name`. Точно также с атрибутом `age`.

**Пример 2**

> Создайте объект `user` и передайте при инициализации имя и возраст в качестве аргументов.

Если в классе определён `__init__`, он вызывается автоматически при каждом создании объекта. А раз `__init__` вызывается, нужно передать аргументы, если этого требует его сигнатура. Решение выглядит так:

```python
user = User("Вася", 21)
```

Передали имя и возраст в качестве аргументов при создании объекта.

**Пример 3**

> Определите `__init__` в классе, который создаёт два атрибута: `name` и `age` с соответствующими значениями параметров. Параметры `name` и `age` имеют значения по умолчанию `None`.

Здесь всё то же самое, только у параметров значения по умолчанию — `None`:

```python
class User:
    def __init__(self, name=None, age=None):
        self.name = name
        self.age = age
```

Так как у параметров есть значения по умолчанию, аргументы при создании объекта можно не передавать. Или передавать только те, которые нужны. Например:

```python
class User:
    def __init__(self, name=None, age=None):
        self.name = name
        self.age = age


user1 = User()
user2 = User("Вася")
user3 = User("Вася", 21)
user4 = User(age=21)
```

#### Частые ошибки начинающих

Давайте разберём несколько ситуаций, в которых у новичков часто возникают ошибки.

**1. Забывают self**

```python
def __init__(name):
    pass
```

Первым параметром должен быть `self`. Правильный вариант:

```python
def __init__(self, name):
    pass
```

**2. Не используют self внутри метода для создания атрибута**

```python
def __init__(self, name):
    name = name
```

Эта запись не вызовет ошибку, но и атрибут создан не будет: Python просто присвоит параметр `name` самому себе как локальную переменную. Объект не получит никакого атрибута `name`.

Для создания атрибута необходима конструкция:

```python
объект.атрибут = значение
```

Внутри метода это делается с помощью `self`. Правильный вариант:

```python
def __init__(self, name):
    self.name = name
```

**3. Передано неверное количество аргументов**

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age


user = User()        # Не переданы аргументы name и age
user = User("Вася")  # Передан только аргумент name
```

Если `__init__` ожидает обязательные аргументы, а вы их не передали — возникнет ошибка. Правильный вариант:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age


user = User("Вася", 21)
```

#### Заключение

В этой статье мы разобрали ситуации, которые могут встретиться в задачках на тему: `__init__`. А также рассмотрели часто встречающиеся ошибки.

#### Ключевые моменты

**По методу __init__ и атрибутам объекта:**
- `__init__` автоматически вызывается при создании объекта и задаёт его начальное состояние.
- `self` — ссылка на текущий объект; через него создаются атрибуты объекта.
- Конструкция `self.name = name` создаёт атрибут объекта и присваивает ему значение параметра.
- Имена параметров и атрибутов часто делают одинаковыми: `name` — параметр, а `self.name` — атрибут объекта.

**По созданию объектов и аргументам:**
- При создании объекта нужно передавать все обязательные аргументы, которые указаны в `__init__`.
- Если у параметров есть значения по умолчанию, например `None`, аргументы можно не передавать.
- Позиционные аргументы передаются по порядку, а именованные аргументы — по имени параметра.
- Именованные аргументы позволяют передавать параметры в любом порядке и пропускать необязательные значения.

**Частые ошибки новичков:**
- В методе `__init__` первым параметром обязательно должен быть `self`.
- Запись `name = name` не создаёт атрибут объекта — нужен именно `self.name = name`.
- Если передать неверное количество аргументов при создании объекта, Python выдаст ошибку.
- Атрибуты объекта создаются через конструкцию `self.атрибут = значение`.

### 0.6 Методы объектов

Существуют различные виды методов, но в этом курсе мы изучим только «методы объектов», так как они чаще всего встречаются в реальной практике. Если вы хорошо знаете функции, то тема методов будет для вас простой.

#### Создание методов

Методы — это функции, размещённые в теле класса, и для создания метода используется ключевое слово `def`. Методы объектов созданы для работы с объектами, поэтому у них есть обязательный первый параметр `self` (как в `__init__`).

```python
class User:
    def greet(self):
        print("Приветствую!")
```

#### Вызов метода объекта

Методы объекта принято вызывать от имени объекта, обращаясь к нему через точку:

```python
class User:
    def greet(self):
        print("Приветствую!")


u = User()
u.greet()  # Приветствую
```

Существует два способа вызова метода:
1. Через объект.
2. Через класс, где объект передаётся в `self` вручную.

Чаще всего к методам объекта обращаются через объект:

```python
class User:
    def greet(self):
        print("Приветствую!")


u = User()
u.greet()  # Приветствую
```

Если обращаться через класс, нужно сначала создать объект, а затем передать его вручную в параметр `self`:

```python
User.greet(u)  # Приветствую!
```

Такой вариант менее удобный, но он существует.

#### 📝 Вызов методов изнутри конструктора __init__

Хотя методы класса по умолчанию остаются «спящими» при создании объекта, их можно запустить в цепочке внутри конструктора.

*   **Механика вызова**: Любой метод класса можно вызвать внутри `__init__`, обратившись к нему через `self.имя_метода()`.
*   **Результат**: Так как `__init__` запускается автоматически, вызванный из него метод также выполнится в момент создания экземпляра (`User()`), без необходимости ручного вызова в основном коде.

**Итог**: Цепочка вызовов через `self` внутри `__init__` — стандартный способ автоматического запуска логики (например, загрузки данных или проверки прав) при рождении объекта.

#### Параметр self

В методах объекта первым параметром всегда указывается `self`. Как и в методе `__init__`, в него автоматически передаётся объект, который вызывает метод. Это легко проверить:

```python
class User:
    def greet(self):
        print(self is u)  # Проверяем self - это объект u?


u = User()
u.greet()  # True
```

В теле метода мы проверяем, является ли `self` объектом `u`. В итоге получаем `True`, что подтверждает: в `self` передаётся объект, вызывающий метод.

**self = объект:**
Запомните, в `self` передаётся объект, который вызывает метод и в этом заключается гениальность `self`.

```python
class User:
    def greet(self):
        pass


u1, u2, u3 = User(), User(), User()

u1.greet()  # self = u1
u2.greet()  # self = u2
u3.greet()  # self = u3
```

У каждого объекта могут быть свои личные данные (атрибуты). Вызывая метод, мы можем использовать данные конкретного объекта и это гениальное решение.

#### Примеры использования методов

Методы — это функции, поэтому они могут иметь все виды параметров (позиционные, именованные и т.д.). Как и функции, методы могут что-то возвращать (использовать `return`), либо выполнять действия: изменять, создавать, проверять и т.д.

**Пример. Создание атрибута с помощью метода:**

```python
class User:
    def create_name(self, name):
        self.name = name  # Создали атрибут name


u = User()
u.create_name("Вася")
print(u.name)  # Вася
```

Метод `create_name` имеет параметр `self` и `name`. В теле метода создаётся атрибут `name`. Обращаясь к методу мы передаём лишь один аргумент `"Вася"`, который присвоится в параметр `name`. В итоге, в объекте появился атрибут `name` со значением `"Вася"`. Конечно, мы могли это сделать с помощью `__init__`, рассматривайте это просто как пример.

**Пример. Валидация (проверка данных):**

```python
class User:
    def __init__(self, age):
        self.age = age

    def check_age(self):
        if self.age >= 14:
            print("Вам 14 или больше")
        else:
            print("Вам меньше 14")


u1 = User(21)
u2 = User(13)

u1.check_age()  # Вам 14 или больше
u2.check_age()  # Вам меньше 14
```

При создании объектов `u1`, `u2` создаются данные о возрасте с помощью атрибута `age` (в `__init__`). Далее мы вызываем метод `check_age` от имени разных объектов, и в нём происходит проверка атрибута `age`. Здесь хорошо раскрывается роль `self`: обращение к `age` внутри метода происходит от разных объектов, поэтому мы получаем разный результат.

**Пример. Вычисление данных**

```python
class Product:
    def __init__(self, quantity, price):
        self.quantity = quantity
        self.price = price

    def get_total(self):
        return self.quantity * self.price


p1 = Product(200, 5)
p2 = Product(100, 5)

print(p1.get_total())  # 1000
print(p2.get_total())  # 500
```

Создаём объекты с атрибутами `quantity` (количество) и `price` (цена). У каждого объекта это будут свои личные атрибуты. Метод `get_total` возвращает стоимость всей покупки, используя атрибуты объекта. Выводим результат и видим, что у каждого объекта он разный.

#### Расположение методов

Методы обычно располагаются после атрибутов класса и `__init__`, если они присутствуют в классе. Принято отделять методы от другого кода одной пустой строкой — так код становится более читаемым.

Примеры:

```python
class Product:
    attr = None

    def method(self):
        pass
```

```python
class Product:
    def __init__(self):
        pass

    def method(self):
        pass
```

```python
class Product:
    def method1(self):
        pass

    def method2(self):
        pass
```

#### Распространённые ошибки

Давайте кратко рассмотрим самые распространённые ошибки начинающих:

**1. Забыли указать self в определении метода:**

```python
class User:
    def greet():
        print("Привет")


u = User()
u.greet()  # Ошибка
```

При вызове метода через объект Python автоматически передаёт экземпляр как первый аргумент, но `self` отсутствует, поэтому возникает ошибка.

**2. Забыли использовать self при обращении к атрибуту:**

```python
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print(name)   # ошибка, правильно: print(self.name)
```

`print(name)` ищет `name` в глобальной области. В методах нужно явно указывать где искать атрибут. Правильно будет использовать `self.name`, если вы обращаетесь к атрибуту объекта.

**3. Забыли вызвать метод:**

```python
class User:
    def greet(self):
        print("Привет")


u = User()
u.greet  # Забыли вызвать метод, правильно: u.greet()
```

Ошибки не произойдёт, но и метод вызван не будет. Для вызова метода используют скобки.

**4. Неверное количество аргументов:**

```python
class User:
    def print_some(self, a, b, c):
        print(a, b, c)


u = User()
u.print_some()            # Ожидается 3 аргумента, передано 0
u.print_some(1, 2)        # Ожидается 3 аргумента, передано 2
u.print_some(1, 2, 3, 4)  # Ожидается 3 аргумента, передано 4
```

Как и в функциях, необходимо передавать нужное количество аргументов. Но помните, что в `self` мы ничего не передаём, смотрим только на другие параметры.

#### Заключение

В этой статье мы разобрали, что такое методы объектов в Python, как они создаются и используются для работы с данными конкретного экземпляра класса. Теперь мы знаем, что методы являются функциями внутри класса и всегда принимают первым параметром `self`, через который получают доступ к объекту.

Мы научились вызывать методы, использовать их для создания и проверки атрибутов, выполнения вычислений и возврата результатов. Также мы рассмотрели распространённые ошибки при работе с методами и способы их избежать. Эти знания пригодятся при разработке собственных классов и объектов, когда потребуется организовать удобную и логичную работу с данными программы.

#### Ключевые моменты

**О методах объектов:**
- Метод объекта — это функция, объявленная внутри класса с помощью `def`.
- Первый параметр метода всегда `self`, через него метод получает доступ к объекту.
- Методы обычно вызываются через объект: `obj.method()`.
- Вызов через класс возможен, но требует вручную передать объект в `self`: `Class.method(obj)`.

**О параметре self:**
- `self` содержит ссылку на объект, который вызвал метод.
- Благодаря `self` один и тот же метод работает с данными разных объектов.
- Для доступа к атрибутам объекта внутри метода используется запись `self.атрибут`.
- Через `self` можно создавать, изменять и использовать атрибуты конкретного экземпляра класса.

**Применение методов:**
- Методы могут принимать любые параметры, как обычные функции.
- Методы могут возвращать результат через `return`.
- Методы используются для создания атрибутов, проверки данных, выполнения вычислений и других операций над объектом.
- Результат работы метода зависит от значений атрибутов конкретного объекта.

**Типичные ошибки:**
- Отсутствие `self` в определении метода вызывает ошибку при вызове через объект.
- При обращении к атрибуту внутри метода нужно использовать `self.атрибут`, а не просто имя атрибута.
- Для выполнения метода обязательны скобки: `method()`.
- Количество передаваемых аргументов должно соответствовать параметрам метода; `self` передаётся автоматически.

### 0.7 Наследование

Наследование — механизм ООП, позволяющий создавать новый класс на основе существующего.

#### Зачем нужно наследование?

Когда мы создаём классы, часто оказывается, что разные объекты имеют много общего. Например, у собаки есть имя и возраст. У кошки тоже есть имя и возраст. У попугая — опять имя и возраст. Если для каждого класса отдельно описывать одинаковые атрибуты и методы, код начнёт повторяться.

![](/assets/images/oop/7.1.png)

Именно для решения этой проблемы в объектно-ориентированном программировании существует наследование. Наследование позволяет создать один класс, например `Animal` (Животное), разместить в нём общие свойства и поведение, а другие классы получают доступ к этим возможностям через наследование.

![](/assets/images/oop/7.2.jpg)

#### Создание наследования

Наследование создаётся указанием родительского класса в скобках:

```python
class Animal:  # Родительский
    pass


class Dog(Animal):  # Дочерний
    pass
```

Класс `Dog` наследуется от `Animal` — это указывается с помощью скобок `Dog(Animal)`.

Запомните термины:
- `Animal` — родительский класс.
- `Dog` — дочерний класс.

Дочерних классов может быть несколько:

```python
class Animal:  # Родительский
    pass


class Dog(Animal):  # Дочерний
    pass


class Cat(Animal):  # Дочерний
    pass

...
```

#### Атрибуты и методы в наследовании

Наследование позволяет создать общие атрибуты и методы в родительском классе:

```python
# Родительский класс
class Animal:  
    species = "animal"

    def eat(self):
        print("Ест")


# Дочерний класс
class Dog(Animal):
    pass


# Дочерний класс
class Cat(Animal):
    pass
```

Теперь объекты `Dog` и `Cat` могут пользоваться атрибутами и методами родительского класса `Animal`:

```python
dog = Dog()
cat = Cat()

print(dog.species)  # animal
print(cat.species)  # animal

dog.eat()  # Ест
cat.eat()  # Ест
```

#### Преимущество наследования

Тем самым уменьшается дублирование кода. Без наследования, нам пришлось бы сделать вот так:

```python
class Dog:
    species = "animal"

    def eat(self):
        print("Ест")


class Cat:
    species = "animal"

    def eat(self):
        print("Ест")
```

А теперь представьте, что классов с животными может быть очень много — тогда в каждом придётся создавать один и тот же код вместо одного объявления в родительском классе.

#### Поиск атрибутов и методов при наследовании

В теме наследования важно понимать логику поиска атрибутов и методов. Рассмотрим пример:

```python
# Родительский класс
class Animal:  
    species = "animal"

    def eat(self):
        print("Ест")


# Дочерний класс
class Dog(Animal):
    pass


dog = Dog()
print(dog.species)  # animal
dog.eat()  # Ест
```

**Что происходит при обращении dog.species?**

Атрибуты и методы — это в первую очередь имена, которые программа ищет при обращении. В нашем случае объект `dog` обращается к `species`.

1. Сначала ищем `species` в хранилище (`__dict__`) объекта. Если такое имя там есть — используем его.
2. Если нет — ищем в хранилище (`__dict__`) класса, которому принадлежит объект, то есть в `Dog.__dict__`. Если есть — используем.
3. Если нет — ищем далее по наследованию, то есть в `Animal.__dict__`. В нашем случае `species` хранится именно там — используем его значение.
4. Если бы и в `Animal` не было, поиск продолжился бы в корневом классе `object` — базовом классе, от которого неявно наследуются все классы. На этом курсе мы это не рассматриваем.

**Что происходит при обращении dog.eat()?**

С `dog.eat()` происходит тот же алгоритм поиска:

1. Ищем `eat` в объекте — там его нет.
2. Ищем `eat` в классе `Dog` — там его нет.
3. Ищем `eat` в родительском классе `Animal` — там оно есть, поэтому вызываем его.

Постарайтесь понять логику поиска имён, и тема наследования станет гораздо понятнее. На основе этих алгоритмов работают переопределение методов и полиморфизм.

#### 📝 Поиск атрибутов и методов при наследовании (upd)
```python
class Animal:
    species = "animal"          # 0. Атрибут класса Animal

    def eat(self):              # 0. Метод класса Animal
        print("Животное ест")


class Dog(Animal):
    sound = "Гав"               # 1. Атрибут класса Dog

    def __init__(self, name):
        self.name = name        # 2. Атрибут объекта Dog

    def bark(self):             # 2. Метод класса Dog
        print("Собака лает")


# Создаём объект
dog = Dog("Шарик")

# ==========================================
# 🔍 Поиск по шагам (MRO)
# ==========================================

# ШАГ 1: Поиск в самом объекте (dog.__dict__)
print(dog.name)     # -> "Шарик" (создан через self в __init__)

# ШАГ 2: Поиск в дочернем классе (Dog.__dict__)
print(dog.sound)    # -> "Гав"
dog.bark()          # -> "Собака лает"

# ШАГ 3: Поиск в родительском классе (Animal.__dict__)
print(dog.species)  # -> "animal"
dog.eat()           # -> "Животное ест"

# ШАГ 4: Поиск в базовом классе object (конечная точка поиска)
# dog.__str__()     # -> Возвращает строковое представление объекта
```

#### Наследование и __init__

`__init__` и другие специальные методы действуют по тому же алгоритму поиска:

```python
class Person:
    def __init__(self):
        print("Person init")


class Employee(Person):
    def __init__(self):
        print("Employee init")


e = Employee()  # Employee init
```

Создаётся объект класса `Employee`, поэтому ищем `__init__` в этом классе и вызываем. Теперь посмотрим что будет, если `__init__` отсутствует в этом классе:

```python
class Person:
    def __init__(self):
        print("Person init")


class Employee(Person):
    pass


e = Employee()  # Person init
```

Создаётся объект класса `Employee`, ищем `__init__` в этом классе, но его там нет. Тогда ищем `__init__` в родительском классе и вызываем.

#### __init__ с параметрами

Здесь всё как обычно, если есть параметры, то необходимо передать аргументы:

```python
class Person:
    def __init__(self, name):
        print("Person:", name)


class Employee(Person):
    pass


e = Employee("Вася")  # Person Вася
```

Вызывается `__init__` класса `Person`, а он требует аргумент (`name`). При создании объекта передаём этот аргумент.

#### Заключение

В этой статье мы разобрали, что такое наследование и как оно помогает создавать новые классы на основе уже существующих. Теперь мы знаем, что дочерние классы получают доступ к атрибутам и методам родительского класса без дублирования кода.

Мы научились создавать наследование в Python и поняли, по какому алгоритму происходит поиск атрибутов и методов при обращении к объектам. Эти знания пригодятся при разработке программ с большим количеством связанных классов, делая код более удобным для поддержки и расширения.

#### Ключевые моменты

**О наследовании в ООП:**
- Наследование позволяет создавать новый класс на основе существующего класса.
- Родительский класс содержит общие атрибуты и методы для связанных классов.
- Дочерний класс автоматически получает доступ к атрибутам и методам родителя.
- Наследование уменьшает дублирование кода и помогает строить иерархии классов.

**О создании наследования:**
- Наследование задаётся указанием родительского класса в скобках: `class Dog(Animal):`.
- Подклассы могут использовать функциональность родительского класса без её повторного объявления.
- Общие методы и атрибуты рекомендуется размещать в родительском классе.

**О поиске атрибутов и методов:**
- Поиск имени начинается в объекте (`__dict__` экземпляра).
- Если имя не найдено, поиск продолжается в классе объекта.
- Если имя отсутствует в классе, поиск идёт по цепочке наследования к родительским классам.
- Методы и атрибуты ищутся по одному и тому же алгоритму.

**Практическое значение:**
- Экземпляры дочерних классов могут вызывать методы и использовать атрибуты родительского класса.
- Понимание алгоритма поиска имён является основой для изучения переопределения методов и полиморфизма.
- Наследование делает код проще для поддержки, расширения и повторного использования.

#### 📝 Разница между Наследованием и Декораторами

Хотя оба механизма служат для расширения функционала кода, они решают эту задачу на разных уровнях архитектуры.

*   **Наследование (`class Child(Parent):`)**:
    *   **Суть**: Создает новый тип данных на основе старого (отношение «Является»).
    *   **Связь**: Жесткая, статическая (закладывается на этапе написания кода). Дочерний класс полностью наследует внутреннюю структуру родителя.
*   **Декораторы (`@decorator`)**:
    *   **Суть**: Внешняя обёртка, которая перехватывает вызовы к объекту/функции, добавляя логику «до» или «после».
    *   **Связь**: Гибкая, динамическая. Декоратор не меняет тип самого объекта и не строит иерархию классов.

**Итог**: Наследование меняет биологию (создает новый вид объекта), а декоратор — надевает на объект одежду (меняет внешнее поведение или добавляет проверки).
