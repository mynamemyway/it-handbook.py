# Functional Programming (FP)

## 1. Декораторы

### Что такое Декораторы и зачем нужны

**Декоратор** — это функция (в некоторых продвинутых случаях — объект специального класса).
  - Принимает в качестве аргумента другую функцию или класс, изменяет или дополняет их поведение и возвращает обратно.
  - В Python декоратор — это синтаксический сахар.
  - Символ `@` над функцией или классом — это сокращённая форма записи обычного вызова функции.

**Зачем нужны декораторы (принцип DRY)**
  Чтобы не писать один и тот же повторяющийся технический код в разных местах. Декоратор позволяет «навесить» готовую логику (например, логирование, проверку прав доступа или автоматическое управление памятью) одной строчкой.

---

### Пример с @dataclass для Двусвязного списка (DLL)

Декоратор `@dataclass` из встроенного модуля Python говорит интерпретатору: «Этот класс нужен только для хранения данных. Возьми его переменные и сгенерируй для него правильную функцию __init__ под капотом».

```py
from dataclasses import dataclass

@dataclass
class DoublyLinkedList:
    val: any = None
    next: 'DoublyLinkedList' = None
    prev: 'DoublyLinkedList' = None
```

**Почему Вариант с декоратором круче и как он работает:**

1. Чистый код: Мы избавились от ключевого слова `def`, __init__, и от `self.переменная = переменная`.
2. Тот же синтаксис: Создание объектов в коде программы не изменилось. Мы также пишем `node1 = DoublyLinkedList('A')`, и всё работает. Декоратор сам создал и выполнил рутину инициализации.

---

### Как это устроено под капотом (без символа @)

Как применить декоратор `@dataclass` к классу `DoublyLinkedList` вручную, без использования знака `@`.

```python
import dataclasses

# 1. Пишем обычный класс без функций внутри class DoublyLinkedList:
    val = None
    next = None
    prev = None

# 2. Передаем наш КЛАСС как аргумент в ФУНКЦИЮ dataclass()
# # Функция dataclass считывает структуру, сама генерирует метод __init__,
# # вшивает его в наш класс прямо в памяти и возвращает модифицированный класс обратно.
DoublyLinkedList = dataclasses.dataclass(DoublyLinkedList)
```

Строка `DoublyLinkedList = dataclasses.dataclass(DoublyLinkedList)` — это то, как Python физически выполняет декорирование.
Видя знак `@`, Python берёт то, что написано ниже, и автоматически передаёт внутрь функции `dataclass()`.

```py
@dataclasses.dataclass
class DoublyLinkedList:
    ...
```

### Какие еще бывают декораторы
В Python есть много встроенных декораторов. Три самых популярных:

1. **@property** — превращает функцию класса в «умное» свойство. Позволяет обращаться к функции без круглых скобок (как к обычной переменной) и защищает данные от некорректного изменения.
2. **@staticmethod** — говорит Python, что функция внутри класса является независимой. Ей не нужен доступ к объекту (аргумент self), она работает как обычная изолированная функция, но просто живет внутри контейнера-класса.
3. **Кастомные декораторы** — функции, которые ты пишешь сам. Например, декоратор **@timer**, который можно повесить над алгоритмом LeetCode, чтобы он автоматически замерял и печатал в консоль время выполнения функции.

---

### Резюме
1. Чем технически является декоратор? Это функция высшего порядка (функция, которая работает с другими функциями или классами как с данными).
2. Что делает знак `@`? Это синтаксический оператор, который заставляет Python автоматически передать сущность под ним (класс или функцию) в качестве аргумента декоратору.
3. Что происходит в памяти? Старый класс заменяется в памяти новым, изменённым классом, который вернула функция-декоратор.

### Пример использования

#### Декоратор-таймер: Разбор

```python
import time

# 1. Объявляем сам декоратор. Он принимает целевую функцию как объект (func)
def timer(func):
    
    # 2. Создаем функцию-матрешку (wrapper). 
    # *args и **kwargs позволяют ей принять любые аргументы, которые будут у целевой функции
    def wrapper(*args, **kwargs):
        
        # 3. ШАГ 1: Включаем секундомер ДО начала работы целевой функции
        start = time.perf_counter()
        
        # 4. ШАГ 2: Запускаем саму целевую функцию, передав ей все её аргументы.
        # Сохраняем её результат в переменную 'result', чтобы вернуть в самом конце.
        result = func(*args, **kwargs)
        
        # 5. ШАГ 3: Выключаем секундомер СРАЗУ ЖЕ, как функция завершила работу
        end = time.perf_counter()
        
        # 6. Печатаем красивый отчет в консоль, вычитая из конечного времени начальное
        print(f"\n⏱️  Функция [{func.__name__}] выполнилась за {end - start:.6f} сек.")
        
        # 7. Возвращаем результат работы оригинальной функции наружу (чтобы код не ломался)
        return result
        
    # 8. Декоратор возвращает саму функцию-обертку 'wrapper', заменяя ей оригинал
    return wrapper
```

#### Декоратор-таймер: Результат

```python
import time
from fractions import Fraction as F


def timer(func):
    '''
    Функция для замера времени выполнения другой функции
    '''
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        end = time.perf_counter()
        print(f"\n⏱️  Функция [{func.__name__}] выполнилась за {end - start:.6f} сек.")
        return result
    return wrapper

# 2. Пример использования (вызываем таймер как декоратор):
@timer
def all_fractal_nums(n):
    '''
    Выводит в порядке возрастания все несократимые дроби
    заключенные между 0 и 1, знаменатель которых не превосходит n
    '''
    nums = set()
    for i in range(1, n):
        for j in range(1, n + 1):
            num = F(i, j)
            if num < 1:
                nums.add(num)
    nums = sorted(nums)
    print(*nums, sep='\n')

# Запуск
all_fractal_nums(int(input("Введите число: ")))
```

#### Декоратор для замера 2.0

```python
import time
import tracemalloc


def profile_resources(func):
    """Декоратор для замера физического времени и оперативной памяти."""

    def wrapper(*args, **kwargs):
        # 1. Включаем мониторинг памяти и фиксируем время старта
        tracemalloc.start()
        start_time = time.perf_counter()

        # 2. Запускаем саму тестируемые функцию
        result = func(*args, **kwargs)

        # 3. Фиксируем время окончания и собираем статистику памяти
        end_time = time.perf_counter()
        current_mem, peak_mem = tracemalloc.get_traced_memory()
        tracemalloc.stop()

        # 4. Переводим данные в понятный вид
        execution_time = end_time - start_time
        peak_mem_kb = peak_mem / 1024  # Переводим байты в Килобайты

        # 5. Выводим результаты в консоль
        print(f"\n[Профиль функции '{func.__name__}']")
        print(f"⌛ Время выполнения: {execution_time:.6f} сек.")
        print(f"💾 Пиковое потребление памяти: {peak_mem_kb:.2f} КБ")

        return result

    return wrapper


# --- ПРИМЕР ИСПОЛЬЗОВАНИЯ ---


# Навешиваем декоратор через @ на любую функцию
@profile_resources
def test_sorting():
    """Тестовая функция: создает большой список и сортирует его."""
    # Создаем список из 100 000 чисел (пространственная нагрузка)
    nums = [int(x) for x in range(100000, 0, -1)]
    # Сортируем его (временная нагрузка)
    nums.sort()


# Запускаем функцию как обычно
test_sorting()
```
