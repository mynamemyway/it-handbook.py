# Дополнительные материалы

## Правила аннотации функций в Python

-   **Аннотация аргументов:** Тип указывается через двоеточие сразу после имени переменной: `аргумент: тип`.
-   **Значения по умолчанию:** Если у аргумента есть дефолтное значение, оно пишется через знак равенства строго ПОСЛЕ типа: `аргумент: тип = значение`.
-   **Возвращаемое значение:** Тип, который возвращает функция, указывается через стрелочку `->` после закрывающей круглой скобки, но ДО двоеточия: `def имя_функции(...) -> тип_выхода:`.

> **Примечание:** Если аргументы функции могут принимать абсолютно любые типы данных, их аннотацию можно полностью опустить, указав только тип возвращаемого значения через `-> тип_выхода:`.

### Пример кода:

```python
# Функция со всеми видами аннотаций и значением по умолчанию
def process_data(text: str, repeats: int = 1) -> str:
    return text * repeats


# Функция без аннотации аргументов (принимает любой тип), но с типом выхода
def get_length(any_data) -> int:
    return len(any_data)
```

## Функция `enumerate()` и ленивые вычисления

* **Суть**: Превращает итерируемый объект в ленивый итератор (генератор), который создаёт пары `(индекс, элемент)` на лету в момент запроса.
* **Зачем**: Позволяет получать индекс элемента в цикле `for` без ручного создания счетчиков (`i += 1`).
* **Память**: Сложность по памяти **O(1)**. Не копирует данные и не создает структуры в памяти до явного требования. На каждой итерации цикла существует ровно одна пара значений, которая сразу после использования стирается.
* **Распаковка**: Прямой `print(enumerate(x))` выведет адрес объекта в памяти. Для визуализации структуры нужно использовать `list(enumerate(x))`.

---

### Примеры использования

#### 1. Прямая распаковка в список (для отладки)
Если просто напечатать объект `enumerate`, мы увидим его технический адрес в памяти (объект-генератор):

```python
nums = ['99', '5', '85']
gen = enumerate(nums)

print(gen)
# Вывод: <enumerate object at 0x...>
```

Чтобы вытащить из него все данные, его нужно обернуть в `list()`, тогда получим список кортежей:
    
```py
print(list(gen)) 
# Вывод: [(0, '99'), (1, '5'), (2, '85')]
```

#### 2. Классический перебор в цикле `for`
В цикле пары значений автоматически распаковываются в две отдельные переменные `index` и `item`:

```python
passengers = ["Костя", "Ваня", "Катя"]

# enumerate() автоматически отдаёт и индекс, и значение
for index, name in enumerate(passengers):
    print(f"Пассажир № {index + 1} — это {name}")

# Вывод:
# Пассажир № 1 — это Костя
# Пассажир № 2 — это Ваня
# Пассажир № 3 — это Катя
```

## Бесконечность (Infinity) ♾️

### Концепция

В Python нет отдельного ключевого слова для бесконечности, поэтому для её создания используется встроенный тип данных `float()`, в который передаётся строка `'inf'` (от английского *infinity*).

Бесконечность используется как **«маркер невозможности»** или стартовая заглушка при поиске минимума/максимума в алгоритмах.

### Синтаксис и свойства

```python
# 1. Создание положительной и отрицательной бесконечности
INF = float('inf')   # Положительная бесконечность
MINF = float('-inf') # Отрицательная бесконечность

# 2. Как это выглядит при выводе на экран
print(INF)   # Выведет: inf
print(MINF)  # Выведет: -inf

# 3. Математические свойства (Любое число всегда меньше INF)
print(1000000 < INF)        # Выведет: True
print(-1000000 > MINF)      # Выведет: True
print(INF + 500 == INF)     # Выведет: True (Бесконечность нельзя увеличить)
```

### Правило💡

*   Если алгоритм ищет **минимум** (`min`) — заполняй стартовые ячейки `float('inf')`. Любое первое найденное реальное число гарантированно перезапишет её.
*   Если алгоритм ищет **максимум** (`max`) — заполняй стартовые ячейки `float('-inf')` или просто нулями `0` (если числа строго положительные).

## Генераторы коллекций и выражения-генераторы

   1. Comprehensions (Включения / Генераторы коллекций) — это синтаксический сахар для быстрого создания готовых объектов в памяти (списков, множеств, словарей). Они сразу вычисляют все элементы.
   2. Generator Expressions (Выражения-генераторы) — это ленивые «фабрики», которые ничего в памяти не создают, а выдают элементы по одному только в момент запроса.


### Группа 1: Генераторы коллекций (Comprehensions) — Жадные
Они берут память компьютера и сразу забивают её результатами.

- **Генератор списков (List Comprehension):**
```python
# В памяти создался готовый список из 10 элементов: [0, 1, 4, ..., 81]
squares_list = [i**2 for i in range(10)]
```

- **Генератор множеств (Set Comprehension):**
```python
# В памяти создалось готовое множество (уникальные элементы, без дубликатов)
squares_set = {i**2 for i in range(10)}
```

- **Генератор словарей (Dict Comprehension):**
```python
# В памяти создался словарь с парами ключ:значение {0: 0, 1: 1, 2: 4...}
squares_dict = {i: i**2 for i in range(10)}
```

---

### Группа 2: Выражения-генераторы (Generator Expressions) — Ленивые
Нам кажется, что если заменить квадратные скобки на круглые, должен получиться «генератор кортежей», но кортежных генераторов не существует.

Круглые скобки создают выражение-генератор:

```python
squares_gen = (i**2 for i in range(10))

print(squares_gen)
# Выведет: <generator object <genexpr> ...>
```

**squares_gen** — это не список чисел.
Это инструкция для Python, чертеж. В памяти сейчас лежит только сам этот чертеж, он занимает ничтожно мало места.

* Компьютер еще не производил расчеты квадратов.
* Если ты попросишь: «Дай первый элемент», он посчитает 0 и отдаст.
* Прокатит миллиард итераций — память компьютера не забьется: старые элементы забываются, а новые считаются на лету.

### Когда можно опустить круглые скобки
Это синтаксическое исключение в Python.
Если выражение-генератор передается единственным аргументом в какую-то функцию (`sum()`, `any()`, `all()`, `join()`), то внутренние круглые скобки можно опустить, чтобы не писать двойные:

**Вместо:**
`sum((n**2 for n in args))`
**Пишут элегантное:**
`sum(n**2 for n in args)`

Функция `sum()` сама поочередно дергает генератор, забирает по одному числу, прибавляет к общей сумме и выбрасывает из памяти.

### Тип generator
Генераторное выражение в Python — это полноценный объект, этот тип называется **generator**.
Если мы проверим его в коде:

```python
gen = (i for i in range(5))
print(type(gen))  # Выведет: <class 'generator'>
```

Этот тип данных не относится к коллекциям (как list, set или tuple), потому что он не хранит данные.
**Он относится к категории итераторов.**

### Аналогия

* Список (list) — это склад с готовыми коробками товаров. Продукты уже произведены, лежат на полках и занимают место (память). Ты можешь сразу взять 5-ю коробку или 100-ю.
* Генератор (generator) — это конвейерный автомат с одной кнопкой. На складе ничего не хранится. Когда ты подходишь и нажимаешь кнопку (в коде это делает функция `next()` или цикл `for`), автомат производит одну коробку и выдает её.

Вторую коробку он делать не будет, пока не нажмёшь кнопку. При этом автомат не знает, сколько коробок он выдаст всего (если последовательность бесконечная) и он не помнит, какую коробку выдал шаг назад. Он знает только, как сделать следующую.

### Главные свойства типа generator:

   1. **Одноразовость (Исчерпаемость):** Генератор можно прочитать только один раз. Если ты прогнал генератор через цикл `for` (или отдал в `sum()`), он полностью опустошается. Если ты попробуешь запустить его второй раз, он ничего не вернет. Чтобы пройтись снова, генератор нужно создавать заново.
   2. Отсутствие индексов и длины: У генератора нельзя спросить длину `len(gen)` (элементы не созданы) и нельзя взять элемент по индексу `gen[2]`. Чтобы добраться до третьего элемента, нужно физически прокрутить конвейер три раза.

### Пример:

```python
gen = (n for n in range(1, 4))

print(sum(gen))  # Выведет: 6 (Генератор полностью исчерпан)
print(sum(gen))  # Выведет: 0 (Генератор пуст, элементы закончились)
```

## Оператор `return`

### Когда нужен `return`

1.   **Возврат вычисленного значения:** Передает результат работы функции во «внешний код» в переменную или  расчеты
2.   **Досрочное прерывание (выход):** Останавливает выполнение функции в любой точке, если сработало условие или защита (Guard Clause).
3.   **Возврат нескольких значений:** Позволяет вернуть из функции несколько объектов - упакует в один кортеж (`return x, y, z`).
4.   **Возврат другой функции (Замыкания / Декораторы):** Передает саму функцию как объект высшего порядка.

> **Важно помнить:** Если после слова `return` ничего не указано (или оператор отсутствует), функция неявно вернет объект `None`.

### Функции с побочным эффектом (Side Effects)
Функции, которые выполняют какое-то действие («оставляют след» в реальном мире или в памяти компьютера), но при этом сами возвращают None, в программировании называются функциями с побочным эффектом (Side Effects).

Помимо `print()`, все такие функции можно разделить на 3 большие группы:

#### 1. Изменение (мутация) списков, словарей и множеств
В Python многие встроенные методы коллекций изменяют объект на месте, но сами возвращают None.
Если вызвать их внутри своей функции, они изменят данные, и писать return не понадобится.

* list.append() / list.sort() / list.remove()
* dict.update()
* set.add()

```python
def add_user(users_list: list, name: str) -> None:
    users_list.append(name)  # Метод append() изменил список, но вернул None
    # Никакой return не нужен, список снаружи функции уже обновился!
```

#### 2. Работа с файлами и базами данных
Когда функция записывает данные на жесткий диск или отправляет их в базу, её задача — совершить физическое действие. Ей нечего возвращать программе, кроме факта успешного выполнения.

* file.write() — запись текста в файл.
* db.execute() — сохранение строки в базу данных.

```python
def save_log(text: str) -> None:
    with open("log.txt", "w") as f:
        f.write(text)  # Записали данные на диск. Возвращать функции нечего.
```

#### 3. Управление временем и операционной системой (Системные вызовы)
Функции, которые влияют на ход выполнения программы или взаимодействуют с компьютером напрямую.

* time.sleep() — ставит программу на паузу.
* os.mkdir() — создает новую папку на компьютере.
* logging.info() — записывает технические логи для разработчиков.

```python
def create_project_folder(name: str) -> None:
    import os
    os.mkdir(name)  # Папка физически создалась на компьютере. return не нужен.
```

**Вывод:** Если функция меняет что-то во «внешнем мире» (выводит текст на экран, создает папку, пишет в файл) или изменяет переданный в неё объект (добавляет элемент в список), ей нужен return. Её работа — это само действие.
