# Checklist базовой настройки сервера (Ubuntu 24.04 LTS)

## Шаг 0. Первое подключение к серверу
Выполнить в терминале локальной рабочей машины (Mac/PC):
```bash
ssh root@<IP_АДРЕС_СЕРВЕРА>
```
*При первом входе на предупреждение безопасности ответить `yes`.*

## Шаг 1. Обновление операционной системы
Обновить индексы пакетов и установить самые свежие исправления безопасности Linux:
```bash
sudo apt update && sudo apt upgrade -y
```

## Шаг 2. Установка системных утилит (Git)
Установить систему контроля версий (в минимальном образе отсутствует):
```bash
sudo apt install -y git
```

## Шаг 3. Установка Docker и Docker Compose
Установить контейнеризацию из официального стабильного репозитория Ubuntu одной командой:
```bash
sudo apt install -y docker.io docker-compose-v2
```

## Шаг 4. Проверка корректности установки
Убедиться, что все утилиты успешно установлены и готовы к работе:
```bash
git --version && docker --version && docker compose version
```

---

## Шаг 5. Создание пользователя и настройка прав доступа
Выполняется на сервере под пользователем `root`. Заменяет работу напрямую от суперпользователя.

1. Создать нового пользователя `mynamemyway`:
```bash
adduser mynamemyway
```
*Задать пароль для нового пользователя, остальные поля данных пропустить (нажимая Enter).*

2. Наделить пользователя правами администратора (`sudo`):
```bash
usermod -aG sudo mynamemyway
```

3. Разрешить пользователю управлять Docker-контейнерами без ввода `sudo`:
```bash
usermod -aG docker mynamemyway
```

## Шаг 6. Перенос SSH-ключа доступа на нового пользователя
Выполняется на сервере под пользователем `root`. Переносит ваш ключ авторизации `MacAir` с аккаунта `root` на новый профиль.

1. Создать скрытую директорию для SSH-конфигов в домашней папке нового пользователя:
```bash
mkdir -p /home/mynamemyway/.ssh
```

2. Скопировать файл авторизованных ключей:
```bash
cp /root/.ssh/authorized_keys /home/mynamemyway/.ssh/
```

3. Выставить жесткие системные права безопасности на файлы ключей (иначе Linux заблокирует вход):
```bash
chown -R mynamemyway:mynamemyway /home/mynamemyway/.ssh
chmod 700 /home/mynamemyway/.ssh
chmod 600 /home/mynamemyway/.ssh/authorized_keys
```

## Шаг 7. Проверка подключения под новым пользователем
Выполнить в терминале локальной рабочей машины:
```bash
ssh mynamemyway@<IP_АДРЕС_СЕРВЕРА>
```
*Вход должен произойти автоматически по SSH-ключу, а строка приветствия изменится на*
`mynamemyway@<SERVER_NAME>:~$`
