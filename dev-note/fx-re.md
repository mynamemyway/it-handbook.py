#### 📝 Справочник параметров и флагов `re.sub()`

Сигнатура: `re.sub(pattern, repl, string, count=0, flags=0)`

##### Основные параметры:
- `pattern`: Шаблон поиска (строка или скомпилированный объект регулярного выражения `re.Pattern`).
- `repl`: Замена (строка или функция, принимающая объект совпадения `re.Match` и возвращающая строку).
- `string`: Исходный текст (строка), в котором производится поиск.
- `count`: Максимальное число замен (целое число). По умолчанию `0` (заменяются все вхождения).
- `flags`: Битовые маски для модификации регулярного выражения. По умолчанию `0` (без флагов).

##### Все доступные флаги (передаются через `flags=`):
- `re.IGNORECASE` (или `re.I`): Отключает чувствительность к регистру (символы [A-Z] соответствуют [a-z]).
- `re.MULTILINE` (или `re.M`): Меняет поведение якорей `^` и `$`. Они начинают соответствовать началу и концу каждой строки внутри текста, а не только началу и концу всего текста.
- `re.DOTALL` (или `re.S`): Символ точки `.` начинает соответствовать абсолютно любому символу, включая символ переноса строки `\n`.
- `re.VERBOSE` (или `re.X`): Разрешает форматировать регулярное выражение внутри строки, добавлять пробелы для читаемости и писать комментарии через `#`.
- `re.ASCII` (или `re.A`): Заставляет метасимволы типа `\w`, `\W`, `\b`, `\B`, `\d`, `\D` соответствовать только символам из таблицы ASCII (латиница), отключая полную поддержку Unicode.
- `re.UNICODE` (или `re.U`): Включает полную поддержку Unicode для метасимволов (в Python 3 этот флаг активен по умолчанию, он избыточен).
- `re.LOCALE` (или `re.L`): Заставляет метасимволы зависеть от текущих системных настроек языка (locale). Устарел в Python 3, использовать не рекомендуется.

##### Комбинация флагов:
- Флаги можно объединять внутри параметра через побитовое ИЛИ `|`. Пример: `flags=re.I | re.M`.


#### 📝 Динамическая замена через функцию-коллбэк (лямбду) в `re.sub()`

Использование объектов совпадения для вычисления строки замены «на лету».

- Механика: Если в параметр `repl` передана функция или `lambda`, движок `re.sub()` автоматически вызывает её для каждого найденного вхождения.
- Объект `re.Match`: Функция принимает на вход не чистую строку, а объект совпадения `re.Match`. Для извлечения найденного текста внутри лямбды вызывается метод `.group()`.
- Паттерн применения:
  ```python
  text = re.sub(pattern, lambda m: '*' * len(m.group()), text, flags=re.I)
  ```
- Эффект: Исключаются ручные циклы перебора. Длина замены вычисляется динамически на основании каждого конкретного совпадения, что критически важно при объединении шаблонов через логическое «ИЛИ» (`|`).
