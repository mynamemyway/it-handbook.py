## Общие названия операций в Computer Science vs Python
Это общепринятые академические названия операций в компьютерных науках (Computer Science). Они одинаковы для всех языков программирования (C++, Java, Python, Go). Но каждый язык реализует их через свои ключевые слова.

## 🗂️ Справочник операций в Computer Science

## 1. Операции добавления (Writing / Insertion)

- **Push** (Пуш / «Затолкнуть») — добавление элемента на верхушку структуры (используется строго в Стеках).
  * В Python list: `.append()`
- **Enqueue** (Энкью / «Встать в очередь») — добавление элемента в самый конец (хвост) структуры (используется строго в Очередях).
  * В Python collections.deque: `.append()`
- **Insert / Add** (Инсерт / Эдд / «Вставить») — принудительная вставка элемента в любое указанное место структуры (например, в середину массива по индексу).
  * В Python list: `.insert(index, value)`
- **Prepend / AppendLeft** (Препенд / «Добавить в начало») — вставка элемента строго в самый старт (начало) структуры.
  * В Python collections.deque: `.appendleft()`

## 2. Операции извлечения и удаления (Deletion / Extraction)

- **Pop** (Поп / «Вытолкнуть») — удаление элемента с верхушки структуры с его обязательным возвратом в переменную (используется в Стеках и обычных массивах).
  * В Python list: `.pop()`
- **Dequeue** (Дикью / «Выйти из очереди») / **PopLeft** — удаление самого первого элемента из начала (головы) структуры с его обязательным возвратом в переменную (используется в Очередях).
  * В Python collections.deque: `.popleft()`
- **Delete / Remove / Drop** (Делит / Римув / «Удалить») — уничтожение элемента в любом месте структуры по его значению или позиции, без возврата в код.
  * В Python list: `.remove(value)` или оператор del array[index]
- **Clear** (Клиар / «Очистить») — полное обнуление структуры. Удаляет абсолютно все элементы за один раз.
  * В Python: `.clear()`

## 3. Операции чтения и осмотра (Reading / Inspection)

- **Peek / Top** (Пик / Топ / «Взглянуть») — просмотр элемента на верхушке стека, не удаляя его оттуда.
  * В Python list: чтение по индексу [-1]
- **Front / Head** (Фронт / Хед / «Взглянуть на начало») — просмотр самого первого элемента в начале очереди или связного списка, не удаляя его.
  * В Python: чтение по индексу [0] или обращение к свойству .val головы списка.
- **Get / Access** (Гет / Аксесс / «Получить») — прямое чтение данных по конкретному индексу (в массивах) или по ключу (в Хеш-картах / словарях).
  * В Python: nums[index] или my_dict[key]

## 4. Операции изменения и поиска (Modification & Search)

- **Update / Set** (Апдейт / Сет / «Обновить / Установить») — замена старого значения на новое по конкретному индексу или ключу.
  * В Python: nums[index] = new_value
- **Search / Find** (Сёрч / Файнд / «Найти») — перебор структуры с целью проверить, есть ли там нужный элемент, и узнать его позицию.
  * В Python: оператор in или метод `.index(value)`

## 5. Служебные проверки состояния (Utility / Metadata)

- **Size / Length** (Сайз / Ленгс / «Размер») — возвращает общее количество элементов в структуре.
  * В Python: функция len()
- **IsEmpty** (Из Эмпти / «Пуст ли?») — проверка, пуст ли контейнер. Возвращает True или False.
  * В Python: оператор if not container:
- **IsFull** (Из Фулл / «Заполнен ли?») — проверка на переполнение структуры (актуально только для статических массивов с фиксированной памятью в низкоуровневых языках).
