## 1. Место работы: ПИРАНЬЯ (Backend-разработчик)
Ноябрь 2025 — по настоящее время (9 месяцев)

1. AI-Консультант в Telegram-бизнес:
  - Архитектура на RAG и LangChain
  - Векторная БД для релевантных ответов
  - Логики калькуляции стоимости услуг по прайсу изолированно от AI (гибрид)

  Стек: Python, Aiogram 3, LangChain, ChromaDB, OpenAI API, Aiosqlite, Pytest-asyncio, HTTPX, Aiohttp-socks, Python-dotenv, Docker.

2. ERP/CRM:
  - Релляционная база данных Grist (SQLite)
  - Бизнес логика на Python в UI, покрывающая всю рутину рабочих процессов
  - Настройка UI (вывод по принципу иерархической фильтрации)
  - Ядро, сервисный слой, REST API на сервере (внешние интеграции)
  - Вэбхуки для обработки входящих запросов
  - Контур.Эльба API (синхронизации контрагентов и транзакций в отчетах)
  - Т-Банк API (генерации ссылок на оплату по параметрам, статусы транзакций)
  - Модель доступа (RBAC) на 5 кастомных ролей пользователей
  - Валидация входящих данных и условное форматирование для пользователей

  Стек: Python, Flask, Pandas, Openpyxl, Requests, Pydantic, Python-dotenv, Docker.

Результаты:
- Полный переход бизнеса на новую систему учета, автоматизация бизнес-процессов
- Рекомендация меня как разработчика клиентам фирмы

## 2. Место работы: PAVEPO (Backend-разработчик)
Период работы (Август 2025 — Декабрь 2025)

Бэкенд-часть сервиса PrimeNetworking (Telegram Mini App):
- Архитектура и БД: проект БД на PostgreSQL, кастомные типы SQLAlchemy, миграции Alembic, SQLite для локальной работы
- Аутентификация: защита данных на Passlib/Bcrypt, авторизация через JWT-токены (Python-jose)
- RESTful API: разработка эндпоинтов с ограничением уровней доступа через FastAPI Dependency Injection
- Бизнес-логика: сложная логика управления контактами (апгрейд аккаунтов, передача прав новым, архивация старых)
- Система лояльности: алгоритм двухуровневой реферальной системы
- Интеграция LLM: подключение моделей через OpenRouter для генеративных функций
- Парсинг данных: асинхронные скраперы на Playwright и BeautifulSoup4
- Интеграция Telegram API: настройка системных оповещений и логики вебхуков
- Модуль поддержки: разработка системы с автогенерацией тикетов и админ-каналом ОС
- Монетизация: интеграция API банка для оплаты подписок по тарифам с логикой списания бонусных и остаточных баллов
- Тестирование: асинхронные интеграционные автотестов на Pytest и HTTpx (+ ручное)
- Docker: контейнеризация приложения для локального окружения и деплоя

Стек: Python, FastAPI, Uvicorn, SQLAlchemy, PostgreSQL, SQLite, Alembic, Pydantic, Python-jose, Passlib, Bcrypt, Playwright, BeautifulSoup4, OpenRouter, Phonenumbers, Pytest, HTTpx, Docker.

Результаты:
- Успешный запуск полноценного MVP сервиса с нуля.
- Заключение договора на техническое обслуживание проекта.
