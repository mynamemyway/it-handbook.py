# Опыт
Баланс между технической и бизнес реализацией.

## 1. Место работы: ПИРАНЬЯ (Backend-разработчик)
Ноябрь 2025 — по настоящее время (9 месяцев)

1. AI-Консультант в Telegram-бизнес для типографии:
  - Архитектура на RAG и LangChain
  - Векторная БД ChromaDB для обучения и релевантных ответов
  - Гибридная логика калькуляции стоимости услуг изолированно от AI
  - Сбор статистики действий клиентов и заказов в базу данных
  - Покрытие ключевого функционала асинхронными тестами

Стек: Python, Aiogram 3, LangChain, ChromaDB, OpenAI API, Aiosqlite, Pytest-asyncio, HTTPX, Aiohttp-socks, Python-dotenv, Docker.

2. CRM/ERP система автоматизации бизнес-процессов:
  - Проект структуры реляционной базы данных (Grist/SQLite)
  - Скрипты для миграций и синхронизации данных по API
  - Бизнес логика на Python, покрывающая всю рутину офиса
  - Настройка UI-виджетов с иерархической фильтрацией данных
  - Валидация данных и условное форматирование для удобства работы
  - Настройка модели доступа (RBAC) на 5 кастомных ролей пользователей
  - Ядро системы, сервисный слой, API и вебхуки на сервере для интеграций
  - Контур.Эльба API (синхронизация контрагентов и транзакций в отчетах)
  - Т-Банк API (генерация ссылок на оплату по параметрам, мониторинг статусов)

Стек: Python, Flask, Pandas, Openpyxl, Requests, Pydantic, Python-dotenv, Docker.

Результаты:
- Переход бизнеса на новую систему учета, полная автоматизация бизнес-процессов
- Рекомендация клиентам фирмы

## 2. Место работы: PAVEPO (Backend-разработчик)
Период работы (Август 2025 — Декабрь 2025)

Бэкенд-часть сервиса PrimeNetworking (Telegram Mini App):

- Проектирование БД на PostgreSQL и SQLite, миграции через Alembic
- Аутентификация через JWT-токены (Python-jose) и Passlib/Bcrypt
- Разработка эндпоинтов через FastAPI Dependency Injection
- Логика управления контактами (апгрейд, передача прав, архивация)
- Реализация алгоритма двухуровневой реферальной системы
- Интеграция LLM-моделей через OpenRouter для AI-функций
- Создание асинхронных скраперов на Playwright и BeautifulSoup4
- Настройка системных оповещений и вебхуков Telegram API
- Автоматизированная система поддержки с тикетами и админ-каналом
- Интеграция API банка для оплаты подписок с учётом бонусов
- Написание асинхронных интеграционных тестов на Pytest и HTTpx
- Контейнеризация приложения через Docker

Стек:
Python, FastAPI, Uvicorn, SQLAlchemy, PostgreSQL, SQLite, Alembic, Pydantic, Python-jose, Passlib, Bcrypt, Playwright, BeautifulSoup4, OpenRouter, Phonenumbers, Pytest, HTTpx, Docker.

Результаты:
- Успешный запуск полноценного MVP сервиса с нуля.
- Заключение договора на техническое обслуживание проекта.
