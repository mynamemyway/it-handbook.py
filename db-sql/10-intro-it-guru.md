## 1. Введение

### 1.5 Полезные онлайн-инструменты для работы с SQL

Эти инструменты помогут вам быстро проверять запросы, отлаживать код и сразу видеть результаты работы с таблицами. Они особенно удобны для практики без установки СУБД на компьютер, позволяют экспериментировать с данными и лучше понимать работу SQL.

| Название | Поддержка СУБД | Описание |
| --- | --- | --- |
| DB Fiddle | MySQL, PostgreSQL, SQLite, SQL Server | Популярный онлайн-сервис для написания, выполнения и совместного использования SQL-запросов. Позволяет создавать схемы баз данных и делиться ссылками на готовые примеры. |
| SQLite Online | SQLite, PostgreSQL, MySQL | Легковесная онлайн-песочница для работы с SQLite и другими базами данных. Подходит для изучения SQL, тестирования запросов и небольших проектов без установки программ. |
| SQL Fiddle | MySQL, PostgreSQL, Oracle, SQLite, SQL Server | Классический инструмент для проверки SQL-запросов на различных СУБД. Позволяет создавать схемы, заполнять таблицы и тестировать запросы. |
| OneCompiler SQL | MySQL, PostgreSQL, SQLite | Онлайн-среда разработки, позволяющая быстро запускать SQL-код прямо в браузере без установки дополнительного ПО. |
| ExtendsClass SQL Editor | SQLite | Онлайн-редактор SQL с возможностью создавать таблицы, выполнять запросы и работать с базами SQLite прямо в браузере. |
| SQLite Viewer | SQLite | Инструмент для просмотра файлов SQLite в браузере. Позволяет открывать базы данных, изучать таблицы и выполнять SQL-запросы. |
| TableConvert | Любые табличные данные | Конвертер таблиц между HTML, CSV, Markdown, Excel, JSON и SQL INSERT. Полезен для подготовки и преобразования данных. |
| QuickDBD | ER-диаграммы, SQL | Сервис для быстрого проектирования структуры базы данных и создания ER-диаграмм с помощью текстового описания. |
| DrawSQL | ER-диаграммы | Онлайн-инструмент для визуального проектирования схем баз данных и совместной работы над структурой таблиц. |
| dbdiagram.io | SQL, DBML | Популярный сервис для создания диаграмм баз данных, импорта SQL-схем и визуализации связей между таблицами. |

1. **DB Fiddle**
  - MySQL, PostgreSQL, SQLite, SQL Server
  - Популярный онлайн-сервис для написания, выполнения и совместного использования SQL-запросов. Позволяет создавать схемы баз данных и делиться ссылками на готовые примеры.

2. **SQLite Online**
  - SQLite, PostgreSQL, MySQL
  - Легковесная онлайн-песочница для работы с SQLite и другими базами данных. Подходит для изучения SQL, тестирования запросов и небольших проектов без установки программ.

3. **SQL Fiddle**
  - MySQL, PostgreSQL, Oracle, SQLite, SQL Server
  - Классический инструмент для проверки SQL-запросов на различных СУБД. Позволяет создавать схемы, заполнять таблицы и тестировать запросы.

4. **OneCompiler SQL**
  - MySQL, PostgreSQL, SQLite
  - Онлайн-среда разработки, позволяющая быстро запускать SQL-код прямо в браузере без установки дополнительного ПО.

5. **ExtendsClass SQL Editor**
  - SQLite
  - Онлайн-редактор SQL с возможностью создавать таблицы, выполнять запросы и работать с базами SQLite прямо в браузере.

6. **SQLite Viewer**
  - SQLite
  - Инструмент для просмотра файлов SQLite в браузере. Позволяет открывать базы данных, изучать таблицы и выполнять SQL-запросы.

7. **TableConvert**
  - Любые табличные данные
  - Конвертер таблиц между HTML, CSV, Markdown, Excel, JSON и SQL INSERT. Полезен для подготовки и преобразования данных.

8. **QuickDBD**
  - ER-диаграммы, SQL
  - Сервис для быстрого проектирования структуры базы данных и создания ER-диаграмм с помощью текстового описания.

9. **DrawSQL**
  - ER-диаграммы
  - Онлайн-инструмент для визуального проектирования схем баз данных и совместной работы над структурой таблиц.

10. **dbdiagram.io**
  - SQL, DBML
  - Популярный сервис для создания диаграмм баз данных, импорта SQL-схем и визуализации связей между таблицами.
