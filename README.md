# it-handbook.py

Личный справочник и база знаний по DSA с примерами реализации на Python + смежные материалы (cs, sql, git и т.д.).

> Расширяется...

## 📌 Для чего?

Систематизация знаний и практики, полученных в процессе обучения для повышения квалификации и подготовки к собеседованиям.

---

## 📂 Структура репозитория
* `/dev-core` — основы **computer science**, **dsa**
* `/dev-note` — справочники по **функциям и классам** + доп. материалы
* `/gen-python` — теория + практика из курсов **«Поколение Python»**
* `/problem-sol` — доп. задачи, экзамены, решения
* `/sql` - справочник **SQL**
* `/vcs-git` - справочник **Git**
* `/win-interview` - материалы для собесов
