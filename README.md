# it-handbook.py

База знаний по Computer Science с реализацией на Python + смежные материалы [python, dsa, sql, git, ...]

> Расширяется...

## 🎯 Цель

Систематизация знаний и практики, полученных в процессе обучения для повышения квалификации и подготовки к собеседованиям.

---

## 📂 Структура
* `/db-sql` — введение в базы данных и **SQL**
* `/dev-core` — основы **computer science**, **dsa**
* `/dev-note` — справочники по **функциям и классам** + доп. материалы
* `/gen-python` — теория и практика из курсов **«Поколение Python»**, **«Осознанный Python»**
* `/problem-sol` — доп. задачи, экзамены, решения
* `/win-interview` - резюме и материалы для интервью
