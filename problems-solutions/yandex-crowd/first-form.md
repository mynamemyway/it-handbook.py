# 2. Коммерческий опыт и роль

1. PrimeNet - сетевая телефонная книга с AI (Telegram Mini App)
Роль: Backend-разработчик Python (по договору), администратор серверной части
Результат: с нуля спроектировал архитектуру и реализовал MVP бэкенд-части сервиса управления контактами. Интегрировал скраперы для обогащения данных, AI предложения, API Банка Точка для обработки платежей, реферальную систему и сервис техподдержки. 
Стек: FastAPI, PostgreSQL, SQLAlchemy, Alembic и т.д.

2. Mr Banners - AI-консультант для типографии (Telegram-бизнес)
Роль: Python-разработчик.
Результат: разработал и запустил в эксплуатацию AI бота с базой знаний на RAG, LangChain и SQLite. Реализовал логику расчёта стоимости услуг по прайсу типографии и логирование действий пользователей для сбора статистики и заказов.

3. PWA-сервис дисконтных карт для Цветочного комбината
Роль: Fullstack-разработчик.
Результат: запустил в продакшен веб-сервис электронных дисконтных карт с возможностью установки на iOS/Android, авторизацией клиентов по звонку / SMS и адаптивной вёрсткой. 
Стек: FastAPI, Jinja2, SQLite и т.д.

4. CRM/ERP на базе Grist self-hosted для типографии (разработка и автоматизация)
Роль: Python-разработчик, автоматизатор, администратор базы / сервера
Результат: спроектировал архитектуру и разработал систему учёта для перевода бизнеса из гугл сервисов в безопасную среду (Forward Auth на Reverse Proxy). Написал скрипты для миграции данных. На базе Flask реализовал и упаковал в Docker микросервис для обработки вебхуков, который принимает запросы из CRM, осуществляет обмен данными по API с внешними сервисами (Т-Банк, Контур.Эльба) и синхронизирует состояния в базе.
