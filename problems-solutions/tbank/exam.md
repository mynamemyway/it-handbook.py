## Problem 1: Превращение строки в палиндром добавлением букв 'a'

**Условие:**
На уроке русского языка Саша получил строку **S**, состоящую из строчных английских букв. Учитель попросил его превратить эту строку в палиндром, но разрешил выполнять только одно действие: дописывать некоторое количество букв **a** в начало строки. Количество добавленных букв может быть и нулевым.

Помогите Саше определить, можно ли таким способом получить палиндром.

Строка длины **N**, \(A = A_1 A_2 \dots A_N\), называется палиндромом, если \(A_i = A_{N+1-i}\) для каждого \(1 \le i \le N\).

**Входные данные:**
* В единственной строке входных данных дана строка **S** (\(1 \le \vert{}S\vert{} \le 10^6\)) из строчных латинских букв.

**Выходные данные:**
* Выведите `Yes`, если можно добавить сколько-то букв **a** в начало строки, чтобы получить палиндром, и `No` иначе.

**Примеры:**
Пример 1
Ввод
```text
qwq
```
Вывод
```text
Yes
```

Пример 2
Ввод
```text
tbank
```
Вывод
```text
No
```

Пример 3
Ввод
```text
bacaba
```
Вывод
```text
Yes
```

```python
# Паттерн: Два указателя
# Сложность: O(N)

s = input().strip()

# Букв 'a' в начале строки
start_a = 0
for char in s:
    if char == 'a':
        start_a += 1
    else:
        break

# Букв 'a' в конце строки
end_a = 0
for char in reversed(s):
    if char == 'a':
        end_a += 1
    else:
        break

# Если в начале 'a' больше, чем в конце, палиндром не получить
if start_a > end_a:
    print("No")
else:
    trimmed_s = s[:len(s) - (end_a - start_a)] if end_a > start_a else s

    if trimmed_s == trimmed_s[::-1]:
        print("Yes")
    else:
        print("No")
```

## Problem 3: Две сделки с акциями

**Условие:**
Вы получили доступ к секретной информации о будущих ценах акций одной компании на ближайшие **n** дней. Для каждого дня заранее известна точная стоимость акции.

Вы планируете воспользоваться этой информацией и совершить ровно две сделки с одной акцией. Каждая сделка состоит из покупки и последующей продажи одной акции. Формально:
* Вы покупаете акцию в день **a** и продаёте её в день **b**, где \(a \le b\);
* Затем вы снова покупаете акцию в день **c** и продаёте её в день **d**, где \(b \le c \le d\).

Таким образом, вы не можете держать более одной акции одновременно, а вторая сделка начинается не раньше завершения первой. Требуется определить максимальную суммарную прибыль, которую можно получить при оптимальном использовании этой информации.

**Входные данные:**
* Первая строка содержит целое число **n** (\(1 \le n \le 5 \cdot 10^5\)) — количество дней.
* Вторая строка содержит **n** целых чисел \(p_1, p_2, \dots, p_n\) (\(1 \le p_i \le 10^9\)) — цену акции в каждый из дней.

**Выходные данные:**
* Выведите одно целое число — максимальную возможную прибыль.

**Примеры:**
Пример 1
Ввод
```text
7
3 2 6 1 4 8 3
```
Вывод
```text
11
```

Пример 2
Ввод
```text
1
67
```
Вывод
```text
0
```

Пример 3
Ввод
```text
2
1 2
```
Вывод
```text
1
```

```python
# Паттерн: Встречные префиксные массивы (Префикс/Суффикс DP)
# Сложность: O(N) по времени, O(N) по памяти

n = int(input())
prices = [int(i) for i in input().split()]

if n < 2:
    print(0)
else:
    # Исходный профит слева направо: макс. прибыль от 1 сделки до дня i включительно
    left_profit = [0] * n
    min_price_left = prices[0]
    for i in range(1, n):
        min_price_left = min(min_price_left, prices[i])
        left_profit[i] = max(left_profit[i - 1], prices[i] - min_price_left)

    # Профит справа налево: макс. прибыль от 1 сделки после дня i включительно
    right_profit = [0] * n
    max_price_right = prices[n - 1]
    for i in range(n - 2, -1, -1):
        max_price_right = max(max_price_right, prices[i])
        right_profit[i] = max(right_profit[i + 1], max_price_right - prices[i])

    # Находим оптимальный день разделения двух сделок
    max_total_profit = 0
    for i in range(n):
        max_total_profit = max(max_total_profit, left_profit[i] + right_profit[i])

    print(max_total_profit)
```

## Problem 4: Минимальное количество монет со сдачей

**Условие:**
В музее нумизматики проходит выставка старинных монет. Экскурсовод рассказал Маше, что в Римской Империи использовались монеты **n** различных номиналов: \(a_1, a_2, \dots, a_n\).

Известно, что \(1 = a_1 < a_2 < \dots < a_n\) и для каждого \(1 \le i \le n-1\) номинал \(a_{i+1}\) кратен \(a_i\).

В сувенирной лавке Маша хочет купить вещь стоимостью **x**. Она может заплатить любую сумму не меньше **x**, а продавец выдаст сдачу теми же монетами. Нужно определить минимальное общее количество монет, которое будет использовано: и тех, которыми Маша платит, и тех, которые она получит в качестве сдачи.

Более формально, среди всех целых \(y \ge x\) требуется найти минимум величины:  
(минимальное число монет, чтобы набрать ровно \(y\)) + (минимальное число монет, чтобы набрать ровно \(y - x\))

**Входные данные:**
* Первая строка содержит два числа **n** (\(1 \le n \le 60\)) и **x** (\(1 \le x \le 10^{18}\)) — количество номиналов монет и необходимая сумма.
* Вторая строка содержит **n** чисел \(1 = a_1, a_2, \dots, a_n\) (\(1 \le a_i \le 10^{18}\)) — номиналы монет. Каждая следующая монета строго кратна предыдущей.

**Выходные данные:**
* Выведите одно целое число — минимальное общее количество монет.

**Примеры:**
Пример 1
Ввод
```text
2 36
1 6
```
Вывод
```text
6
```

Пример 2
Ввод
```text
3 16
1 10 100
```
Вывод
```text
6
```

```python
# Паттерн: Динамическое программирование с мемоизацией
# Сложность: O(N)

n, x = [int(i) for i in input().split()]
a = [int(i) for i in input().split()]

memo = {}

# Функция возвращает минимальное число монет для оплаты остатка,
# используя монеты до индекса idx включительно
def solve(rem, idx):
    if rem == 0:
        return 0
    if idx == 0:
        # Монета достоинством a[0] всегда равна 1
        return rem
    
    state = (rem, idx)
    if state in memo:
        return memo[state]
    
    current_nominal = a[idx]
    
    # Сколько целых монет текущего номинала помещается в остаток
    count = rem // current_nominal
    current_rem = rem % current_nominal
    
    # Вариант 1: платим count монет текущего номинала, остаток меньшими
    res = count + solve(current_rem, idx - 1)
    
    # Вариант 2: если есть остаток, можно заплатить на 1 монету больше текущего
    #  и получить сдачу меньшими
    if current_rem > 0:
        res = min(res, count + 1 + solve(current_nominal - current_rem, idx - 1))
        
    memo[state] = res
    return res

print(solve(x, n - 1))
```

## Problem 5: Интересный выбор блюд на ужине

**Условие:**
Т-Банк празднует свой день рождения. В честь этого события устраивается торжественный ужин для сотрудников, всего приглашено **2n** человек. Ресторан предлагает **m** различных блюд и располагает одним длинным столом, за которым можно разместить ровно **n** человек с каждой стороны (2 ряда по **n** мест).

Выбор блюд называется интересным, если никакие два соседних человека не выбрали одинаковое блюдо. Люди считаются соседними, если:
* они сидят в одном ряду (на соседних местах)
* они сидят друг напротив друга по разные стороны стола.

Определите количество различных интересных вариантов выбора блюд по модулю \(10^9 + 7\).

**Входные данные:**
* В единственной строке заданы два целых числа **n** (\(1 \le n \le 10^6\)) и **m** (\(1 \le m \le 10^9\)).

**Выходные данные:**
* Выведите одно целое число — количество интересных вариантов по модулю \(10^9 + 7\).

**Примеры:**
Пример 1
Ввод
```text
2 2
```
Вывод
```text
2
```

Пример 2
Ввод
```text
4 4
```
Вывод
```text
4116
```

```python
n, m = [int(i) for i in input().split()]
MOD = 10 ** 9 + 7

if m < 2:
    # Если одно блюдо, люди напротив друг друга, то нет интересного выб.
    print(0)
else:
    # Вар. для первой верт. пары
    first_col = (m * (m - 1)) % MOD

    # Вар. для след. колонки
    next_col = (m * m - 3 * m + 3) % MOD

    total = (first_col * pow(next_col, n - 1, MOD)) % MOD

print(total)
```

## Problem 6: Набор команды (Бэкендеры и ML-инженеры)

**Условие:**
Компания T-Bank планирует нанять **a** backend-разработчиков и **b** ML-инженеров. Всего на позиции претендуют **n** кандидатов. Каждого кандидата можно назначить только на одну из двух ролей.

Для каждого кандидата известны две оценки:
* **x** — уровень backend-навыков
* **y** — уровень ML-навыков

Требуется выбрать сотрудников так, чтобы было нанято ровно **a** backend-разработчиков и ровно **b** ML-инженеров, максимизировав суммарную сумму навыков выбранных сотрудников. Каждый кандидат может быть выбран не более одного раза.

**Входные данные:**
* Первая строка содержит три целых числа **a**, **b** и **n** (\(1 \le n \le 2 \cdot 10^5\), \(0 \le a, b \le n\), \(a + b \le n\)).
* Далее следует **n** строк, каждая из которых содержит два целых числа **x** и **y** (\(0 \le x, y \le 10^9\)) — навыки кандидата.

**Выходные данные:**
* Выведите одно целое число — максимальную суммарную сумму навыков.

**Примеры:**
Ввод
```text
3 2 7
10 12
11 11
9 1
1 2
3 2
7 6
5 3
```
Вывод
```text
44
```

```python
import heapq

a, b, n = [int(i) for i in input().split()]

candidates = []
for _ in range(n):
    x, y = [int(i) for i in input().split()]
    candidates.append((x, y))

# Сортируем всех кандидатов по разности в реверс
candidates.sort(key=lambda item: item[0] - item[1], reverse=True)

# Макс. сумма a бэкендеров из кандидатов 0...i
max_x_prefix = [0] * n
heap_x = []
current_sum_x = 0

for i in range(n):
    heapq.heappush(heap_x, candidates[i][0])
    current_sum_x += candidates[i][0]

    if len(heap_x) > a:
        current_sum_x -= heapq.heappop(heap_x)

    if len(heap_x) == a:
        max_x_prefix[i] = current_sum_x

# Макс. сумма b ML из кандидатов i...n-1
max_y_suffix = [0] * n
heap_y = []
current_sum_y = 0

for i in range(n - 1, -1, -1):
    heapq.heappush(heap_y, candidates[i][1])
    current_sum_y += candidates[i][1]

    if len(heap_y) > b:
        current_sum_y -= heapq.heappop(heap_y)

    if len(heap_y) == b:
        max_y_suffix[i] = current_sum_y

# Ищем оптимальную точку разделения k между бэк. и ML
max_total_score = 0
for k in range(a, n - b + 1):
    # Бэкендеры выбираются из 0...k-1, ML — из k...n-1
    total = max_x_prefix[k - 1] + max_y_suffix[k]
    if total > max_total_score:
        max_total_score = total

print(max_total_score)
```

```python
# Паттерн: Жадный алгоритм / Куча (Heap) / Префиксы и суффиксы

a, b, n = [int(i) for i in input().split()]

# Сортируем всех кандидатов по разности в реверс

# Функция для сбора максимальных сумм k элементов в куче
def get_best_sums(items, count, is_reverse=False):
    res = [0] * n
    heap, curr_sum = [], 0
    indices = range(n - 1, -1, -1) if is_reverse else range(n)
    
    for i in indices:
        heapq.heappush(heap, items[i])
        curr_sum += items[i]
        if len(heap) > count:
            curr_sum -= heapq.heappop(heap)
        if len(heap) == count:
            res[i] = curr_sum
    return res

# Получаем префиксы бэкенда и суффиксы ML
max_x = get_best_sums([c[0] for c in candidates], a)
max_y = get_best_sums([c[1] for c in candidates], b, is_reverse=True)

# Ищем максимальный результат по всем точкам разделения
print(max(max_x[k - 1] + max_y[k] for k in range(a, n - b + 1)))
```

## Problem 7: Преобразование строки в TOI-палиндром

**Условие:**
Организаторы «T-Bank Olympiad in Informatics» вводят новый класс строк, используемых в олимпиадных задачах. Строка называется TOI-строкой, если выполняются следующие условия:
* Она состоит только из символов **T**, **O** и **I**;
* Она читается одинаково слева направо и справа налево (является палиндромом).

Дана произвольная строка из больших букв латинского алфавита, требуется преобразовать её в TOI-строку. За одну операцию разрешается выполнить одно из следующих действий:
1. Заменить один символ строки на другой;
2. Удалить один символ;
3. Вставить один символ в произвольную позицию.

Требуется определить минимальное количество операций, необходимых для преобразования данной строки в TOI-строку.

**Входные данные:**
* В первой строке задано целое число **n** (\(1 \le n \le 1000\)) — длина строки.
* Во второй строке задана строка **s** длины **n** из больших букв латинского алфавита.

**Выходные данные:**
* Выведите одно целое число — минимальное количество операций.

**Примеры:**
Ввод
```text
7
AOTXITB
```
Вывод
```text
3
```

**Замечание:**
В примере из условия исходную строку `AOTXITB` можно преобразовать в TOI-палиндром `IOTXI` (или аналогичный), если заменить `X` на `I`, `B` на `O` и удалить `A`. Всего 3 операции.

```python
import sys

# Увеличиваем лимит рекурсии для вложенных вызовов
sys.setrecursionlimit(2000)

n = int(input())
s = input().strip()

VALID_CHARS = {'T', 'O', 'I'}
memo = {}

# Возвращает мин. стоимость приведения подстроки к TOI-палиндрому
def get_min_ops(i, j):
    if i > j:
        return 0
    if i == j:
        # Для одного символа: 0 операций, если он уже T, O или I, иначе 1 замена
        return 0 if s[i] in VALID_CHARS else 1

    state = (i, j)
    if state in memo:
        return memo[state]

    res = float('inf')

    # Вариант 1: Символы на краях совпадают и валидны
    if s[i] == s[j] and s[i] in VALID_CHARS:
        res = min(res, get_min_ops(i + 1, j - 1))

    # Вариант 2: Замена левого, правого или обоих символов на одинаковые валидные ('T', 'O', 'I')
    # Стоимость: 1 (если один символ уже == нужному, второй меняем под него) или 2 (если меняем оба)
    for char in VALID_CHARS:
        cost = 0
        if s[i] != char: cost += 1
        if s[j] != char: cost += 1
        res = min(res, cost + get_min_ops(i + 1, j - 1))

    # Вариант 3: Удаление/вставка символа с левого края
    res = min(res, 1 + get_min_ops(i + 1, j))

    # Вариант 4: Удаление/вставка символа с правого края
    res = min(res, 1 + get_min_ops(i, j - 1))

    memo[state] = res
    return res

print(get_min_ops(0, n - 1))
```
